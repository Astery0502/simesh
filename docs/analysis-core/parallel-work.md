独立任务优先新增自己的模块，不同时改 `__init__.py`、`applications.py`、`geometry.py`、
全局 README 和当前方向文档。通过模块导入即可使用，公共导出及便利入口在后续集成时统一处理。
确有必要改共享契约时，先说明具体阻塞和最小变化，不自行扩大为通用执行框架。
各任务完成实现与相称验证后，提交本 worktree 的改动，报告提交号、测试和已知限制；不自动合并或推送。

共同保持：原生核心仍为非周期笛卡尔三维；QSL/twist 诊断不保存积分路径；
筛选种子后再独立追踪；应用追踪默认双向。已有一般数组接口继续保留。

## 暂不启动，留在当前任务继续分析

- 时间序列与多快照流程。
- 真实强 QSL、长磁力线、弱场/零点邻域的验证。
- 准备后字段子集、字段合并、多输出派生配方。
- 保留编号和弧长的沿线诊断。
- 散度、力平衡等数值质量汇总。
- 独立追踪与 QSL 脚点的定位一致性。
- 真实大输入、应用级流式输出和负载均衡。

这些事项没有交给三个并行任务，不视为它们必须顺带完成的工作。
