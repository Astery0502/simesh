# 探索任务：热 LOS 同单元多节点复用

先读[共同约定](sampling-reuse.md)。本任务只研究已分段热射线中的角点和寻址
复用，不改射线遍历、响应表、细分数、积分公式或热场构建方式。

## 源码切入点与假设

`_kernels/thermal_rays.pyx` 的 `thermal_leaf` 已在插值节点处划分区间。
subdivisions=4 时，每段有八个 Gaussian 求值点，逐次通过 `interpolate`
读取密度/温度角点和计算索引。

候选假设：单段内可复用八角点及部分寻址，保持每个点原来的坐标、权重与
算术次序。先做局部角点读取和多节点计算；不采用沿射线多项式展开/Horner
或近似 log/pow，不将“先插值热变量再响应”替换为“先 emissivity 再插值”。

必须核对浮点舍入：极短区间、擦边位置、nextafter/clamp 后实际插值单元
可能与理想区间推断不同。复用条件不能仅凭数学上的同一区间假定成立；
必要时保留原路径处理特殊情况。失败/非有限值的采样计数和输出状态保持。
优先在任务自有头文件实现 helper，避免修改通用 `native.pxd`。

## 核心检查

沿用当前热场模型/重构的编译与 Python 参考检查。补充能触及复用条件的
斜射线、节点边界、退化极短段、不同 subdivisions、非有限值或缺失覆盖案例。
检查输出值、状态、entry/exit 和样本数，不只比较图像视觉效果。

## 有用的前后比较

使用 `scripts/compare_n3.py` 的 WENO 热配置：显式构造 0.45–1.65 MK 正弦
温度，原密度归一化与长度单位不变；500² 轴向与斜向图像各一幅，subdivisions=4。
先做 64² 完整一致性检查，再做正式工作量。构造温度不是实际快照热力学声明。

分别记录同一已准备热场的积分时间与文件→准备→热场→图像的完整时间。
保留 emissivity-first 作为不应改变的路径控制，但不要把其耗时变化解释成
本候选收益。workers=1/4 即可；不要并行测量或展开细分/调度的组合矩阵。

最终按共同约定交付，证据写 `evidence/sampling-thermal-nodes.md`。如果角点
已经被缓存得很好而局部副本增加成本，应据实拒绝或精简候选；不改变精度/
积分工作量来满足性能目标。
