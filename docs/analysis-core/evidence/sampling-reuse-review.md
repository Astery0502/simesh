## 协调任务的比较方法核查

两个比较器均在独立解释器中加载一份版本，完整数组哈希在主体计时外；
分别报告原始首次值与交错重复结果。控制请求和主体请求分开计时。

B/curl 记录的 `file_to_result` 从打开源开始，**不含 Python 包导入**，不能
写成包含包加载的完整启动耗时；其 trace 包含准入、积分与摘要组装。
热比较同时记录文件到图像与含包加载的 startup，控制 emissivity-first 不计入
主体双图请求。两者的“完整时间”名称须按各自边界解释，不能跨请求直接相加。

候选最终记录已核对：后续热内核差异仅为模块说明文字，未改变已审算术。
源码评审不等同于采用；两个单独候选的加速没有相加作为整合收益。
