## 1. 目标与完成边界

围绕数据如何准备、组织和被应用消费，组合已有有效实现，形成清楚且有实际
效率收益的主路径。优先减少显著的准备成本、长批量计算时间和重复分析累计时间，
同时改善适用阶段的并行 kernel 与任务划分。短耗时部分优先保留方便接口；
只有在真实工作流中累计成为主要成本时才专项优化。

普通流程为：选择字段与全域/选区，取得真实 AMR 支撑，一次准备独立场，反复
计算所需结果，按需保留或分批交付。全域无法驻留时保留显式批次流程。
F 和 D 是主要工作流，F 略优先；L 继续在已交付科学范围内优化。

长任务的终点是：六个主要计算块都有明确职责与处置；选定主要成本的改进完成
实现和对应 weno509 对照；完整应用获得有用收益且不存在未解释的实质回归；
接口、构建与受影响的科学/所有权行为通过检查；保留可用基线、简明证据和恢复入口。
完成设计或单个 kernel 不是整个任务结束。某个模块经审查无需修改，可以明确
保留并复用已有证据，无需为了证明工作量改写它。

本轮不承诺 Q、新重构、精确边界足点、周期/2D 新分析实现、GPU、CT 或真实
10–20 GB 超内存输入验收。已有规范 API 继续可用。重分块、自动缓存体系、
通用任务图或表达式引擎不进入默认实施队列。

## 2. 模块与计算阶段

| 大块 | 内部功能 | 输入与输出 | 设计重点 |
| --- | --- | --- | --- |
| 输入与读取 | 元数据、记录索引、文件传输、解码、字段提取 | 文件与字段/叶块选择 → 原始内部值 | 全域批量和区域选择性读取分别保留；不承担 ghost 运算 |
| 网格与几何 | 森林、邻接、区域选择、点定位、射线区间定位 | 网格描述 → 可复用几何及空间查询 | 几何不持有字段值、淘汰或积分状态 |
| 鬼点准备 | 支撑规划、装载与缓冲区绑定、同级复制、限制、延拓、物理边界 | 几何和完整支撑值 → 有效准备场 | 规划、读取、数值执行、发布可以单独分析和替换 |
| 基础数值运算 | 插值、导数、curl、具体物理量变换 | 有效场 → 样本或独立派生场 | 编译循环接收明确数组，不进入文件与缓存管理 |
| 科学消费者 | 追踪、twist、切片、标量 LOS、热 LOS | 场与科学请求 → 对应科学结果 | 维持各自步进、积分、覆盖和终止语义 |
| 批处理与交付 | 种子/像素/叶块分批、调度、汇集、流式输出 | 独立任务及结果批次 → 完整交付 | 普通调用方便，大任务允许显式控制批次与输出 |

这是职责划分，不要求建立六套类或插件系统。分配、清零、布局转换、复制归属
发生它们的模块，但必须能单独记录成本。计时划分可以比模块划分细。

```mermaid
flowchart LR
    A["文件与字段选择"] --> R["读取与解码"]
    A --> G["网格与几何"]
    G --> P["支撑规划"]
    P --> R
    R --> H["鬼点数值执行"]
    P --> H
    H --> F["独立准备场"]
    G --> K["数值运算与科学消费者"]
    F --> K
    K --> O["结果与分批交付"]
```

消费内核不调用读取、准备器或缓存池。已有有限容量消费者的缺失恢复留在其
外层协调边界，普通固定覆盖消费可以直接执行。接口层和高效循环允许在同一
模块共存；不为函数名统一而强迫 F/D/L 使用一个通用遍历器。

## 3. 鬼点准备的优先讨论项

“准备”需要区分四种工作：

1. 规划目标、真实支撑闭包、传递范围与阶段依赖。
2. 从读取模块取得支撑值，分配/复用工作区并绑定源与目标。
3. 执行同级复制、限制、限制器与延拓、物理边界处理。
4. 转换/复制结果，并在完整成功后发布有效准备场。

规范驻留路径的价值是已有邻接、直接数据访问和编译循环；区域路径的价值是
明确目标及其真实支撑。统一准备的输入输出和依赖模型，保留适合不同覆盖的
执行组织；不强制它们立即共用全部最内层代码。

全域规范 provider 使用 `canonical-coordinatephase-cont-v1`，区域 provider
使用 `rewrite-ratio2-minmod-exactphase-cont-v1`。已有比较不等于逐位相同；
迁移必须明确采用的算术，不在同一准备产品中无声混用不同策略。

规范 `AMRMesh.getbc` 是分阶段串行叶块循环，部分操作由当前叶块写入邻居。
rewrite `_apply_chunk_actions_unchecked` 在 Python 的 primary/direction 循环
中调用数值 primitives，并复用 action 数组与 coarse 工作区。优先审查能否以
批量编译执行减少编排，再按目标写入归属、阶段屏障与私有 scratch 组织并行。
源码入口为 `amr/mesh.pyx`、`analysis/providers.py` 与
`rewrite/src/simesh_rewrite/refined_halo.py`。不能只把外层循环改成 `prange`。

具体方案以相同算术、支撑和输出的比较决定。减少预检查只能基于明确的不变
事实和其生命周期；动态字段/槽位、别名、输入有效性及失败发布义务仍保留。

## 4. 现有资产的处置

| 方法 | 建议处置 | 依据、代价或重新考虑条件 |
| --- | --- | --- |
| 连续记录批量读取与批量解码 | 全域主路径保留 | 完整流程已有收益；区域保留选择性读取 |
| 驻留邻接、几何与规范 bulk 准备 | 保留 | WENO 几何只有几十毫秒；不为消除它增加管理机制 |
| 独立准备场、独立 curl 场 | 核心数据组织 | 多消费者共享，派生量不重建 B 的存储 |
| 直接批次准备、减少重复编排 | 保留并继续审查编译边界 | 相同读取量和输出已有收益；不变与动态检查分开 |
| 导数循环不变量外移 | 保留 | 同运算树已有性能与数值证据 |
| 追踪定位提示、射线区间遍历、已知 owner 插值 | 保留 | 避免重复树查询、全叶扫描和 Python 临时工作 |
| 完整准备块池 | 显式有限容量选项 | 工作集适配时避免整次准备；不强迫驻留消费者理解池 |
| 原始值缓存 | 条件性保留，默认不扩展 | 主要减少读取，不能消除 ghost 规划和运算；按完整时间判断 |
| 持久 fill plan | 显式可选 | 适合相同几何再次准备；同一准备场反复消费无需重执行计划 |
| 多进程全域准备、多视角交错 | 保留具体用途与对照 | 既有有限容量收益不决定驻留默认路径 |
| 重分块 E1 | 暂缓默认采用 | 存储潜力已证明，完整计算加速未证明；需直接砖边界准备与原生消费者 |
| 更精细命中反馈、额外 padded staging | 保持历史回退结果 | 旧实验增加了重复准备；无新原因不重启 |
| 自动多层缓存、动态分页、通用表达式/任务图 | 暂不建设 | 当前重要流程不需要这些外围机制 |
| E2/E3 新重构与 dual mesh、E4 GPU/RT | 保留研究入口 | 需要新的科学需求或硬件与定位瓶颈，不是 CPU 交付前提 |

区分“保留算法”“保留特定执行组织”和“保留整个接口”。旧 provider 是可替换
组件；不因已复用就跳过对其主要成本的检查，也不按历史文件逐个移植。

## 5. 对决策有用的历史证据

以下都是历史同轮结果，不是本次新测量，各轮时间不拼接：

- [逐阶段比较](evidence/stages.md)：相同后续交换与消费者，原型读取完整流程
  6.110 秒，批量读取逐记录解码 2.277 秒，批量读取与解码 2.169 秒。
  大头来自读取组织，批量解码贡献较小；主机与文件缓存未完全控制。
- [直接准备](evidence/direct-preparation.md)：固定区域准备 1.232 → 0.315 秒，
  支撑装载数量、字节和结果相同。该区域准备 1,142 个目标块，实际轨迹只访问
  246 个 owner；可容纳工作集的池首次请求更便宜。选区驻留不是普遍最优。
- [导数比较](evidence/p3-d-global-slices.md)：相同运算顺序，历史全域 kernel
  0.648 → 0.208 秒，完整派生分配/curl/两切片 0.849 → 0.400 秒。
- [运行时比较](evidence/runtime-execution.md)：准备块保留与原始值缓存避免的
  工作不同；减少读取字节没有自动转为等比例时间收益。追踪静态 OpenMP 与
  线程池近似相当；64 视角已有准备场的图像调用/交付由静态线程池 9.738 秒
  降至动态 OpenMP 7.880 秒。公共准备另计，不是独立冷文件到结果试验。
- [几何计划](evidence/geometry-plans.md)：固定几何重复准备有收益；计划构建
  和保留量要计入，不能用 warm 执行隐藏首次成本。
- [重分块](evidence/rebricking.md)：全域 padded 计数减少 39.24%，但原型先
  准备原叶块再打包，稀疏覆盖放大，尚未证明全流程加速。
- [热射线](evidence/thermal-rays.md)：保留 AMR 区间、增量单元穿越、共享内联
  插值与编译响应计算；实际 500² 结果已有证据，但有显著主机/内存压力波动。

## 6. 共享数据与并行约定

- 原始叶块身份、字段身份和存储槽位分开，保留未来映射边界而不先建设重分块。
- 原始内部值可保持 field-major；准备场当前为 component-adjacent
  `(slot,x,y,z,component)`。转换在明确边界发生，不为统一布局反复复制。
- 覆盖与支撑分开；支撑区不变成结果区，选区边缘不当作物理边界。
- 主场至少两层有效 halo；当前一次导数留下一个有效派生层。更长导数链需真实
  传播 reach，不能把分配了空间当作已有有效数据。
- 准备结果、几何、临时 coarse/support 和 worker 状态分别明确所有权。
  新场不改变旧场；结果能在源关闭后继续使用。尚无收益时不先建设分配器。
- 规范 owner 当前继续保留约 278 MB 的 WENO 三分量 coarse 工作区。分离其
  生命周期是候选，不是已实现速度或 RSS 收益；避免为了释放它复制整个准备场。
- 内核共享只读场，每个 seed/pixel/目标区域拥有输出及临时状态；消费者不改变
  源或缓存。并行只选择一层，避免进程、线程池与 OpenMP 嵌套放大工作者数。
- 追踪以 seed 并行，单线 RK 阶段顺序不变；LOS 以 pixel/ray 区间并行，逐像素
  累加顺序不变；导数按叶块分工；鬼点先解决跨目标写入和阶段依赖。

四工作者是本机此次测量范围，不作为未来科学能力的永久上限。方便接口可以
主要暴露 `workers`、科学参数和输出选择，但默认后端必须由完整负载证据支持。
编译了 OpenMP 本身不是采用自动后端选择的理由。

## 7. 长任务执行顺序

1. **建立可信工作基线。**读取本文件、current、必要的科学约定；确认实际工作区、
   源码状态与扩展构建。区分已验证的批量读取/直接准备成果和未验收并行草稿。
   保存可恢复基线及必要对照；不覆盖旧结果、不丢弃用户已有改动。
2. **准备模块优先。**围绕规划、装载、运算、发布检查当前主要成本，选择少数
   有明确假设的候选。优先减少重复工作、批量编译执行和合适的并行结构。
   同时保留快速驻留与明确区域使用方式。达到有效完整收益后继续下一块。
3. **长消费者与并行。**保留定位/射线/导数已有改进；用长追踪和实际图像比较
   工作划分、调度与内存访问。逐项评估上轮热 OpenMP 草稿，不预设其必须采用。
4. **接口与组合。**让一次准备、多次消费、独立派生场、按需输出自然组合。
   避免普通用户反复传递缓存/内部调度参数。廉价操作不创建新的优化框架。
5. **完整验收与交付。**运行受影响的 weno509 组合、核心检查和必要的构建/安装
   检查；给出相对规范路径及上一可用版本的同范围结果，更新设计与 current。
   六块中未改的部分说明保留依据。提交代码/文档检查点，准备清楚的最终差异。

每轮候选开始前写下成本假设、比较对象、工作量和停止条件。一次只推进一个
离散探索，通常至多两个可信候选；失败后修复或保留基线并说明原因，不反复调参
直到出现偶然更快的样本。普通技术取舍、回退本人候选、构建、测试、基准和本地
检查点均在授权范围内，不在每阶段重新索取许可。

只在缺少必要的科学含义/精度决定、需要扩大资源或替换授权外支持范围时询问。
保持其他可执行工作推进。不把全部研究方向或真实大输入缺口变成这次任务阻塞。

## 8. WENO509 验证安排

固定样本为 `data/weno509_sub_0000.dat`，1,045,232,320 字节，22,614 个 8³
叶块、级别 3–6。磁场普通字段为 b1/b2/b3，原文件位置 4/5/6。用户已明确
这里的样本就是 weno509。读取普通字段并跳过已验证的 staggered 尾部不代表 CT。

| 检验块 | 固定请求与起点 | 主要指标 |
| --- | --- | --- |
| 读取 | 全域 B；区域变更时复用已有 mixed/thin 选区 | 总读取时间、字节/批次数、解码与布局复制、原始位一致 |
| 鬼点 | 相同原始值、目标叶块、两层 halo 和边界策略 | 规划、装载、数值交换、发布，以及完整准备时间 |
| 派生量 | 同一准备 B，全部叶块 curl，128² 轴向与 96×80 斜切片 | kernel、分配/发布、完整消费者时间及全域有效值 |
| 追踪 | 同一准备 B，固定种子/步长/步数上限 | 总时间、实际接受步数/采样数、终止分布、1/2/4 工作者扩展 |
| LOS | 同一准备场，实际 500² 轴向与斜向；重复视角按相关变更选用 | 图像总时间、采样量、负载均衡、覆盖与输出一致 |
| 组合 | 文件 → 准备 → 连续多次分析 → 交付 | 首结果、累计时间、完整活跃内存与输出成本 |

追踪初始候选规模为 65,536 seeds、至多 1,000 步，以既有固定分布构建确定性
请求；执行前冻结坐标生成、步长与输出模式。默认只保留摘要，需要检查轨迹时
另取少量固定 seeds。记录实际工作，不能仅凭 max_steps 宣称完成长路径测试。
不为微小 helper 人工增加无应用意义的重复次数。

热 LOS 使用既有制造的 0.45–1.65 MK 温度与明确演示单位，沿用其 nonlinear
重构与 quadrature。WENO 不含真实温度；这组验证计算效率与实现一致性，不能
宣称真实快照热辐射。标量 LOS 可单独评估几何与并行，不强制依赖热模型。

比较规范实现、上一可用版本及候选在相同输出上的成本。新消费者没有规范对应
实现时明确注明，不制造 tracer/LOS 原型对照。阶段测量与实际文件到结果分开；
不能把不同驻留状态、版本或运行中的阶段中位数相加宣称完整加速。

采用同机交错测量，必要 warmup 后通常三次正式重复，保存全部原始时间与波动。
归因和数值检查在正式计时之外；OpenMP 比较包含同构建单工作者，记录编译设置。
操作系统缓存未控制就如实标注。稳定性不足时先解释负载/缺页，不发布精确倍率。
核对完整请求及声明有效区；相同算术以精确一致为目标，不同历史策略沿用既有
独立数值比较，不放宽容差掩盖失败。复用充分的既有科学参考，只补实际改变的风险。

默认沿用 8 GiB 本机的保守范围：最多四计算工作者，单例受控活跃数组不超过
