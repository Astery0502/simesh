## simplify 修复

三路审查完整 diff 后处理了以下问题：

- 原磁压/磁能接口在 `mu=1e308`、`B=1e154` 时因中间 `2*mu` 溢出返回零，
  与 MHD 恢复的正确磁压 0.5 不一致。统一为先除以 `sqrt(mu)` 的稳定顺序，并加入跨接口断言。
- 文件边界禁止已发布的 LOS/轨迹保留 RUNNING；成功 LOS 必须有限，空 LOS 必须为零；
  有效 Q 不得为 NaN 或非正值，正无穷溢出仍保留。增加损坏状态的读写回归。
- 文件解码复用已拥有的数组，仅在字节序/布局转换时复制；调用者元数据先校验，
  清单大小在完整对象校验前检查。
- MHD 复用已有字段选择工具，保持 None 拒绝；缓存局部平方根与有限性掩码。
- 归约复用单块的有限性掩码和交叠测度筛选结果。
