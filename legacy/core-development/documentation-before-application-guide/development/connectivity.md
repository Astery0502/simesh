# AMR 磁连接性实现检查

日期：2026-09-08。面向开发协作。

按用户要求，将 FastQSL2 公开方法中的磁连接性与 twist 计算接入独立包。
实现入口为 `qsl` / `iter_qsl`，默认采用脚点差分，也可显式选择变分法；
提供 Q、Q⊥、局部球面映射、双向脚点、长度和 twist。
复用 N4 的整数几何、三线性插值、中心差分、curl 来源校验和线程执行工具。
原有 `trace` 不改变停止语义。详见[英文调用说明](../connectivity.md)。

## 来源与实现选择

- 上游：[陈俊等的 FastQSL2](https://github.com/el2718/FastQSL2)。
- 数学来源：[Chen et al. (2026)](https://arxiv.org/abs/2604.16195)及其引用的方法论文。
- 对照版本：`314bbf01ab72e43f82cb6b2e1c2a4d22d93aacdd`。
- 上游声明 CC BY-NC-SA 4.0。本库没有复制或翻译其 Fortran 源码，
  没有加入该代码作为依赖；按公开数学方法独立编写 Python/Cython 消费者。
- 采用按局部 AMR 单元尺寸限制的 RK4 和边界事件二分重积分。
  没有声称复现上游 RKF45 或全部球坐标、周期、输出与绘图功能。
- 默认以实际映射的面积行列式归一化；`normalization="flux"` 对应上游常用的无散磁通关系。
  两种归一化在离散磁场中不保证相同。

## 直接对照

通过本地 gfortran 编译独立下载的上游程序；其 Python 包装器在父环境中运行，
新实现使用 `analysis-core/.venv`。没有修改父包或安装依赖到父环境。
两边采用相同的 64³ 均匀节点值、15 个种子和节点范围作为积分边界。
新实现为脚点差分加磁通归一化，上游为变分法加磁通归一化。
这是一项跨方法、跨离散边界实现的比较，不是逐位等价声明。

| 磁场 | Q 最大相对差异 | Q⊥ 最大相对差异 | twist 最大绝对差异 |
| --- | ---: | ---: | ---: |
| 双曲场 | 0.01675% | 0.01669% | 0 |
| 螺旋场 | 0.0000345% | 0.0000464% | 4.44×10⁻⁷ |
| 四极势场 | 0.8540% | 0.8197% | 5.90×10⁻⁵ |

四极势场理论 twist 为零，非零结果来自离散 curl；接近零时相对误差没有代表性。
三组 45 个中心种子均完成定位。完整数值见
[对照结果](evidence/fastqsl2-comparison-2026-09-08.json)，复现入口是
`analysis-core/scripts/compare_fastqsl2.py`。

直接采用变分法时，64³ 四极场的 Q 对照差异仍约 9.46%，与物理边界附近
单位方向梯度的离散处理差异有关；加密后减小但不应当作等价。
因此默认用脚点差分直接计算实际 AMR 映射，并保留变分法供显式选择和交叉检查。

## AMR 与失败语义

测试包含匀强场 Q=2、正负螺旋场的解析 twist、双曲场的解析 Q 与网格收敛，
同时检查反序叶块、混合粗细层、有限差分脚点导数、边界种子、局部球面、
角点、空输入、缺失覆盖和内存拒绝。
混合 AMR 四极场还对步长和扰动间距同时减半进行了检查，所选三点 Q 变化小于 1%。

已完成 `analysis-core/` 内的 `make build` 和 `make test`：51 项通过，
2 项由于普通构建未启用 OpenMP 而跳过；没有改动既有准备或追踪的数值语义。

后续 simplify 审查修复了局部球面事件被球面外缺失覆盖抢先中断的问题：
事件试步增加球面延拓与半径步长上限，回归覆盖球面紧邻缺失区的情况。
同时跳过无效邻线和脚点差分中的变分计算，复用线程池、正交基和种子采样逻辑。

完整性表示中心线两端到达指定表面，不代表角点或跨边界类型的扰动邻域存在
可微映射；必须同时检查 `valid`。步数/长度截断的 Q 为 NaN，Q⊥ 和 twist
可描述已接受段。缺失数据不会被当成物理边界，失败结果不会当作有效科学值。

这次验证使用解析和小型混合 AMR 数据，没有真实大文件验收或吞吐性能承诺。
新数据需要分别检查输入分辨率、积分步长和扰动尺度；尤其不能用高密度输出种子
代替输入磁场的精度检查。
