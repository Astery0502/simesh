## 接口与数据边界

通过 `simesh.results_io` 显式导入 `save_result` 和 `load_result`。
前者写入一个对象并返回路径，后者返回包含原有结果类型、调用者元数据和来源说明的
`ResultFile`。用法和可运行示例见[用户文档](../result-files.md)。

支持 `PointSet`、`RaySet`、`SampledPoints`、`ConnectivityMap`、`QSLResult`、
`RayResult`、`LineSet`、`UniformResult`。保持几何、布局、整数编号、字段定义、单位、
状态与可选诊断量。稀疏点集保持当前一维布局和父平面；原始 `QSLResult` 没有编号和图像布局，
不会人为补造。射线方向重载后保持原数值，避免重复归一化改变掠射位置的裁剪。

格式版本为 1：单个压缩 NPZ 文件包含标准数组及 UTF-8 JSON 清单。读操作使用
`allow_pickle=False`，只允许封闭的类型、成员和数组类型；校验形状、编号唯一性、
双支偏移、种子关联、枚举状态以及诊断有效性与完成状态的一致性。
写入采用现有 `write_amrvac` 的同目录临时文件与硬链接／替换发布协议；默认拒绝覆盖，
显式覆盖也在序列化成功后才替换。原机制内嵌在 AMRVAC 写出函数中，没有可直接调用的通用
发布函数，因此仅复用该协议，不修改其他模块以抽取新公共辅助函数。

## 数值与来源语义

不重采样、不转换单位、不重新计算物理量。保留非有限诊断值、覆盖有效性与有限值可用性的
区别，以及失败／不完整状态。仅计算 twist 时四个 Q 数组保持空值；仅计算 Q 时 twist
保持空值。诊断不增加轨迹存储；筛选后仍通过独立追踪生成双支紧凑轨迹。

进程内 `source_identity` 不写入文件，重载后为 `None`。调用者显式提供的来源说明存入
独立字段，状态固定为未验证；未提供则明确标为未指定。空标识相等不代表同源，也不会
访问来源路径或自动计算摘要。结果对象未保留的积分参数、物理模型假设、输入字段或坐标
单位需要显式元数据补充。已有热 LOS 模型元数据与补充元数据分开保存。

## 限制

这是整体结果格式，保存和恢复可能需要多份驻留数组，不提供流式、追加、内存映射或内存
预算保证。JSON 清单限制为 1 MiB，元数据嵌套最多 64 层；调用者元数据中的无限值需转为
明确描述，NumPy 标量与数组需显式转换。依赖文件系统的硬链接与原子替换能力，不保证断电
后的持久性。来源未验证，结果也不保存可自动执行的配方、原始场、完整网格或重启状态。
未涉及 HDF5、Zarr、ParaView、时间序列、沿线诊断或字段合并。
