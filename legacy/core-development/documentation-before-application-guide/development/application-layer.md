# 点、射线与结果关联的首版接口

日期：2026-09-09。面向开发协作。

按本轮讨论，直接保留既有 `Fields` 和通用数组接口，增加 `PointSet`、`RaySet`、
`LineSet` 及独立的 `simesh.applications` 命名空间。
用户随后取消了在 QSL/twist 计算时保存路径的想法，因此没有给 QSL 内核或结果
增加轨迹存储；诊断后通过阈值筛选种子，再显式调用应用追踪接口。

- 点集支持任意物理坐标、平面像素中心、物理边界和分批平面坐标生成。
  筛选保留编号及父平面，稀疏点的当前形状为一维。
- 采样和诊断结果保留输入点集、数值和来源标识。诊断分批后仍使用原始点编号。
- `ConnectivityMap.threshold` 对 Q 使用有效映射，对绝对 twist 使用完整且有限的结果。
  条件可按任一或全部组合，阈值和任意掩码选择均不会触发路径计算。
- 单独追踪支持顺场、逆场、双向和边界向内方向，并将输出压缩为实际接受的点。
  仍采用通用追踪的接受前缀语义；上边界种子以最近域内浮点数启动，显示起点保留原坐标。
  未请求支路与无法定义向内方向的切向种子有单独状态。
- 射线保留起点编号、图像形状、方向和近远裁剪，支持公共方向或逐射线方向。
  标量 LOS 与原生 AIA171 热 LOS 均复用既有积分内核，只增加逐射线方向的调用适配。
- 结果保存来源标识而不保留磁场数组；几何可以明确复用于其他场。
  追踪批次和最终压缩输出都执行已知数组内存检查，未承诺进程 RSS 限制。

已在独立环境完成 Cython 重建。完整测试集为 59 项通过、2 项因未启用 OpenMP 跳过。
新增检查覆盖点布局与编号、稀疏选择、诊断分批编号、正负磁极性向内追踪、
上边界与切向种子、空输入、内存拒绝，以及逐射线标量/热积分与原平面接口的对照。
未作大输入或新接口吞吐性能承诺。

调用示例与限制见[英文应用说明](../applications.md)。
