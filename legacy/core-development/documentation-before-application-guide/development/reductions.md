- `volume_integral`：原始叶块内部值与选区交叠体积的乘积求和。

## 关键数值决定

积分对象固定为内部值的分段常数表示。主变量的完整单元积分是单元平均值乘体积；
截断单元按真实几何交叠计权，不恢复子单元线性变化。派生字段和已准备字段沿用这一语义，
保留字段解释以免把离散派生量或重构采样误报为守恒量。

叶块编号通过槽位目录访问，排除鬼点和细化父节点；按全局叶块编号排序归约，
极值并列时再按单元索引确定位置。默认选区来自字段已有选择，保留原请求矩形；
调用者可显式请求整域来检测部分字段的缺失覆盖。

表面通量显式选择单侧常值，内部交界默认取坐标正侧，支持负侧；物理域边界总取内部值。
法向符号与单侧选择相互独立。粗细交界两侧通量可能不同，不宣称恢复 CT 面通量。

默认遇到缺失、域外和非有限输入均抛错。显式忽略时报告请求、域内、可用、有效测度及损失，
不对积分补值；平均值只归一化保留的权重。负权重始终拒绝，零总权重平均和无有效单元的极值抛错。
空积分和空直方图返回零并保留覆盖信息。物理尺度由调用者显式提供，不解析单位字符串。
