## 交付边界

N3 已完成以下既有科学与执行能力的独立接入：

| 责任 | 实际实现与寿命边界 |
| --- | --- |
| 长追踪、接受段 twist、重追踪 | `tracing.py` 的具体 RK 状态供直接和有界入口使用；普通入口只接收 Fields。接受前缀、终止原因、原种子 ID、可选轨迹保持原语义。 |
| 派生结果复用 | curl 记录来源值身份、字段定义/顺序、分量与 scheme。逻辑身份不引用 B 的 backing；兼容的分批全域 curl 可以复用，错序/错分量拒绝。 |
| 标量 LOS | 保留插值节点分段和 Gaussian2/中点方案、深度限制、失败状态及多视角顺序；直接与有界路径共享图像分块。 |
| 热 LOS | 保留历史 AIA171 表、显式 H/He 组成和密度/长度单位、外部 K 温度或等温输入、两种非线性重构次序、编译与独立 Python 参考路径。 |
| E5 几何计划 | `plan_preparation(mesh, ...)` 只持有目标与几何动作，每次 `prepare` 绑定新来源/字段值并重算限制器；不持有 Source、原始值或缓存地址。 |
| 可选缓存和准备池 | 原始值缓存为独立 Source 适配器；准备池拥有 exact-phase 工作区和作用域借用。父源关闭禁止命中读取，池关闭不关闭父源。 |
| 有界消费者 | 明确的 `bounded` 入口恢复缺失块；没有把透明读取分派放回普通采样、追踪或 LOS。热 LOS 当前消费完成的热场组。 |
| 全域 curl 和文件任务 | 有界准备写入独立或调用者输出。进程/线程文件任务各自打开 Source，验证来源一致性；返回前等待全部任务结束。失败不发布完成场，调用者输出可能保留部分写入。 |
| 均匀输出 | 逐 z 返回拥有数据的 `(index, SliceResult)`；迭代器没有全体积 backing。调用者同时保留的历史切片由调用者计入占用。 |

保留。N3 没有另选重构或重启 E1 重分块、历史已回退缓存方案。实际来源和适配

## 核心行为和独立构建

新增 `tests/test_science_workflows.py` 围绕科学结果和寿命组合检查：

- 螺旋场的解析 twist、接受步结果、指定 ID 重追踪，以及小容量驱逐后 RK 状态续算。
- 分批全域 curl 与直接 curl 一致；错分量派生拒绝；保留 curl 后 B 可被回收。
- 常标量轴向/斜向路径长度积分、全像素状态、有界驱逐一致性和样本上限失败。
- 非线性温度场的编译/独立参考热射线一致性；两种重构次序确实产生不同结果，且
  先 emissivity 路径与独立标量积分一致；模型身份不匹配拒绝。
- 乱序目标的几何计划复用、字段重绑、换值重算、原始值命中、源关闭与缓存释放。
- 拥有结果的切片和独立文件线程/进程任务；可用时检查科学消费者的 OpenMP 一致性。

普通构建为 **21 通过、2 跳过**；OpenMP 构建为 **23 通过**。随后用 OpenMP

哈希，全部一致。三个相关编译模块的 `enabled` 均已检查；最终恢复普通构建。

## WENO 完整流程比较

原输入为 `data/weno509_sub_0000.dat`，1,045,232,320 字节、22,614 叶，
只读使用。脚本 `scripts/compare_n3.py` 在独立解释器中加载一种版本；
`run_science_comparison.py` 顺序交错执行新旧版本。NumPy 预加载后开始计时，
**包含包加载、文件打开、准备、科学计算及结果组装**，全数组哈希在计时外。
完整形状、dtype 和数组字节共同参与哈希，不使用少量抽样代替完整结果比较。

除文件任务一对之外，每组保留首对和三对后续测量；下表是后三对完整流程
中位数。没有控制操作系统文件缓存，不将一次波动或单核变化解释为普遍倍率。

| 工作流 | 固定工作量和结果 | 旧 / 新完整秒数 | 完整核对 |
| --- | --- | --- | --- |
| 长磁力线和诊断 | 256² 固定 XY 种子，起始 z=.05，步长为最小间距的 .25，最多 1000 步；64 种子 twist、3 条按 twist 选择重追踪 | 3.1817 / 3.0369 | 27 组数组；65,536 种子共 21,573,979 接受步一致 |
| 几何计划与有界组合 | 中心 .46–.54 选区，原始缓存 256，计划两次准备 b3/b1，池容量 64；32 种子×128 步 twist/轨迹，双视角 8² 标量 LOS，32×24×4 均匀输出 | 2.9277 / 2.7554 | 17 组数组全部一致 |
| 最终热图 | 500² 轴向和斜向各一幅，4 细分；另有 64² 的先 emissivity 路径 | 8.2387 / 8.3368 | 12 组数组全部一致 |
| 独立文件全域 curl | 2 进程，任务 512 叶，批量/支撑 256；完整 curl 与 128² 切片 | 7.4145 / 5.9889 | 3 组数组全部一致；仅一对，不作稳定速度结论 |

原始记录分别位于 `benchmark-results/n3/magnetic/`、`bounded/`、
`thermal-final/` 和 `file-curl/`。每个目录保留逐次 JSON 与汇总。

热图采用明确构造的归一化 z 正弦温度 0.45–1.65 MK、
`density_unit_g_cm3=1.4*PROTON_MASS_G*1e9`、`length_unit_cm=1e8`。
这验证既定响应/插值/积分流程，**不是快照真实温度恢复或实际仪器物理标定**。
非线性热积分是复合 Gaussian2 近似；不称为解析精确积分。

有界比较的旧缓存绑定三字段来源，新缓存属于七字段原始来源，实际分配容量
不同。因此只比较完整结果与流程，不声称这是一组相同缓存内存的策略优劣实验。

### 热场构建回归与修正

首次 500² 比较全部结果一致，但完整中位数旧/新为 8.5352/9.4510 秒，约慢
10.7%。源码和分阶段数据定位到新热场构造循环逐叶调用公共 `Fields.window`，
重复验证不变的槽位、选择和布局；不是射线算术不同。

修正把 density/temperature backing、slot 和有效窗口绑定移到循环外；
emissivity 构造同样处理。浮点表达式和响应公式保持原样。修正后另起一轮交错
比较得上表 8.2387/8.3368 秒，差约 1.2%，完整数组仍一致。首次结果保留在
`thermal/`，小图初核在 `thermal-small/`，没有删去失败比较或拼接不同时段
新旧耗时来制造加速结论。

## 真实输出规模与资源

`scripts/validate_large_output.py` 使用小型原生常向量场实际运行：

| 输出 | 实际工作量 | 测得时间 / 存储 |
| --- | --- | --- |
| 百万种子 | 1,000,000 种子，每条 32 接受步，共 32,000,000 步 | 2.148 秒，摘要输出 96 MB |
| 1000³ 均匀采样 | 1000 张 1000² 切片，共 1,000,000,000 点；逐片核对有效性和常向量值 | 含消费检查 43.315 秒，累计交付数值 24 GB，单片含状态/owner 最大 33 MB |

整段进程峰值 RSS 为 354,287,616 字节，约 338 MiB。全部切片实际计算并消费；
没有保存完整体积文件，不只是外推估算。该证据属于**大输出**，没有真实
10–20 GB 或超内存输入验收声明。记录在 `benchmark-results/n3/large-output.json`
及 `validate-n3-large.log`。

本机 8 GiB 内存、8 逻辑 CPU；计算最多四工作者，文件进程任务为二工作者，
大数组工作流全部顺序运行，未与编译或另一版本并发。内存 admission 沿用
2 GiB 受控活跃数组范围，包含相关输入、工作区、输出和文件任务/IPC 估算；
它不是 RSS 或操作系统文件缓存上限。

完整磁力线组峰值 RSS 旧/新约 1.479/1.464 GB，最终热图约 1.253/1.170 GB，
有界组约 112.7/101.1 MB。文件任务 JSON 只记录父进程 RSS，不能当作全部
子进程总峰值；其 admission 单独包含同时任务和返回值。
N3 结果与安装产物合计约 48 MiB，新增暂存低于 2 GiB；验收时磁盘可用约
30 GiB，满足至少 2 GiB 余量。
