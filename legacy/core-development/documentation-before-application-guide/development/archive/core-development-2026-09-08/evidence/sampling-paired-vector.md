## 候选范围与数值边界

仅修改 `analysis-core/src/simesh/_kernels/native.pyx` 的 twist 采样调用点，
新增专用 `paired_vector.pxd`；通用 `native.pxd`、文件读取、准备、curl 算法、
RK4、种子组织和求和顺序均未修改。

每个执行范围的栈上有一个 72 字节 `VectorStencil`，保存三轴的原始局部坐标、
未加存储偏移的 floor 索引和权重。B 先验证自己的数组范围，随后按原表达式
完成三分量采样。B 的有限值、范数和空场检查通过后，才查询 curl 的 slot、
检查 curl 自己的范围并按自己的 `storage_halo` 取值。curl 不重算几何。
原本一次成功 B/curl 对的六次局部坐标、floor 和权重计算减为三次；没有
硬件内存流量计数，不把这项变化解释为 DRAM 流量减半。

三个分量的乘加表达式与次序保持原样，float64、编译精度选项不变；没有全域
六分量副本。不同组的映射与存储 halo 不要求相等。普通 B-only 调用继续使用
原 `interpolate`。声明有效 halo 的公共准入保持原样，复用不扩大物理覆盖。

特别保留失败顺序：B 几何失败不增加 `samples`；B 插值成功后增加一次；B
非有限、范数不可表示或空场优先于 curl 缺失。curl 缺失只报告请求和 miss，
没有写入当前 RK 阶段的切向量或 alpha。失败采样不提交位置、长度、步数或 twist。

## 正确性检查

新增检查回答本 helper 的具体风险：

- 不同且带 NaN 外层填充的存储 halo；各组独立的奇数非打包槽位和相反叶顺序。
- 混合粗细网格的所有叶中心、各轴叶面及向内一个 ULP 的位置，包含物理边界；
  比较完整轨迹、状态、采样数、miss、长度和 twist 的原始 64 位表示。

  及当前 RK 切向量/alpha 不被失败采样写入。
