# 辐射合成扩展验证记录

日期：2026-09-11。

本次按 MPI-AMRVAC 上游实现扩展当前 `simesh` 包。核对远程分支后使用
`amrvac3.3` 的提交 `423ad207a7fedcf5436a4d1d229199e29e166e81`，
而不是本机较旧的分支缓存。算法、表格摘要及许可证来源记录在
[ASSETS.md](../../ASSETS.md)。

## 交付范围

- 新增 `EUV`：AIA 94、131、171、193、211、304、335；IRIS 1354；
  EIS 192、255、263、264。保留各仪器的上游插值方式与表外零响应规则。
- 新模型默认发射量为 `nₑ nH R(T)`；现有 `AIA171` 的默认 `nₑ² R(T)`
  和历史身份保留，避免无提示地改变既有结果。
- 新增 `HHeAbsorption`，按固定总氢密度及温度求解用于辐射后处理的
  Saha 电荷平衡。发射气体组成和吸收体氦丰度分别声明。
- 新增 `RadioFreeFree`，频率以 Hz 明确指定，输出射电亮温。
- `radiative_los` 复用现有原生 AMR 树定位与插值区间遍历，沿观察者到远端
  的方向累积发射与吸收；返回亮度、光深、无吸收亮度及吸收比例。
  远端背景、物理长度单位、覆盖失效及采样上限均显式处理。
- 对上游一阶层内累积作局部改进：使用常系数小层的解析传输解和 `expm1`，
  正确处理透明与大光深极限。空间变化系数仍需检查细分收敛。

新工作不改动模拟 EOS，不引入历史 Dataset，也不把球坐标、仪器 PSF 或
非 LTE 模型纳入当前笛卡尔接口。

## WENO509 全域测试

输入为 `data/weno509_sub_0000.dat`，共 22,614 个 AMR 叶块、11,578,368
个内部单元；未重采样成均匀体网格。温度按要求指定为 1 MK。
单位沿用仓库现有该快照示例的 `MHDUnits.solar()`：
密度系数 `2.3416706931659997e-15 g/cm³`，长度系数 `1e9 cm`。
这属于显式测试假设，不是从文件能量列恢复温度或自动识别归一化。

12 个 EUV 通道及 17 GHz 射电分别计算轴向、斜向两幅 32 × 32 图像，
共 26 组。全部射线处于完整或空射线状态，所有亮度有限且非负。
每组保存亮度、光深、无吸收亮度三个可重载结果，共 78 个结果文件。

- 与独立标量 Gauss2 薄积分比较，最大绝对差除以整幅图最大薄亮度为
  `5.9910051e-5`，约 0.006%。这是整图归一化偏差，不是每像素相对误差。
- AIA 171 和射电的细分从 4 加倍到 8 后，最大整图归一化亮度变化为
  `4.4932579e-5`，约 0.0045%。
- 每组另抽取一条穿过域内的射线，与独立 Python 叶块相交参考积分比较，
  均通过 `rtol=2e-10` 的一致性检查。
- EUV 最大光深约 `1.62e-15`，符合该热等温测试下吸收极弱的结果。
- 射电最大光深约 `0.005115`；轴向、斜向峰值亮温分别约 3142 K、5102 K。
- IRIS 1354 及 EIS 192、255、264 在此次 1 MK 测试中亮度为零，原因是
  响应表在该温度为零或温度低于表格下界，均非积分失败。

重现命令：

```bash
.venv/bin/python examples/radiation_bands.py data/weno509_sub_0000.dat \
  --temperature-k 1e6 --workers 4 --output example-output/radiation-weno509
```

详细数值记录在 `example-output/radiation-weno509/validation.json`。
该输出目录被忽略，不加入源代码交付；可由上面的示例重新生成。

## Simplify 结果

已依照 `simplify` 技能完成复用、代码质量和效率三方面的并行审查并处理发现：

- 共用发射及吸收的数密度约定换算系数，避免正向与反向定义漂移。
- 将固定温度对应的 Saha 项移出迭代循环。
- 仅在吸收求解中使用较高临时内存预算，保留普通发射率路径的原预算。
- 在加入背景前保存吸收比例，避免极亮背景造成浮点相消；补充回归检查。

整理后已重新执行全部测试、文档构建和 WENO509 全域测试。
