# FST-002 Evidence

## Correctness And Lifecycle Conformance

FST-002 provides the once-per-artifact conformance boundary extracted by the
TOP decomposition audit.  It validates representation semantics only; MOR key
order remains an upstream MOR-001 precondition and contacts/balance/cache policy
remain outside.

Nineteen focused tests and all 221 accumulated rewrite tests pass.  Valid
all-level-1, mixed-depth, and deep artifacts agree exactly with an independent
recursive Python reference.  Parametrized late corruption covers MOR inverse
maps, roots, levels, coordinates, parents, children, node-to-leaf and
leaf-to-node arrays.  Leaf/internal sentinels, truncated/trailing nodes/leaves,
maximum level 63, level-64 logical-grid overflow, dtype/shape/contiguity, empty
artifacts, and root subtree partitioning are explicit.

Read-only inputs are accepted and preserved.  A valid one-root artifact shares
the same array for node-to-leaf and leaf-to-node, proving read-only overlap is
allowed when simultaneous values conform.  A lifecycle test validates writable
arrays, mutates one level, observes rejection, restores it, and revalidates.
This freezes the requirement that unchecked consumers revalidate after any
mutation.

A mutually consistent reversed `(2,1,1)` rank map is accepted by inverse/root
alignment checks and is explicitly tested as outside the MOR mathematical-order
precondition; FST-002 does not overclaim what inverse consistency proves.  The
real refined Cartesian metadata artifact has 25,844 nodes, 22,614 leaves, and
maximum level six and conforms exactly.  Its staggered header remains metadata
evidence only.

## Runtime, Scaling, And Allocation

Final Apple arm64 measurements use 31 repetitions.  Synthetic profiles have 32
roots and uniformly refine through the stated maximum level.

| Max level | Nodes | Validation | Mnode/s | Validation / construction | Python reference |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 2 | 288 | 9.17 us | 31.4 | 0.77x | 1.142 ms |
| 3 | 2,336 | 22.42 us | 104.2 | 0.83x | 8.291 ms |
| 4 | 18,720 | 0.133 ms | 140.3 | 0.61x | 61.52 ms |
| 5 | 149,792 | 1.012 ms | 148.1 | 0.41x | not run |

The real 25,844-node tree validates in 0.184 ms at 140.3 million nodes/s.
Validation is below construction time in every profile and scales linearly once
fixed boundary cost is amortized.  Repeated calls retain zero traced bytes at
useful sizes and have a fixed 1,784-byte traced peak (1,752 bytes on the
smallest profile).  The C traversal uses only representable-depth stack state
and no heap, visited set, hash, or bitmap.

This cost is paid once per unchanged artifact lifecycle.  TOP-002, BAL-001,
GEO-002, and chunk/query loops must consume that established precondition rather
than repeat FST-002 internally.
