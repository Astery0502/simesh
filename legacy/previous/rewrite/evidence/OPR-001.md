# OPR-001 Evidence

## Correctness, IEEE Behavior, And Composition

Eleven focused tests and all 125 accumulated rewrite tests pass. Coverage
includes asymmetric translated regions, explicit/repeated source fields and
destination field position, preservation outside the target, empty requests,
FND-002 zero reach, exact scale type/finiteness, late field/region/writability/
overlap/overflow atomic failures, and bounded reordered gather/compute/scatter.

The compiled tree is exactly multiply then subtract. With
`left=1`, `scale=1+2^-52`, and `right=1-2^-52`, the product rounds to one and
the result is exact `+0.0`; a fused operation would retain a value near
`2^-104`. Signed-zero fixtures cover positive/negative zero coefficients and
operands. `0*inf`, `inf-inf`, finite-input product overflow, and NaN propagation
follow the same two-operation IEEE classification/sign behavior as NumPy.

The current registered derived recipe `e - 0.5*rho` agrees bitwise. A bounded
`5x3x2` integration gathers fields in `[e,rho]` order, computes into a separate
one-field workspace, scatters every primary exactly once, and agrees bitwise
with direct NumPy/current arithmetic.

Independent audit ran 1,000 randomized finite translated-region cases and found
bitwise NumPy equality with complete source and non-target preservation. Review
also enforced exact Python-float/NumPy-float64 scalar types, finite-result error
scope, cancellation-aware relative metrics, finite-nonzero ULP scope, and exact
signed-zero/nonfinite handling. No remaining correctness, atomicity, allocation,
or benchmark finding remains.

## Runtime, Memory, And Fusion Trade-Off

The retained 15-repeat kernel measurements are:

| Slots | Spatial shape | Runtime | Mvalue/s | Effective GB/s | NumPy |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 16 | `8^3` | 23.42 us | 349.8 | 8.40 | 13.17 us |
| 128 | `8^3` | 79.21 us | 827.4 | 19.86 | 64.92 us |
| 16 | `16^3` | 77.04 us | 850.7 | 20.42 | 35.79 us |

Every case is bitwise equal with zero absolute, away-from-cancellation relative,
and finite-nonzero ULP error. Calls retain zero traced bytes and have a fixed
1,453-byte traced peak. Effective bandwidth counts two reads plus one write.

For 4,096 blocks with three `8^3` source fields:

| Capacity | Chunks | Managed workspace | Runtime | Mvalue/s | Traced peak |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 64 | 64 | 786,944 B | 6.658 ms | 315.0 | 5,552 B |
| 256 | 16 | 3,147,776 B | 4.360 ms | 480.9 | 2,864 B |
| 1,024 | 4 | 12,591,104 B | 4.158 ms | 504.3 | 2,256 B |

All capacities agree bitwise and report zero finite metrics. Whole-array NumPy
takes 3.864 ms (542.8 Mvalue/s) but uses a separate 16,777,216-byte product
temporary. The capacity-1,024 bounded path is within about 7% while preserving
explicit ownership and a smaller managed working set. In-place or fused backing
execution would complicate overlap and storage contracts for little observed
gain, so optimization stops at the separate path.
