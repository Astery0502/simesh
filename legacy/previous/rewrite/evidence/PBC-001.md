# PBC-001 Evidence

## Decomposition, Correctness, And Integration

PBC-001 is the second incremental HAL-002 Red refinement.  It owns one
explicit physical face/mode's coordinate and value meaning and owns no topology
eligibility, source block/slot, multi-axis order, or payload execution.
Independent review accepted the two operations as phases of one BoundaryMode
responsibility after safe layer arithmetic, scalar/return types, exception
taxonomy, exact IEEE behavior, and inline reuse were frozen.

Seven focused tests and all 189 accumulated rewrite tests pass.  Every face,
mode, and reflected layer agrees with an independent Python reference.
One thousand randomized coordinate/value cases agree exactly.  Tests include
valid reflection adjacent to `INT64_MAX`, excessive lower depth at
`INT64_MIN`, exact scalar-kind/range errors, read-only triplets, wrong sides,
and all face/mode codes.

Value evidence compares `uint64` bits for positive/negative finite values,
both signed zeros, both infinities, quiet NaNs, and signaling NaNs with payloads
and signs.  Identity retains every bit, antisymmetry toggles only the sign bit,
and no-inflow produces exact `+0.0` only for the disallowed strict sign on the
normal field.  Public operations return exact Python `int`/`float` values.

The production definitions are `cdef inline noexcept nogil` in
`_boundary_rules.pxd`.  Both HAL-001 and HAL-002 consume them directly inside
their existing Cython cell loops; their independent aggregate references remain
unchanged.  The focused aggregate fixture and complete HAL-001/HAL-002 suites
remain bitwise equal, including the documented noncommuting current divergence.
HAX-001 also consumes these rules through its own Cython translation unit,
proving the header is a real substitution boundary rather than local factoring.

## Performance And Allocation

Validated scalar entrypoints are descriptive rather than hot-loop timings.
With 10,000 calls and nine repeats, coordinate mapping is 4.20 us/call and
value transformation is 0.845 us/call.  A paired call retains zero traced bytes
with a fixed 1,053-byte traced peak.  Production consumers use the inline C
bodies, not these Python call boundaries.

Same-runner aggregate medians before and after extraction are:

| Workload | Before | After | Change |
| --- | ---: | ---: | ---: |
| HAL-001 `8/1/64`, all physical | 1.311 ms | 1.263 ms | -3.6% |
| HAL-001 `8/1/64`, mixed | 1.046 ms | 0.979 ms | -6.4% |
| HAL-001 `16/4/32`, all physical | 9.981 ms | 10.058 ms | +0.8% |
| HAL-002 `256/4/4`, kernel | 5.198 ms | 5.207 ms | +0.2% |
| HAL-002 `256/4/4`, composed | 14.491 ms | 14.996 ms | +3.5% |

All are below the 10% investigation threshold.  HAL-001 retains zero traced
bytes and a 1,565-byte peak; HAL-002 retains zero and a 1,584-byte peak.  No
payload, plan, or retained allocation was added.
