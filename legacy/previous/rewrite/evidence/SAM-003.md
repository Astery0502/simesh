# SAM-003 Evidence

## Correctness, Reach, And Composition

Nine focused tests and all 114 accumulated rewrite tests pass. Exact discrete
coverage includes canonical owner blocks, block-local left/right indices and
weights, exact native cell/block faces, reordered/repeated/partial/empty slots,
unowned-output preservation, input preservation, and atomic region/reach/map/
field/output/overlap failures.

The scalar reference fixes four z blends, two y blends, and one x blend with all
eight loads. Compiled results agree bitwise in the retained scalar and bounded
fixtures. Independent audit checked 400 randomized finite cases with asymmetric
padding, reordered/repeated/partial owners, and arbitrary finite stencil values;
every result agreed bitwise and no kernel, atomicity, reach, allocation, or
performance defect was found.

One lower and one upper valid cell per axis is both sufficient and necessary.
A zero-weight test poisons the nominally unused upper corner with NaN and obtains
NaN, proving that all eight values are read. First-layer physical interpolation
for continuous, symmetric, antisymmetric, and no-inflow modes yields
`[2.0, 2.0, 1.0, 1.5]` in the retained lower-face fixture.

The full bounded path plans complete halo closure, gathers all selected
interiors, applies HAL-001 and HAL-002, and samples only the primary prefix.
Capacity-27 traversal over a `3^3` root is bitwise equal to the independent
full-payload scalar result, including reordered fields. Support halos are never
sampled.

Affine fields satisfy the local `64*eps*scale` bound. The retained smooth-field
sequence at 12, 24, and 48 cells per axis has observed L-infinity orders above
2.1 (the regression floor is 1.8), establishing second-order behavior. A
GEO-valid coincident-center case returns `[15,15]` from source `[10,20]`; the
outer-collapsed large-origin case is rejected consistently with SAM-002.

## Current Comparison

Current and rewrite outputs are identical for dyadic coarse/native affine
cases. Fine and non-dyadic subdomain cases differ only by the canonical GEO
versus current-rnode weight arithmetic: across the retained benchmark, maximum
absolute error is at most `4.27e-14`, maximum relative error is at most
`5.42e-16`, and maximum ULP distance is 3. These are within the declared local
affine bound.

At exact block faces, current visits both blocks and retains its OpenMP write
overlap; completed sibling halos normally make both interpolated values equal,
whereas SAM-003 writes once through SAM-002 ownership. Current comparisons use
continuous commuting halos, so HAL-002's separately documented noncommuting
physical-boundary difference is not conflated with interpolation error.

Direct calls retain 64 traced bytes with a fixed 3,080-byte peak. The rewrite
is slower than the current OpenMP-capable kernel because it enforces unique
ownership and separately rounded, noncontracted IEEE operations; it does not
trade those semantics for timing.

For the four-field fine subdomain composition, capacity 64 uses ten chunks,
2,048,512 managed bytes, and 36.735 ms (36.1 Msamples/s); capacity 256 uses one
chunk, 8,194,048 bytes, and 28.351 ms (46.8 Msamples/s). Both are bitwise equal
to full sampling with zero absolute/ULP difference. Traced peaks are 4,616 and
3,536 bytes. A small scalar reference takes 5.118 ms versus 70.3 us compiled,
a 72.8x speedup with zero absolute/ULP difference.

The retained kernel already uses the optimized SAM-002 owner and hoists
per-coordinate work outside fields. Cached coordinate arrays would violate the
fixed-scratch goal; zero-weight skipping and FMA contraction violate numerical
semantics; parallel/fused variants require executor evidence. Optimization
therefore stops at the useful serial bounded path.
