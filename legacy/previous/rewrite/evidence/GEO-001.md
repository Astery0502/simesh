# GEO-001 Evidence

## Correctness And Numerical Behavior

Seven focused tests and all 54 accumulated rewrite tests pass. Selected block
IDs preserve arbitrary slot order, duplicates, and empty selections. Cython
outputs agree with an independent exact-rational reference within the
contracted bounds. Exact invariants establish positive global spacing, supplied
domain endpoints, bit-identical TOP sibling faces, selected MOR inverse
consistency, and partition-independent global-index center reconstruction.

The numerical boundary rejects non-finite/reversed bounds, nonpositive or
indivisible counts, subnormal spacing, outer cell centers that collapse onto a
domain face, selected collapsed block bounds, invalid IDs/maps, layout/dtype/
writability errors, and overlap before output mutation. Regressions cover
subnormal accumulation, a selected block that would otherwise lie outside its
domain, and the exact `n-1` center operation order above `2^53`. Independent
review found no remaining issue.

For the asymmetric current comparison `(root, block) = ((3,2,5),(4,6,8))`,
rewrite spacing equals every current spacing exactly. Bound differences are at
most one ulp and

```text
max absolute difference by axis = (0, 4.44e-16, 8.88e-16)
max difference / cell spacing   = 3.74e-15
```

Current neighboring faces and its final endpoint miss by up to `8.88e-16`.
The rewrite has zero bit mismatches across every sibling face and exact supplied
endpoints, which is the reason for intentionally not preserving current
operation order.

## Runtime, Throughput, And Memory

The benchmark uses a 1,392,047-block root grid and sparse selected IDs, with 15
repetitions of the checked caller-buffer operation.

| Selected slots | Checked time | Mblocks/s | Bounds bytes |
| ---: | ---: | ---: | ---: |
| 1 | 25.5 us | 0.04 | 48 |
| 8 | 23.5 us | 0.34 | 384 |
| 64 | 24.8 us | 2.58 | 3,072 |
| 512 | 31.6 us | 16.2 | 24,576 |
| 4,096 | 89.8 us | 45.6 | 196,608 |
| 65,536 | 4.753 ms | 13.8 | 3,145,728 |
| 1,392,047 | 126.26 ms | 11.0 | 66,818,256 |

The fixed Python boundary dominates tiny selections. At full sparse selection,
map/geometry validation takes 83.74 ms and fill takes 42.19 ms; both use no
selection-sized scratch. Raw pointers improved the validated memoryview baseline
from 145.43 to 126.26 ms, a modest 15% gain. Further optimization belongs in a
composed source/executor path where ID order and geometry reuse are known.

`tracemalloc` reports a fixed 2,104-byte peak and 64-byte retained increase from
one through all slots. A 4,096-block chunk uses 196,608 bytes of bounds instead
of the 66,818,256-byte full table, while one spacing triplet avoids another
98,304 bytes for that chunk and 33,409,128 bytes at full size. This validates
the selected-only surface; an implicit full-N API or materialized center arrays
would add memory without new semantics.

Benchmark command:

```text
PYTHONPATH=rewrite/src:src .venv/bin/python rewrite/benchmarks/geo_001.py --repeats 15
```
