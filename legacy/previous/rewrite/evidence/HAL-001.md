# HAL-001 Evidence

## Correctness

Five focused tests and all 74 accumulated rewrite tests pass. Continuous,
symmetric, antisymmetric, and no-inflow layers match the independent direct-cell
reference bitwise. Mixed x/y/z edge and corner composition preserves signed-zero
order, no-inflow on nonnormal rows is continuous, interiors remain bitwise
unchanged, and cells outside each physical envelope retain their sentinel bits.

The all-physical `(4,6,8)` block with halo width three, four fields, mixed modes
on every face, and normal slots `(1,2,3)` matches the current Cython mesh over
the complete padded payload through `uint64` views. Independent review also ran
250 randomized asymmetric TOP-valid cases and four focused current tests with
no discrepancy.

Validation rejects bad modes, missing no-inflow normal metadata, out-of-range
IDs/normal slots, read-only payloads, and reflected depths beyond the interior
before mutation. Per-slot physical envelopes and their common FND intersection
are exact, including mixed physical/sibling blocks.

## Runtime, Throughput, And Allocation

Final checked measurements use nine repetitions and mixed boundary modes.

| Block/halo/slots | Physical signature | Produced values | Time | Mvalue/s |
| --- | --- | ---: | ---: | ---: |
| `8/1/64` | all faces | 124,928 | 1.250 ms | 100.0 |
| `8/1/64` | mixed | 74,528 | 0.983 ms | 75.8 |
| `8/2/64` | all faces | 311,296 | 2.597 ms | 119.9 |
| `8/2/64` | mixed | 166,144 | 1.741 ms | 95.4 |
| `16/2/32` | all faces | 499,712 | 4.415 ms | 113.2 |
| `16/4/32` | all faces | 1,245,184 | 9.736 ms | 127.9 |
| `32/2/8` | all faces | 444,416 | 5.163 ms | 86.1 |
| `32/2/8` | mixed | 299,264 | 4.492 ms | 66.6 |

The direct kernel visits allocated cells and writes each produced physical cell
once. Performance scales with produced volume and mixed blocks pay predictable
classification overhead. Checked/unchecked gaps are small once payload work is
material. Standard cases retain zero traced bytes with a fixed 1,565-byte peak.

Initial vectorized metadata validation and advanced-index intersection allocated
about one byte per selected slot and took 8.02 seconds at one million repeated
IDs. Streaming validation plus a Cython common-region scan reduced the same
probe to 9.62 ms, a 2,336-byte peak, and 912 retained bytes. No slot-, field-,
or payload-sized scratch remains.

A separate face-sweep/fused-sibling implementation is not retained: the current
direct rule is correct, allocation-free, and already exceeds roughly 100 million
produced values/s in representative cases. HAL-002 is the first place where a
fused physical/sibling sweep can improve composed transfers rather than only
this isolated kernel.

PBC-001 decomposition now owns the per-axis coordinate and value rules through
shared Cython inline functions.  HAL-001 still owns physical eligibility,
multi-axis x/y/z composition, payload mutation, and produced validity.  Its
independent aggregate reference remains unchanged and bitwise equal; selected
before/after medians range from 6.4% faster to 0.8% slower with identical
allocation.  See `evidence/PBC-001.md`.
