# PWA-001 Contract: Cartesian Physical Widening Application

## Responsibility

PWA-001 fills explicit physical and mixed-physical target boxes from already
valid base boxes in one canonical payload slot.  It applies PBC-001 coordinate
and binary64 value semantics in fixed x/y/z order.  It defines no face
discovery, topology, support, source transfer, base validity production,
workspace allocation, backend, scheduling, periodicity, or 2D behavior.

## Stable Operation

```text
apply_cartesian_physical_widening(
    payload, target_slot,
    logical_interior_lower, logical_interior_upper,
    storage_logical_offsets,
    directions, physical_masks,
    base_lower, base_upper,
    target_lower, target_upper,
    boundary_modes, normal_field_slots,
) -> None
```

`payload` is caller-owned writable C-contiguous
`float64[S,F,sx,sy,sz]`.  `target_slot` is in `[0,S)`.  Every row array has
shape `(R,3)` and native-endian C-contiguous `int64`, except
`physical_masks uint8[R]`.  `boundary_modes uint8[F,6]` and
`normal_field_slots int64[3]` have PBC/HAL meanings.  Inputs are borrowed,
read-only or writable, and retained nowhere.

For row `r`, storage coordinate `q` maps to logical coordinate
`q + storage_logical_offsets[r]`.  The logical interior is nonnegative and
nonempty.  The base and target are ordered storage-contained boxes.  The mask
is nonzero, uses bits zero through two, and marks only nonzero components of a
valid direction.

On a masked axis the complete logical target interval is immediately outside
the logical interior on the direction's lower or upper side.  On an unmasked
axis the target interval is contained in the base.  For every field, mapping
all masked target axes with that face's PBC-001 coordinate rule and translating
back to storage yields an image contained in the complete base rectangle.
Symmetric/antisymmetric target depth may not exceed logical interior extent.
Precisely, a lower masked row has
`target_upper+offset==logical_interior_lower`; an upper row has
`target_lower+offset==logical_interior_upper`.  These anchoring rules are still
validated for a zero-width target.  Logical interiors and bases are nonempty;
target boxes may be empty.

## Exact Application

For every row, field, and target cell, set unmasked source coordinates to the
target coordinate.  For each masked axis, translate target to logical space,
apply `physical_halo_source_index` using the row's true logical interior and
face `2*axis + (direction>0)`, then translate the source back to storage.  Read
that one `payload[target_slot,field,...]` base value.  Apply
`transform_physical_halo_value` for masked axes in ascending x, y, z order and
write `payload[target_slot,field,target]`.

Target boxes are pairwise disjoint.  Every target box is disjoint from every
base box in the batch; bases may overlap or repeat.  Thus every target is
written exactly once, no source is overwritten, and row traversal order is not
semantic.  Empty `R`, `F`, or spatial target boxes are valid no-ops after
ordinary representation, slot, logical/base/target ordering, direction/mask/
side, alias, and boundary-table validation.  For a spatially empty row the
mapped-image and reflection-depth checks are vacuous.  With `F=0`, every normal
slot is `-1`, and mapped-image/value-mode checks are vacuous.

## Validation, Exactness, And Performance

Before mutation validate scalar/array representations, target slot, row
shapes, logical boxes and translated arithmetic, directions/masks/sides,
storage boxes, mode/normal metadata, reflection depth, complete mapped-image
containment, pairwise target disjointness, target/base RAW safety, payload/
metadata nonoverlap, and writable payload.  Wrong scalar/array/dtype kinds
raise `TypeError`; invalid range/shape/layout/box/mask/mode/normal/overlap/image
raises `ValueError`; signed translation overflow raises `OverflowError`.  Every
failure preserves the complete payload.

Normal entries are `-1` or local positions in `[0,F)`.  As in HAL/HAX, if any
field row anywhere in the supplied boundary table uses no-inflow on axis `a`,
`normal_field_slots[a]` must be valid.  Forward translation
`logical_target=storage_target+offset` and reverse translation
`storage_source=logical_source-offset` are evaluated as mathematical integers;
an unrepresentable result raises `OverflowError`.  Excess reflected depth
raises `ValueError` before mapped-image containment, and an otherwise mapped
image outside the base raises `ValueError`.

Copies and PBC transforms are bit exact, including signed zero, infinities, and
NaN payloads.  The independent reference uses Python integer mapping and the
independent PBC scalar reference.  Evidence covers all faces/modes/depths,
one/two/three-axis composition, noncommuting no-inflow/antisymmetry, translated
CWP frames, primary SAME/FINER/COARSER bases, preservation, and atomic errors.

The unchecked Cython kernel allocates no scratch and performs one read and one
write per produced field-cell plus fixed coordinate/value work.  PWA is a hot
kernel.  Its standard gate records written field-cells/s, effective payload
bytes, checked/unchecked and reference ratios, halo/field/row scaling, exact
bits, and immediate CWA/RHE runtime.  A reproducible median regression above
10% is investigated and above 20% in two representative cases blocks complete
unless a documented material I/O/memory benefit justifies it.

The standard kernel case uses one slot, four fields, a nonsymmetric interior,
all six faces plus mixed edges/corners, two halo layers, and continuous,
symmetric, antisymmetric, and no-inflow rows including noncommuting transforms.
The independent direct-cell reference establishes semantics.  HAL-001 on the
pure-physical case and HAX-001 on an equivalent mixed plan are the two compiled
throughput comparators.  The hypothesis is that allocation-free unchecked PWA
has no more than 20% median per-written-cell regression versus the corresponding
comparator in either stable case.  Candidate and written field-cell counts are
exactly equal, and semantic payload traffic is `16*written_field_cells` bytes.
Correct bits and zero size-dependent allocation are hard gates; the ordinary
10% investigate and reproduced 20% block policy applies.

## Immediate Composition

CWA supplies CSP-completed coarse bases and uses PWA before PRL.  RHE supplies
fully assembled reduced-direction primary bases and uses PWA only after every
SAME/FINER/COARSER base action, producing complete physical/mixed targets.
