# ROI-001 Contract: Refined Cell-Center Physical-Region Windows

## Responsibility

ROI-001 maps one contained half-open Cartesian physical box to the exact
canonical refined leaf IDs and leaf-local cell windows whose cell centers lie
inside it. It defines no leaf-volume overlap, clipping, payload, field,
spacing/bounds output, support, halo, operator, reduction, scheduling, cache, or
dataset behavior.

## Stable Operations And Result

```text
count_refined_region_windows(
    domain_lower, domain_upper,
    root_shape, domain_cell_counts, block_cell_counts,
    node_levels, node_coords, leaf_node_ids,
    region_lower, region_upper,
) -> selected_count

fill_refined_region_windows(
    ...same inputs...,
    leaf_ids, cell_lower, cell_upper,
) -> None

refined_region_windows(...same inputs...) -> RefinedRegionSelection
```

Domain/count and FST arrays are borrowed unchanged from the FST-002/GEO-002
lifecycle. They have GEO-002's native C-contiguous representations and exact
`domain_cell_counts == root_shape * block_cell_counts` compatibility.
`region_lower` and `region_upper` are borrowed finite C-contiguous `float64[3]`,
satisfy

```text
domain_lower <= region_lower <= region_upper <= domain_upper,
```

and are not clipped. Equality on any region axis defines an empty region.

For selected count `S`, outputs are caller-owned writable C-contiguous
`leaf_ids int64[S]`, `cell_lower int64[S,3]`, and
`cell_upper int64[S,3]`. They may not overlap inputs or one another. Success
fully overwrites every output, mutates no input, and retains nothing. The
allocating helper returns the three arrays in a frozen `RefinedRegionSelection`
tuple. Output storage is exactly `56*S` bytes.

## Canonical Center And Membership

For leaf node level `ell`, coordinate `c`, axis `a`, local cell `i`, and
`shift=ell-1`, evaluate separately in binary64:

```text
base_h[a] = (domain_upper[a] - domain_lower[a])
            / float(domain_cell_counts[a])
h[a]      = ldexp(base_h[a], -shift)
g         = c[a] * block_cell_counts[a] + i
factor    = float(g) + 0.5
offset    = factor * h[a]
center(i) = domain_lower[a] + offset
```

No accumulated stepping or fused multiply-add is permitted. A cell belongs to
the ROI exactly when, independently on every axis,

```text
region_lower[a] <= center(i) < region_upper[a].
```

Thus equality with the lower ROI face is included and equality with the upper
face is excluded. For each leaf/axis, the selected indices form one monotone
half-open local interval `[lower,upper)`, found by exact lower bounds over the
canonical center sequence. A leaf row is emitted iff all three intervals are
nonempty. Rows follow ascending canonical leaf ID; every emitted local box lies
within `[0,block_cell_counts)` and is nonempty.

ROI-001 validates each leaf's first and last center as finite, ordered, and
strictly inside its canonical GEO leaf faces. Internal centers may coincide as
representable binary64 values; lower-bound semantics still selects all matching
cell identities deterministically. A full-domain region emits every leaf with
the full `[0,B)` window.

## Validation, Errors, And Atomicity

The checked boundary validates exact ndarray types/dtypes/ranks/shapes/
C-contiguity, output writability/nonoverlap, finite/increasing domain bounds,
positive compatible counts, root/level/global-cell int64 arithmetic, normal
base/refined spacing, selected leaf-node access, canonical leaf faces/outer
centers, and contained ordered region bounds. Type/dtype failures raise
`TypeError`; invalid layouts, lifecycle shapes, bounds, counts, centers, or
outputs raise `ValueError`; unrepresentable integer arithmetic raises
`OverflowError`.

`fill` performs the complete validation/count pass and checks exact output
shapes/aliases before any output mutation, then repeats the scan to fill. All
ordinary failures preserve every output. FST/GEO semantic mutation after their
established lifecycle is a caller contract violation.

## Independent Evidence

All leaf IDs and cell windows compare exactly. The independent reference
exhaustively constructs every leaf/local canonical center and filters it under
the half-open inequalities; it does not call production lower-bound code.
Evidence includes full/empty/no-center/thin/single-cell/non-block-aligned and
multi-leaf regions; mixed levels and every child phase; nonsymmetric roots and
blocks; exact cell centers, leaf/domain faces and `nextafter` probes; strict
ascending IDs; exact union of reference cells; large origins/center collapse;
level/count overflow; nonfinite/outside/inverted regions; and output atomicity.

## Performance And Immediate Composition

The production implementation makes two compiled ascending full-leaf scans,
uses fixed scalar scratch and exact binary-search center bounds per axis, and
allocates only final output. Complexity is `O(L*sum(log B))`; no `O(L)` geometry
table or retained spatial index is built. ROI-001 is `cold/control`: record the
bound and output bytes here, then measure selection time and fraction of first
result in LFE-001 small/medium/full native workflows.

LFE-001 consumes rows directly as strict ascending RHE primaries and exact
output/reduction windows. Hierarchy pruning, a BVH, or retained region plans
reopen only when selection exceeds 10% of small-ROI first-result time or
repeated ROI evidence can amortize state.
