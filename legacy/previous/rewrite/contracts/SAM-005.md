# SAM-005 Contract: Refined Trilinear Point-Group Sampling

## Responsibility

SAM-005 evaluates the frozen Cartesian trilinear reconstruction for explicit
groups of points owned by completed refined primary workspaces. It owns axis
stencils, exact one-cell reach, eight loads, and the z/y/x blend tree. It does
not locate leaves, plan groups, infer/fill halos, choose PBC/topology, read
storage, cache payloads, schedule chunks, or advance streamlines.

## Stable Operation

```text
sample_refined_trilinear_point_groups(
    payload,
    payload_valid_lower,
    payload_valid_upper,
    interior_lower,
    interior_upper,
    slot_leaf_ids,
    domain_lower,
    domain_upper,
    domain_cell_counts,
    block_cell_counts,
    node_levels,
    node_coords,
    leaf_node_ids,
    points,
    point_indices,
    slot_point_offsets,
    point_values,
) -> None
```

Payload, geometry, forest, point/group, output, overlap, ordering, preservation,
and lifecycle representations are exactly SAM-004 except for reach. The
declared valid box must contain the interior expanded by one cell on every
lower and upper side. Payload values throughout that expanded box are a
semantic precondition and must be complete for each primary slot. The tight
FND-002 requirement is `LOCAL_STENCIL` with lower and upper reach exactly
`(1,1,1)`.

Every grouped point must be finite, inside LOC-001's half-open domain, and
owned by its corresponding slot leaf. Slot order/repetition and deterministic
overwrite behavior are exactly SAM-004. Empty slot, point, selection, and field
axes are accepted. Validation completes before output
mutation. Success writes only grouped result rows and preserves all other rows
bitwise; no input is changed and nothing is retained.

## Canonical Axis Stencil

For owner leaf level `ell`, coordinate `c`, axis `a`, and point `x`, derive
`h`, the level cell count, and the canonical block lower face with LOC/GEO
arithmetic:

```text
g0          = c[a] * block_cell_counts[a]
block_lower = face(g0)
delta       = x - block_lower
ratio       = delta / h
u           = ratio - 0.5
j0          = floor(u)
j1          = j0 + 1
w           = u - float(j0)
```

Each subtraction, division, conversion, and subtraction is separately rounded
binary64, with no fused operation or accumulated coordinate stepping. Complete
prevalidation establishes `-1 <= j0 <= B-1`, `0 <= j1 <= B`, finite
`0 <= w < 1`, and storage containment for every grouped point and axis. Some
GEO-valid large-origin point/leaf combinations can fail this later center/
stencil representability rule and are rejected before mutation; the sampler
does not clamp or silently choose another stencil.

Storage indices are `interior_lower[a] + j0/j1`. Exact equality with an
internal owner-leaf lower face gives `u=-0.5` and averages the lower halo with
the first interior cell. Points can approach but never equal the global upper
endpoint under LOC-001.

## Fixed Trilinear Arithmetic

For every grouped point and field, load all eight values even when a weight is
zero. With x/y/z side zero denoting `j0` and side one denoting `j1`, evaluate:

```text
c00 = v000*(1-wz) + v001*wz
c01 = v010*(1-wz) + v011*wz
c10 = v100*(1-wz) + v101*wz
c11 = v110*(1-wz) + v111*wz
c0  = c00*(1-wy) + c01*wy
c1  = c10*(1-wy) + c11*wy
out = c0 *(1-wx) + c1 *wx
```

Every subtraction, multiplication, and addition is separately rounded; the
implementation does not use `a + (b-a)*w`. Evaluation order is z, then y, then
x. Loading all corners freezes NaN, infinity, signed-zero, and zero-weight
behavior exactly as SAM-003.

## Validation, Errors, And Failure Semantics

SAM-005 validates every SAM-004 structural and owner condition; valid/interior
ordering and one-cell reach; and all selected stencil indices/weights before
writing any row. Type/dtype failures raise `TypeError`; invalid layout,
mapping, owner, geometry, reach, stencil, output, or overlap raises
`ValueError`; signed integer/index overflow raises `OverflowError`. Ordinary
failures preserve the complete output. A changed FST/GEO lifecycle or invalid
completed-halo value is a caller contract violation.

RPS-001 runs the checked group/stencil preflight for all unique owners and
points before its first nonempty read. Its synchronous RHE chunk consumer calls
only the unchecked sampler over already proved group slices; external reader or
consumer failures may leave earlier completed owner groups written.

## Numerical Evidence

Owner/group IDs and stencil indices compare exactly. Weights compare by exact
binary64 bits against the scalar operation-order reference. Finite outputs use

```text
64 * eps * max(1, max(abs(eight stencil values)), abs(reference output))
```

plus maximum absolute, relative-away-from-zero, and ULP reports. Affine fields
must satisfy that local bound, and smooth refinement retains SAM-003's observed
second-order behavior. Nonfinite results compare IEEE category, sign, and fixed
evaluation behavior.

Tests cover lower/upper leaf approaches, exact internal/coarse-fine faces,
edges and corners, every child phase, SAME/FINER/COARSER and pure/mixed
physical RHE halos, all four PBC modes, all-eight-load NaN cases, repeated
points/indices/fields, unselected-row preservation, and invalid last stencils.
On an all-level-one forest, exact SAM-003 output-center points and completed
halos must reduce bitwise to the retained fused wrapper. Safe dyadic non-tie
refined cases compare with current; current overlapping face windows and
rounded `rnode` differences are recorded rather than hidden by tolerance.

## Performance And Memory

The compiled kernel derives geometry once per slot, computes three stencils per
point, and performs eight loads plus seven blends per field. Its cost is
`O(S + Q*F)` with no payload-, point-, field-, group-, or output-sized scratch.

SAM-005 is `hot-kernel`. Measure single/batch point and field-value throughput,
field count, block extent, depth, owner reuse, fixed allocation, retained
SAM-003 ratio, and immediate completed-RHE composition. Shared inline
extraction must not materially regress SAM-003 under PERFORMANCE.md.

## Immediate Composition

LOC-001 plus explicit owner groups supplies identity; RHE-001 supplies complete
one-layer primary workspaces. A resident completed array is the reference
composition. RPS-001 samples each completed RHE primary prefix synchronously
before workspace reuse, without exposing reader/cache policy to SAM-005.
