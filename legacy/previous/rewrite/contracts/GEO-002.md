# GEO-002 Contract: Cartesian 3D Refined Leaf Bounds And Spacing

## Responsibility

GEO-002 maps selected canonical FST leaf IDs to Cartesian physical bounds and
per-leaf cell spacing using one explicit dyadic geometry rule.  It defines no
forest conformance, topology, balance, contact/cache representation, cell
centers, sample ownership, interpolation, payload, halo, storage, scheduling,
periodicity, or file/dataset metadata inference.

## Stable Operation

```text
fill_refined_leaf_geometry(
    domain_lower,
    domain_upper,
    root_shape,
    domain_cell_counts,
    block_cell_counts,
    node_levels,
    node_coords,
    leaf_node_ids,
    leaf_ids,
    leaf_bounds,
    leaf_cell_spacing,
) -> None
```

- Domain bounds are borrowed read-only native-endian C-contiguous
  `float64[3]`, finite, and strictly increasing componentwise.
- `root_shape`, `domain_cell_counts`, and `block_cell_counts` are borrowed
  read-only C-contiguous `int64[3]` and positive.  Their exact compatibility is
  `domain_cell_counts == root_shape * block_cell_counts`; every product and the
  root volume must fit signed `int64`.
- `node_levels`, `node_coords`, and `leaf_node_ids` are the borrowed read-only
  C-contiguous `int64[K]`, `int64[K,3]`, and `int64[L]` subset of one unchanged
  FST-002 artifact lifecycle established with the same `root_shape`.  GEO-002
  validates shapes needed for safe selected access but does not repeat forest
  conformance.
- `leaf_ids` is borrowed read-only C-contiguous `int64[S]`.  IDs may be empty,
  repeated, and in arbitrary order; output row `s` describes canonical leaf
  `leaf_ids[s]`.
- `leaf_bounds` is caller-owned writable C-contiguous `float64[S,2,3]`, with
  side zero lower and side one upper.
- `leaf_cell_spacing` is caller-owned writable C-contiguous `float64[S,3]`.
  Refined spacing is slot dependent and is not collapsed to one global triplet.

Inputs may overlap when their simultaneous values satisfy the contract.  The
two outputs may not overlap each other or any input.  Validation completes
before either output is mutated.  Successful execution fully defines both
outputs, changes no input, and retains nothing.  An allocating
`refined_leaf_geometry(...)` helper returns the same two arrays.

## Canonical Arithmetic

For axis `a`, compute the level-one spacing with the GEO-001 operation order:

```text
extent[a]       = domain_upper[a] - domain_lower[a]
base_spacing[a] = extent[a] / float(domain_cell_counts[a])
```

For selected leaf node level `ell`, coordinate `c[a]`, and exact
`shift = ell-1`:

```text
scale                 = 2**shift
level_domain_cells[a] = domain_cell_counts[a] * scale
spacing[a]            = ldexp(base_spacing[a], -shift)
g0[a]                  = c[a] * block_cell_counts[a]
g1[a]                  = g0[a] + block_cell_counts[a]
```

All integer quantities above must fit signed `int64`.  For a level-specific
global integer cell-face index `g`:

```text
face(0)                     = domain_lower[a]
face(level_domain_cells[a]) = domain_upper[a]
face(g)                     = domain_lower[a] + float(g) * spacing[a]
                              otherwise.
```

Conversion, multiplication, and addition in the interior expression are
separate binary64 operations in that order.  The selected lower/upper bounds
are `face(g0)` and `face(g1)`.  This reduces bitwise to GEO-001 at level one.
Dyadically equivalent face identities use doubled integer index and halved
normal spacing, so same-level and coarse/fine shared faces are bit-identical
across selections and calls.  Global outer faces equal the supplied bounds
exactly.

The base spacing and every selected spacing must be finite, positive, and
normal binary64.  Every selected bound must be finite and strictly ordered.
Numerical validity is selection scoped: a bounded workflow must preflight all
leaves it may process if it needs whole-artifact geometry validity.  GEO-002
does not define or validate cell-center representability; the later refined
center/owner/sampling boundary owns that independently variable decision.

## Validation, Errors, And Lifecycle

Exact ndarray type/dtype/rank/shape/C-contiguity and output writability are
checked before unchecked access.  Wrong types/dtypes raise `TypeError`.
Invalid bounds, nonpositive/incompatible counts, shapes, layouts, leaf IDs,
selected levels/coordinates, nonnormal spacing, collapsed bounds, or overlap
raise `ValueError`.  Root-volume, dyadic level-cell-count, or selected
cell-index overflow raises `OverflowError`.  All ordinary failures preserve
both outputs.

Semantic corruption of the FST subset after FST-002 is a caller contract
violation.  Any artifact mutation begins a new lifecycle and requires FST-002
again before GEO-002 or later unchecked consumers execute.

## Independent Evidence And Exactness

The independent reference converts supplied binary64 endpoints to exact
rationals and computes level spacing and faces without using production
integer/pointer traversal.  Production spacing agrees within `8*eps` relative
error.  Bounds use zero relative tolerance and per-axis absolute tolerance

```text
16*eps*max(abs(domain_lower), abs(domain_upper), domain_extent)
```

with a floor of sixteen times the smallest positive binary64 subnormal.
Discrete IDs/levels/coordinates, supplied endpoints, level-one GEO-001
reduction, and shared-face identity compare exactly.

Evidence includes reordered/repeated/empty selection; nonsymmetric roots and
mixed depths; every level and axis; level-one reduction; sibling and
coarse/fine faces; maximum representable depth; integer overflow; subnormal
spacing and large-origin bound collapse; nonmutation on late errors; synthetic
current comparison; and the representative real refined Cartesian 3D tree.
The real file's staggered header limits it to geometry metadata evidence.

## Performance And Memory

Validation and fill are `O(S)` with fixed Python/C metadata and no
selection-sized scratch.  Caller output is exactly `72*S` bytes.  Measure
selected leaves/s, fixed allocation, selection/depth scaling, FST-to-geometry
lifecycle, full real-tree time, current cached-table comparison, and exact
output bytes.  No implicit full-leaf table or center array is retained.

## Immediate Composition

FST-002 supplies canonical leaf identity and levels/coordinates.  Explicit
domain metadata supplies Cartesian extents and counts.  Refined transfer,
halo, operator, and sampling capabilities consume the plain selected bounds
and spacing arrays.  GEO-002 has no TOP-002, BAL-001, or TOP-003 dependency.
