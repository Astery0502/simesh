# MIG-001 Contract: Supported Feature Migration Ledger

## Responsibility

MIG-001 defines the source-wide migration unit, status, disposition, milestone
mapping, and final cutover gate. It prevents completion of the AMR core from
being confused with replacement of the supported `simesh` product surface. It
defines no numerical behavior or implementation API.

## Stable Rules

- Supported user-observable behavior is the migration unit; files, classes,
  methods, and source lines are not.
- Every canonical feature family records current authority, rewrite state,
  planned closure, parity/workflow evidence, and one closing disposition:
  rewrite, adapter, retain, replace, retire, or unsupported.
- Legacy/reference code is evidence and is not automatically ported.
- Synthetic lower-kernel completion does not close a public workflow; real
  data, format, failure, memory/performance, and integration evidence close the
  corresponding rows.
- M0--M3 own the AMR numerical axis. M4--M7 own operators/derived behavior,
  I/O/export, dataset/public API, packaging/parallelism, and cutover.

## Completion

The ledger itself is complete when the source-wide families and closure rules
are documented and linked from the durable workflow. Individual rows close as
their capabilities complete. Final cutover requires every row to have a closing
disposition and canonical public workflows to use the new implementation by
default with exercised fallback/rollback.
