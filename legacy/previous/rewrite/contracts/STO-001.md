# STO-001 Contract: In-Memory Block Source And Sink

## Responsibility

STO-001 transfers selected block/field data between resident canonical storage
and caller-owned canonical buffers. It defines no allocation budget, file I/O,
chunk planning, workspace lifetime, topology, geometry, halo value rule, or
operator behavior.

## Backing And Selection

Backing storage is native-endian C-contiguous `float64` with shape
`(nblock, nfield, sx, sy, sz)`. Backing row `b` is global block ID `b`; at M0
this is dense Morton order. Fields are zero-based backing-axis positions, not
names or file-header IDs.

`block_ids` and `field_ids` are borrowed read-only C-contiguous signed `int64`
vectors. They may be empty, repeated, and arbitrarily ordered. Gather repeats
selected data. Scatter traverses slot first and selected field second; when
selectors target the same backing block/field more than once, the later
lexicographic visit wins deterministically.

## Gather

```text
gather_blocks_into(
    backing,
    backing_valid_lower,
    backing_valid_upper,
    block_ids,
    field_ids,
    destination,
    destination_lower,
) -> None
```

Let `extent = backing_valid_upper - backing_valid_lower`. Destination has exact
prefix shape `(len(block_ids), len(field_ids))`. For every spatial offset
`0 <= q < extent`, gather defines

```text
destination[s, f, destination_lower + q] =
    backing[block_ids[s], field_ids[f], backing_valid_lower + q].
```

The resulting destination-valid box is exactly
`[destination_lower, destination_lower + extent)`. Only that box is mutated;
all other destination cells remain bitwise unchanged.

## Scatter

```text
scatter_blocks_from(
    source,
    source_valid_lower,
    source_valid_upper,
    block_ids,
    field_ids,
    backing,
    backing_lower,
) -> None
```

Source has exact prefix shape `(len(block_ids), len(field_ids))`. With
`extent = source_valid_upper - source_valid_lower`, scatter defines

```text
backing[block_ids[s], field_ids[f], backing_lower + q] =
    source[s, f, source_valid_lower + q].
```

Only the selected Cartesian product and translated spatial box may change.
Valid-region metadata remains explicit caller state; STO-001 does not silently
widen backing validity after a write.

## Validation, Ownership, And Empty Requests

All payloads are rank-five native `float64` C-contiguous arrays. Spatial regions
and translated lowers are FND-001 C-contiguous `int64[3]` triplets. Regions are
half-open, ordered, nonnegative, and contained in the source spatial shape; the
translated box must fit the output spatial shape without signed overflow.

Gather backing and scatter source are borrowed read-only. Gather destination
and scatter backing are exclusively borrowed writable. Inputs, selector/region
metadata, and the mutated output may not overlap; read-only inputs may overlap
one another. Arrays and pointers are never retained.

Every selector is range-checked before mutation, even if another selector or
the spatial box is empty. After complete validation, an empty block selection,
field selection, or spatial box is a no-op. Invalid calls leave the output
unchanged. Type/dtype errors raise `TypeError`; shape, layout, bounds, range,
writability, or overlap errors raise `ValueError`; unrepresentable region
translation raises `OverflowError`.

## Valid Regions And Exactness

The source valid box is the transferred box. Callers may conservatively expose
only an interior even when more halo cells are valid. A common box applies to
all selected block/field pairs, matching FND-001; fields with different validity
are transferred separately or through their intersection.

No floating-point arithmetic occurs. Every selected binary64 representation,
including signed zero, infinities, and NaN payload bits, is copied exactly.
Placement, duplicate order, input preservation, and preservation outside the
target are exact; no tolerance applies.

## Performance And Memory

Validation is `O(len(block_ids) + len(field_ids))`. Copy cost is proportional
to selected pairs times transferred cells. General copies use contiguous-z
rows; complete contiguous y/z suffixes use larger x-plane or x-slab `memcpy`
operations. No payload or selection-sized scratch is allocated. Parallel
scaling is not relevant to the deterministic serial primitive.

## Immediate Composition

Current level-1 SFC arrays feed backing storage directly. STO-002 adds bounded
selection/workspace policy over these operations. SAM capabilities gather
selected fields, while OPR capabilities gather, compute into explicit outputs,
and scatter without changing STO-001 semantics.
