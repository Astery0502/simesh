# SAM-003 Contract: Trilinear Level-1 Sampling

## Responsibility

SAM-003 samples Cartesian output cell centers by trilinear interpolation from
completed level-1 primary workspaces. It consumes valid physical and sibling
halo values but does not infer or fill them. It defines no allocation, field
selection, topology, boundary modes, refinement, exterior fill, 2D behavior, or
chunk planning.

## Stable Operation

```text
sample_level1_trilinear(
    payload,
    payload_valid_lower,
    payload_valid_upper,
    interior_lower,
    interior_upper,
    block_ids,
    domain_lower,
    domain_upper,
    domain_cell_counts,
    block_cell_counts,
    coord_to_rank,
    rank_to_coord,
    sample_lower,
    sample_upper,
    uniform_grid,
) -> None
```

- `payload` is borrowed read-only C-contiguous
  `float64[nslot,nfield,sx,sy,sz]` containing completed primary slots only.
- Its borrowed valid/interior bounds are C-contiguous `int64[3]` boxes. The
  interior extent equals `block_cell_counts`; the declared valid box contains
  the interior expanded by one cell on every lower and upper side.
- `block_ids` is borrowed C-contiguous `int64[nslot]`; arbitrary order and
  repeats are allowed.
- Domain/count/map/sample/output inputs have the exact SAM-002 representations,
  including contained sample bounds and positive field-first output shape.

Payload and metadata may not overlap the output. Read-only inputs may overlap
one another. Nothing is retained. Payload values throughout the declared valid
box are a semantic precondition; ordinary bounded composition passes only
HAL-002's completed primary prefix, never support slots.

## Output Centers And Unique Owner

Output center construction, canonical native faces, highest-face native-cell
ownership, block ownership, coincident-face behavior, and sample/domain
representability are exactly SAM-002. Thus distinct selected IDs own disjoint
output cells and exact block-face centers belong only to the upper block.

For one owned output center `x` on axis `a`, let the owner block coordinate be
`c`, `B=block_cell_counts[a]`, `h` be GEO's native spacing, and
`block_lower=face(c*B)`. Evaluate each operation separately in binary64, with no
fused multiply-add or accumulated stepping:

```text
delta = x - block_lower
ratio = delta / h
u     = ratio - 0.5
j0    = floor(u)
j1    = j0 + 1
w     = u - float(j0)
```

Storage coordinates are `interior_lower[a] + j0` and
`interior_lower[a] + j1`. Complete prevalidation establishes
`-1 <= j0 <= B-1`, `0 <= j1 <= B`, and finite `0 <= w < 1` for every selected
owned range. At an exact ordinary block face the upper owner has `u=-0.5`, so
it averages its lower sibling halo and first interior cell.

## Fixed Trilinear Arithmetic

Every output and field loads all eight stencil values, including zero-weight
corners. Let `vxyz` use x/y/z side zero for `j0` and one for `j1`. The exact
operation tree is:

```text
c00 = v000*(1-wz) + v001*wz
c01 = v010*(1-wz) + v011*wz
c10 = v100*(1-wz) + v101*wz
c11 = v110*(1-wz) + v111*wz
c0  = c00*(1-wy) + c01*wy
c1  = c10*(1-wy) + c11*wy
out = c0 *(1-wx) + c1 *wx
```

Each subtraction, multiplication, and addition is separately rounded binary64;
the implementation does not rewrite a blend as `a + (b-a)*w`. Evaluation is z,
then y, then x. Loading all corners means NaN/Inf behavior and the required halo
do not depend on whether a weight happens to be zero.

## Reach, Mutation, And Bounded Composition

The tight FND-002 access requirement is `LOCAL_STENCIL` with both lower and
upper reach exactly `(1,1,1)`. HAL-001 supplies physical first-layer values and
HAL-002 supplies sibling/mixed values.

Slots are visited ascending. A slot writes exactly the output cells canonically
owned by its block ID. Distinct IDs are disjoint; a repeated ID writes the same
cells again and the later slot wins. Unselected-owner output cells are bitwise
preserved. A complete bounded path is:

```text
HCL-001 full-halo plan
-> STO-001 gather all selected interiors
-> HAL-001 physical fill
-> HAL-002 same-level fill
-> SAM-003 on payload[:primary_count] and IDs[:primary_count].
```

Successive primary chunks define the complete output exactly once.

## Validation And Atomicity

Before mutation, validate all SAM-002 types/layouts/counts/maps/domain/sample/
output/nonoverlap conditions; valid and interior box ordering/containment;
interior extent; one-cell lower/upper valid reach; and selected endpoint stencil
indices/weights. For each selected block/axis with an owned output interval,
checking its first and last output indices proves the monotone index bounds;
fractional weights are checked explicitly. No full topology or output rescan is
performed.

Empty slot or field axes are validated no-ops. Invalid calls leave output
unchanged. Type/dtype failures raise `TypeError`; invalid layout, region,
geometry, map, selector, sampling box, stencil, output, or overlap raises
`ValueError`; unrepresentable volumes raise `OverflowError`.

SAM-003 inherits SAM-002's rejection of exterior sample bounds and outer-center
collapsed grids. GEO-valid coincident internal faces remain accepted when the
selected endpoint stencils satisfy this contract.

## Numerical Evidence

Owner IDs, output ranges, stencil indices, duplicate order, and preserved cells
are discrete and compare exactly. For finite interpolation values, comparisons
report maximum absolute error, relative error away from zero, and maximum ULP
distance. The scalar reference and affine tests use the bound

```text
64 * eps * max(1, max(abs(eight stencil values)), abs(reference output)).
```

Affine fields reproduce within that local bound; smooth-field refinement shows
approximately second-order L-infinity convergence, with observed order at least
1.8 on the retained sequence. Nonfinite tests compare IEEE classification,
sign, and the fixed evaluation behavior rather than applying a tolerance.

Current comparisons use the same metrics where canonical owner and halo
semantics agree. Evidence separately records differences from current rnode
rounding, its overlapping/OpenMP block-face windows, and HAL-002's documented
noncommuting mixed-boundary ordering; these discrete causes are not hidden by a
wider floating tolerance.

## Performance And Memory

The block-centric Cython path reuses SAM-002 owner ranges, computes axis
indices/weights once per output coordinate, and performs eight loads and seven
fixed blends per field. No payload-, output-, map-, selection-, or resolution-
sized scratch is allocated. Measure samples/s, field and up/down/native scaling,
allocation, current runtime, and the composed gather/halo/sample path before
considering parallel, cached-coordinate, or fused halo/sampling variants.

## Immediate Composition

GEO/SAM-002 supply geometry and unique ownership; HCL-001/STO-001/HAL-001/
HAL-002 supply bounded completed primaries. INT-001 consumes the bounded
trilinear path, and the `(1,1,1)` reach also informs OPR-002 executor checks.
