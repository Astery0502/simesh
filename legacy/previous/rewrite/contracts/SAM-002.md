# SAM-002 Contract: Zero-Order Level-1 Sampling

## Responsibility

SAM-002 samples Cartesian output cell centers from piecewise-constant level-1
source cells. It assigns every requested center to one canonical source cell
and lets bounded primary chunks write disjoint output ownership regions. It
defines no allocation, field selection, halos, interpolation, refinement,
exterior fill, 2D behavior, or physical-coordinate data structure.

## Stable Operation

```text
sample_level1_zero_order(
    payload,
    payload_valid_lower,
    payload_valid_upper,
    block_ids,
    domain_lower,
    domain_upper,
    domain_cell_counts,
    block_cell_counts,
    coord_to_rank,
    rank_to_coord,
    sample_lower,
    sample_upper,
    uniform_grid,
) -> None
```

- `payload` is borrowed read-only C-contiguous
  `float64[nslot,nfield,sx,sy,sz]`.
- Its borrowed `int64[3]` valid box is contained and has extent exactly
  `block_cell_counts`; allocated halos are ignored.
- `block_ids` is borrowed C-contiguous `int64[nslot]`; arbitrary order and
  repeats are allowed.
- Domain/sample bounds are borrowed finite C-contiguous `float64[3]` triplets.
  Both are strictly increasing, and the closed sample bounds are contained in
  the domain bounds.
- Domain/block cell counts and MOR maps have their GEO-001 representations.
- `uniform_grid` is caller-owned writable C-contiguous
  `float64[nfield,nx,ny,nz]`. Its field count equals the payload field count,
  and all three inferred output counts are positive.

Payload and metadata may not overlap the output. Read-only inputs may overlap
one another. Nothing is retained.

## Canonical Centers And Ownership

All listed operations are separate binary64 operations in the written order;
implementations do not use accumulated coordinate stepping or fused multiply-
add. For axis `a`, let `N=domain_cell_counts[a]` and `M=uniform_grid.shape[a+1]`:

```text
h_native = (domain_upper[a] - domain_lower[a]) / float(N)
h_output = (sample_upper[a] - sample_lower[a]) / float(M)
center(p) = sample_lower[a] + (float(p) + 0.5) * h_output
```

The canonical native face is GEO-001's function:

```text
face(0) = domain_lower[a]
face(N) = domain_upper[a]
face(g) = domain_lower[a] + float(g) * h_native otherwise.
```

The source global cell index is

```text
g(p) = max { g in [0,N-1] : face(g) <= center(p) }.
```

Validated centers are strictly inside the domain, so the set is nonempty and
`g(p)` is defined. Exact equality with an interior cell or block face belongs
to the upper cell. If several representable faces coincide, the highest such
index wins deterministically.

Then, exactly in integer arithmetic,

```text
block_coordinate[a] = g(p) // block_cell_counts[a]
local_index[a]       = g(p) %  block_cell_counts[a]
owner_id             = coord_to_rank[block_coordinate]
```

For output index triplet `p`, slot `s` writes only when
`block_ids[s] == owner_id`:

```text
uniform_grid[f,p] =
    payload[s,f,payload_valid_lower + local_index].
```

## Mutation And Bounded Composition

Slots are visited in ascending order. Distinct valid block IDs own disjoint
output cells independent of selection/chunk order. If an ID repeats, the later
slot overwrites the same owned cells and wins deterministically. Output cells
owned by no selected ID are bitwise preserved.

One call therefore defines the union of its selected ownership regions. A
complete STO-002 no-closure traversal passes only each primary prefix and
defines the entire output exactly once. Support blocks and halos are not
required.

A full-domain native-resolution request is identical to SAM-001 only when every
nominal native center `center(g)` satisfies
`face(g) <= center(g) < face(g+1)` in binary64. GEO's fixed outer-center checks
do not prove that condition for all internal cells. A production SAM-001 fast
path therefore requires an explicit exact `O(sum(domain_cell_counts))`, no-
scratch owner check that may be amortized outside chunk calls; ordinary SAM-002
validation alone never authorizes the dispatch.

## Validation And Atomicity

Before mutation, validate exact ndarray types/dtypes, ranks, shapes,
C-contiguity, output writability/non-overlap, payload/ID prefix, nonempty source
box and exact extent, finite/increasing domain bounds, positive/divisible counts
and signed volumes, MOR map shapes, every selected ID/coordinate/inverse,
GEO-001 normal native spacing/representability and selected block-face ordering,
finite/increasing/contained sample bounds, positive output counts, and finite
positive normal output spacing. The first and last output centers must be
finite and strictly inside the requested bounds and domain. Full MOR ordering
is an upstream precondition and is not rescanned for each chunk.

Empty slot or field axes are validated no-ops. Invalid calls leave output
unchanged. Type/dtype failures raise `TypeError`; invalid layout, region,
geometry, map, selector, sampling box, output, or overlap raises `ValueError`;
unrepresentable volumes raise `OverflowError`.

Sample bounds outside the domain are rejected rather than defining an exterior
fill rule. Output grids whose outer centers collapse are rejected. Source grids
that fail GEO-001's outer representability checks are rejected, but coincident
internal native faces that still satisfy GEO are accepted; the highest-face
rule resolves them without an out-of-bounds or history-dependent read.

## Exactness And Current Evidence

Values are copied without floating-point arithmetic, preserving every binary64
bit pattern. Output centers, owner cells/blocks, local indices, duplicate order,
and preserved regions are exact contract artifacts; comparisons use integer
owner maps and `uint64` value views with no tolerance.

The output-center operation order matches current zero-order sampling, and
ordinary in-domain owner maps compare exactly. Current block windows overlap
when a center lies exactly on a shared block face: the lower block can read one
cell past its extent while the upper block also writes, becoming an OpenMP race.
SAM-002 intentionally makes the intended upper owner unique. Retained evidence
covers exact cell/block-face centers, coarse/fine/native resolutions,
subdomains, safe large origins, the GEO-valid native/SAM-001 counterexample,
and explicit rejection of current outer-center garbage behavior and exterior
untouched cells.

## Performance And Memory

The Python reference locates each output cell globally. The Cython path is
block-centric: binary searches find each selected block's Cartesian output
index ranges, then the same canonical owner function supplies local indices.
Each selected-owned output value is written once. No payload-, output-, map-,
selection-, or resolution-sized scratch is allocated.

Measure sampled-value throughput, effective bandwidth, up/down/native ratios,
subdomain coverage, field/slot/chunk scaling, reorder/duplicate behavior,
allocation, current runtime, and composed plan/gather/sample execution. A
SAM-001 native fast path is optional only when its owner-proof scan can be
amortized and materially improves the composed trade-off. Parallelize only
after duplicate-free disjoint traversal is justified.

## Immediate Composition

GEO-001 supplies canonical source faces, MOR/TOP supply exact owner IDs,
STO-001 supplies selected fields/interiors, and STO-002 supplies bounded primary
chunks. SAM-001 supplies an exact native comparator and conditionally proven
fast path. INT-001 consumes the bounded general sampler.
