# CSP-001 Contract: COARSER Slope-Support Plan

## Responsibility And Scope

CSP-001 maps one nonempty CWP-001 row to a complete bounded plan for assembling
its rectangular PRL workspace before any payload read.  It owns support tiling,
source scale/slot placement, physical base placement, and plan representation.
It owns no support union/capacity, values, numerical transfer, PBC rule,
workspace allocation, backend, scheduling, periodicity, or 2D behavior.

This first consumer requires positive even Cartesian block extent `B>=4` on
every axis and requested lower/upper halo reach no larger than `B/2`.  CWP-001
remains valid outside this consumer scope.

## Stable Operation

```text
fill_coarser_slope_support_plan(
    interior_lower, interior_upper,
    selected_count, primary_slot, primary_phase_code, reduced_direction,
    directions,
    relation_kinds, physical_masks, source_counts, source_slots,
    fine_target_lower, fine_target_upper,
    coarse_source_lower, coarse_source_upper,
    workspace_source_lower, workspace_source_upper,
    workspace_required_lower, workspace_required_upper,
    workspace_coarse_origin,
    plan_source_slots, plan_source_is_fine, plan_physical_masks,
    plan_directions,
    plan_source_lower, plan_source_upper,
    plan_base_lower, plan_base_upper,
    plan_target_lower, plan_target_upper,
    plan_logical_interior_lower, plan_logical_interior_upper,
    plan_storage_logical_offsets,
) -> (transfer_count, record_count)
```

Triplets and row/box arrays use native-endian C-contiguous `int64`; codes use
C-contiguous `uint8`.  `directions` is the exact canonical x-fast 26 noncenter
rows.  REL/RSL inputs are one accepted row with shapes `(26,)` and `(26,4)`;
active source slots lie in `[0,selected_count)`, inactive slots are `-1`.
`primary_slot` is in `[0,selected_count)`, phase is `0..7`, and the noncenter
reduced direction identifies an unmasked COARSER count-one row whose source
box/workspace box is exactly the supplied nonempty CWP row.  The original CWP
fine target bounds are supplied as `int64[3]`; they obey the reduced-direction
side rules and expose each requested side width for the `B/2` gate.  Either
phase bit is valid on a nonzero direction axis, matching CWP/RPH; CSP does not
reintroduce the retired fine-to-coarse send gate.

Every plan vector has length 18 and every plan matrix has shape `(18,3)`.
Outputs are pairwise nonoverlapping, writable, disjoint from inputs, completely
overwritten on success, and never retained.

## Exact Direction Partition And Sources

Let `B=U-L`, `H=B/2`, `O=workspace_coarse_origin`, and
`R=[workspace_required_lower,workspace_required_upper)`.  Intersect `R` on
each axis with `[O+eH,O+(e+1)H)` for `e=-1,0,+1`; enumerate nonempty Cartesian
products in x-fast 27-column order.  Products are pairwise disjoint and cover
`R`.  Products wholly contained in CWP's `workspace_source` are replaced by one
first direct record using CWP's exact coarse source/workspace boxes.  Partial
overlap is invalid.  Emit remaining unmasked records, then physical records.
Within each part, preserve raw x-fast 27-column order after the first merged
direct record.

For unmasked direction `e`, center uses `primary_slot` and restriction; SAME
uses its sole RSL slot and restriction; COARSER uses its sole RSL slot and
direct copy.  Unmasked PHYSICAL/FINER is invalid.  With phase bits `p`:

```text
q                  = floor((p+e)/2)
source phase       = p+e-2*q
target band lower  = O+e*H
coarse band lower  = L+source_phase*H
COARSER source     = coarse_band_lower + (target-target_band_lower)
fine source        = L + 2*(target-target_band_lower)
```

Coarse source extent equals target extent.  Fine source extent is twice target
extent.  These are mathematically equal to the direct global expressions in
CWP, but the band-relative evaluation order is required: `target-band_lower`
stays in `[0,H]`, `source_phase` is zero or one, and no large intermediate can
overflow before cancellation near int64 limits.  Every source box is inside
`[L,U)`.

Every active transfer record has `base_lower==target_lower` and
`base_upper==target_upper`; all three logical metadata rows are zero.  For a
physical record, `slot=-1`, `source_is_fine=255`, and source boxes are zero.
Clearing its mask bits from `e` identifies a unique earlier unmasked base-owner
record.  Define a storage offset component as `-e[a]` on masked axes and zero
otherwise, then set `base=target+offset`.  This same-extent base is contained in
the owner's target but normally is not equal to it.  Let
`owner_source_lower`, `owner_target_lower`, and `owner_source_is_fine` denote
that earlier record.  Its source mapping defines the physical row's PWA
metadata:

```text
coarse base: logical interior=[L,U),
             storage offset=owner_source_lower-owner_target_lower
fine base:   logical interior=[0,H),
             storage offset=(owner_source_lower-L)/2-owner_target_lower
```

The division is exact.  A physical target is one cell wide on every masked
axis.  Its PWA mapped image is contained in the base for every supported mode.

## Representation, Validation, And Cost

`source_is_fine` is `0` for direct copy, `1` for RST, and `255` for physical or
inactive records.  Active physical rows have nonzero masks.  The inactive
suffix has slot `-1`, `source_is_fine=255`, mask zero, and zero directions/
boxes/logical metadata.  `[0,transfer_count)` is exactly the unmasked prefix;
`[transfer_count,record_count)` is the physical suffix.

Integer scalars accept Python/NumPy integer values except booleans and rank-zero
arrays, must be nonnegative where stated, and must fit signed int64.  Validate
every representation, scalar, direction/order, REL/RSL row, original target and
exact CWP identity, extent/reach gate, derived signed arithmetic, target partition,
source/ratio containment, physical base/mapped image, output writability, and
all overlap before mutation.  Wrong types/dtypes raise `TypeError`; invalid
shape/value/order/coverage/slot/reach/alias raises `ValueError`; derived int64
overflow raises `OverflowError`.  Every failure preserves every output.

The plan introduces no leaf ID: all unmasked noncenter slots already occur in
the primary all-26 SPR/RSL closure; center uses the primary and physical rows
use completed bases.  The universal 57-slot progress bound is unchanged.
CSP is cold/control: at most 18 records, fixed local work, no size-dependent
internal allocation, and exactly 4,500 caller-owned output bytes.

## Immediate Composition

CWA first applies every unmasked direct/RST record, then PWA applies the
physical suffix, producing exact rectangular CWP validity.  RHE invokes CSP for
all active COARSER rows before the chunk reader and reuses one plan buffer.
