# FRP-001 Contract: Cartesian FINER Restriction Placement

## Responsibility

FRP-001 maps explicit active FINER child phases and reduced directions to exact
primary target sub-boxes and fine-source interior boxes for RST-001.  It owns no
relation classification, source-slot mapping, physical rule, requested reach,
numerical averaging, payload mutation, backend, scheduling, periodicity, or 2D
behavior.

## Stable Operation

```text
fill_finer_restriction_boxes(
    interior_lower,
    interior_upper,
    reduced_directions,
    phase_codes,
    target_lower,
    target_upper,
    placed_target_lower,
    placed_target_upper,
    fine_source_lower,
    fine_source_upper,
) -> None
```

The interior is an ordered nonnegative `int64[3]` storage box.  Row inputs are
borrowed C-contiguous `reduced_directions int64[R,3]`, `phase_codes uint8[R]`,
and TGT boxes `int64[R,3]`.  Directions contain `-1/0/+1` and are noncenter;
each phase is in `[0,7]`.  The four outputs are caller-owned writable
C-contiguous `int64[R,3]`, pairwise nonoverlapping and disjoint from inputs.

For every row and axis let `[l,u)` be the interior, `B=u-l`, `[a,b)` the target,
`d` the reduced direction, and `p=(phase>>axis)&1`.

- `d == 0`: require positive even `B` and exact target `[l,u)`.  Phase zero
  writes target `[l,l+B/2)` and phase one writes `[l+B/2,u)`; source is `[l,u)`.
- `d == -1`: require `b==l`, `l-B/2 <= a <= l`, and phase bit one.  The placed
  target is `[a,b)` and source is `[u-2*(b-a),u)`.
- `d == +1`: require `a==u`, `u <= b <= u+B/2`, and phase bit zero.  The placed
  target is `[a,b)` and source is `[l,l+2*(b-a))`.

Thus source extent is exactly twice placed-target extent on every axis and is
contained in the fine source interior.  For the complete active RPH phase set,
placed target boxes are disjoint and their union is the input TGT box.  Empty
normal halo widths are valid and yield spatially empty boxes.

## Validation, Evidence, And Cost

Validate all representations and output writability, interior order, direction
and phase values, target side/width/phase compatibility, derived containment,
and all output overlap before mutation.  Wrong objects/dtypes raise `TypeError`;
invalid shapes/layouts/boxes/directions/phases/overlap raise `ValueError`.
Every error preserves all outputs.  Empty `R` is valid; inputs are unchanged and
nothing is retained.

All box results are exact.  Evidence covers every direction and phase, target
partition, asymmetric/zero halo widths, RST value composition, read-only inputs,
current-supported cases, and atomic failures.  Output is `96*R` bytes.  FRP-001
is cold/control: checked and unchecked work is `O(R)`, the implementation uses
no internal size-dependent allocation, and RST composition establishes its
consumer boundary without artificial repeated box timing.

## Immediate Composition

TGT and compact active FINER RPH rows produce the inputs.  RSL supplies the
corresponding fine-source slot separately.  RST restricts `fine_source` directly
into `placed_target`; a later executor owns application order and PBC widening.
