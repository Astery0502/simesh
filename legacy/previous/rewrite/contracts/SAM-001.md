# SAM-001 Contract: Exact Level-1 Block Placement

## Responsibility

SAM-001 places selected Cartesian level-1 block interiors onto their exact
native full-domain cell regions. It is a discrete placement operation, not
nearest-neighbor sampling or interpolation. It defines no allocation, chunk
planning, file field selection, halos, refined overlap policy, 2D behavior, or
physical-coordinate search.

## Stable Operation

```text
place_level1_blocks(
    payload,
    payload_valid_lower,
    payload_valid_upper,
    block_ids,
    domain_cell_counts,
    block_cell_counts,
    coord_to_rank,
    rank_to_coord,
    uniform_grid,
) -> None
```

- `payload` is borrowed read-only native-endian C-contiguous
  `float64[nslot,nfield,sx,sy,sz]`.
- `[payload_valid_lower,payload_valid_upper)` is a borrowed C-contiguous
  `int64[3]` box contained in the payload spatial shape. Its extent is exactly
  `block_cell_counts`.
- `block_ids` is borrowed C-contiguous `int64[nslot]`; arbitrary order and
  repeats are allowed, and each slot maps explicitly to its global ID.
- `domain_cell_counts` and `block_cell_counts` are borrowed positive
  C-contiguous `int64[3]` triplets with exact componentwise divisibility.
- `coord_to_rank` and `rank_to_coord` have the MOR-001 shapes for
  `root_shape = domain_cell_counts // block_cell_counts` and satisfy the
  validated TOP/GEO map contract.
- `uniform_grid` is caller-owned writable C-contiguous
  `float64[nfield,nx,ny,nz]`, where its field extent equals `payload.shape[1]`
  and its spatial shape equals `domain_cell_counts` exactly.

Payload and metadata may not overlap `uniform_grid`. Read-only inputs may
overlap one another. Inputs and pointers are not retained.

## Exact Placement

For slot `s`, let

```text
c  = rank_to_coord[block_ids[s]]
g0 = c * block_cell_counts
g1 = g0 + block_cell_counts.
```

For every local field `f` and offset `0 <= q < block_cell_counts`, the operation
performs the exact bit copy

```text
uniform_grid[f, g0 + q] = payload[s, f, payload_valid_lower + q].
```

Integer half-open regions assign every native level-1 cell to exactly one
global block; physical floating bounds are never compared. Slots are visited in
ascending slot order. If a global block ID repeats, the later slot overwrites
the same output region and therefore wins deterministically, matching STO-001
scatter ordering. Output cells outside the union of selected block regions are
bitwise preserved.

With every global ID selected exactly once, the complete uniform grid is
defined. A bounded caller may instead place successive unique primary chunks
into one output; support slots are excluded by slicing the STO-002 primary
prefix before this call.

## Validation And Atomicity

Before mutation, validate exact ndarray types/dtypes, ranks, shapes,
C-contiguity, output writability, nonempty/contained source region, positive and
divisible counts, signed-`int64` volume representability, MOR map shapes,
selected ID ranges, selected coordinate bounds, selected inverse consistency
`coord_to_rank[rank_to_coord[id]] == id`, field/spatial output shape, and
forbidden output overlap. Full MOR ordering is an upstream precondition and is
not rescanned for every chunk.

An empty slot or field selection is a valid no-op after ordinary validation.
Invalid calls leave `uniform_grid` unchanged. Type/dtype failures raise
`TypeError`; invalid layout, region, count, map, selector, output, or overlap
raises `ValueError`; unrepresentable volumes raise `OverflowError`.

## Exactness And Evidence

No floating-point arithmetic occurs. Signed zero, infinities, and NaN payload
bits are preserved exactly. Discrete placement, duplicate ordering, source
preservation, and unselected-output preservation use bitwise comparison with no
tolerance.

Evidence includes an independent NumPy slice reference; axis-coded asymmetric
root/block shapes; reordered, repeated, partial, empty, and padded-source
selections; exact full-grid comparison with current `uniform_full_level1`;
atomic late-selector/map failures; and a bounded STO-002/STO-001 chunk traversal
whose final grid equals direct full placement.

## Performance And Memory

Validation is linear in selected slots. Placement copies one contiguous z row
per selected slot/field/x/y tuple, so runtime is proportional to placed values.
No payload-, output-, topology-, or selection-sized scratch is allocated.
Measure value throughput, field/block/chunk scaling, allocation behavior,
reordered versus Morton-order placement, the current implementation, and the
composed plan/gather/place path before considering parallel disjoint-block
placement.

## Immediate Composition

MOR/TOP/GEO supply validated integer block coordinates, STO-001 supplies the
selected valid payload, and STO-002 supplies bounded unique primary chunks.
SAM-002 may use this operation as the exact native-full-grid fast path; INT-001
uses the bounded composition directly.
