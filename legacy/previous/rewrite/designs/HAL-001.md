# HAL-001 Design: Non-Periodic Physical Halos

## Problem

Physical boundary rules must fill padded workspaces without relying on hidden
mesh state or reading uninitialized sibling halos. Different blocks expose
different physical faces, so their produced regions are not generally one
common padded box.

## Choices Considered

The current implementation performs x/y/z sweeps before and after neighbor
exchange. Reproducing those partial passes directly would make correctness
depend on call history. Treating each face independently would leave physical
edges/corners ambiguous and lose observable no-inflow/antisymmetry ordering.

A direct cell rule can map every outside physical axis back to the interior,
read one valid interior value, then compose transforms in x/y/z order. It is
equivalent for cells whose outside axes are all physical and never reads an
invalid sibling halo.

## Selected Direction

Mutate a canonical padded payload in place. Use explicit block IDs, TOP face
sentinels, a normalized per-field face-mode table, and explicit local normal
field positions. Fill exactly each slot's rectangular physical envelope,
preserve the interior and all cells outside that envelope, and expose the common
valid region as the intersection of slot envelopes.

Reject reflected depths larger than the interior rather than inheriting the
current cross-halo reads. Reject missing no-inflow normal metadata rather than
silently degrading. Field-name inference, sibling completion, periodicity, and
workspace sizing remain outside HAL-001.
