# RTP-001 Combined Boundary Rejected

The proposed combined target-region/phase capability failed the five-question
gate before implementation.  Directed target boxes depend only on requested
and interior boxes plus directions; refined phase codes depend only on
FST/REL/RSL facts.  Their validation, substitution, measurement, and reasons to
change are independent.

The boundary is split into:

- TGT-001: directed halo target boxes;
- RPH-001: refined relation child-phase codes.

RAC-001 also remains retired because REL kind/mask already fully determines the
base action.  A later thin application may consume both artifacts, but no fused
stable wrapper is introduced without measured justification.
