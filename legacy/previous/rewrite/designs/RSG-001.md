# RSG-001 Combined Boundary Rejected

The proposed combined source/workspace geometry capability failed the
five-question gate before implementation.  SAME source translation, FINER
restriction placement, COARSER PRL workspace alignment/reach, and physical
widening have different inputs, outputs, references, substitution points, and
costs.

The replacement sequence is:

- SLB-001: same-level source-box translation;
- FRP-001: FINER restriction placement;
- CWP-001: COARSER explicit-workspace placement/reach.

Physical widening is not a static geometry capability; it remains in later
PBC-aware application because source depth/ownership depends on boundary mode
and contracted axis order.
