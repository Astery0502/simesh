# FRP-001 Design: FINER Restriction Placement

## Choice And Decomposition

FRP-001 maps one compact active FINER source row at a time from an RPH child
phase and reduced direction to two explicit boxes: the primary target sub-box
and the fine-source interior box consumed by RST-001.  It does not perform
restriction, resolve slots, inspect relation kinds, apply physical rules, or
schedule writes.

On a zero direction axis, the child phase selects the lower or upper half of
the target interior and the complete fine source interior maps to it.  On a
nonzero axis, the target halo interval is unchanged and the touching fine
source strip is twice as wide.  This makes the RST region exactly twice the
target extent on every axis and partitions a TGT row across the active RPH
children without overlap.

An executor-internal action dispatcher was rejected because it would combine
kind, slot, phase, box, numerical restriction, physical widening, and mutation
order.  Precomputing all possible phase boxes globally is deferred because the
artifact is small and selected-row scoped.

Responsibility: derive exact target and fine-source boxes for explicit active
FINER rows.

Owned decisions: phase-to-target-half mapping, touching fine strip, exact
two-to-one extent, parity/side validation, and output atomicity.

Explicitly non-owned decisions: REL kind/mask, source count/slot, TGT reach,
PBC, RST arithmetic, payload, application order, cache, scheduling, 2D, or
periodicity.

Inputs/outputs: one interior box; `int64[R,3]` reduced directions and TGT boxes;
`uint8[R]` phase codes; four caller-owned `int64[R,3]` box outputs.

Mutation/ownership: inputs borrowed, outputs fully overwritten only after
complete validation, nothing retained.

Access/halo reach: no values; output fine source extent is exactly twice its
target extent.

Reference/invariant: Python integer boxes; containment, exact 2:1 extent,
phase partitions, RST composition, and supported current placement.

Producer/consumer: TGT/RPH produce rows; RST consumes the source/target boxes.

Performance class: cold/control.  Work is exact `O(R)` integer geometry with
`96*R` caller-owned output bytes and no internal size-dependent allocation;
RST composition establishes usefulness without an artificial box-only timing.

Five-question result: yes/yes/yes/yes/yes.
