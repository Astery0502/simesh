# CWA-001 Design: COARSER Workspace Application

## Choice

Apply one complete CSP plan to one caller-owned coarse scratch.  All unmasked
records run first: coarse-scale records copy exactly and fine-scale records use
RST-001.  Only after those disjoint targets are valid does one PWA batch fill
the physical suffix.  CSP's targets partition the complete CWP required
rectangle, so no preliminary whole-box CWP copy or workspace clear is needed.

Merging CWA into RHE was rejected because rectangular scratch validity,
two-scale source application, PBC-after-restriction order, and atomic workspace
mutation are independently testable and reusable by resident/cached execution.
A cross-only fill was rejected because checked PRL currently accepts a complete
rectangular valid box.  A fused Cython cell dispatcher is deferred until the
simple composition is measured.

## Decomposition Record

Responsibility: apply an explicit CSP plan to assemble one complete CWP coarse
workspace rectangle.

Owned decisions: complete plan preflight; direct-versus-RST application of
already classified records; all-base-before-PWA stage order; exact mutation and
preservation of one coarse scratch.

Explicitly non-owned decisions: topology/support/source choice, PBC meaning,
RST meaning, PRL, workspace allocation/reuse, reader/writer, chunking/cache,
final primary halo, periodicity, or 2D.

Inputs/outputs: selected interior payload, one writable coarse workspace,
interior/required boxes, and one CSP plan with transfer/record counts.

Mutation/ownership: selected payload and plan are borrowed; only the required
workspace rectangle changes after complete preflight; its exterior is preserved.

Access/halo reach: reads only CSP source boxes and physical bases; produces the
complete CWP required rectangle.

Reference/invariant: explicit FND copy, RST reference, and PWA reference;
disjoint target volume equals required volume; poison proves no missing reads.

Producer/consumer: CSP produces the plan; PRL consumes the completed rectangle
through RHE.

Performance class: composition-only in CWP plan/apply/PRL and complete RHE.

Five-question result: yes/yes/yes/yes/yes.  CWA owns value-application order,
not source planning or executor scheduling.
