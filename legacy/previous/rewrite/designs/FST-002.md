# FST-002 Design: Refined Forest Artifact Conformance

## Problem

FST-001 constructs exact flat forest arrays, but its validation starts from the
Boolean preorder stream.  Independent consumers can receive caller-supplied or
adapter-produced flat arrays and otherwise must duplicate recursive pointer-
safety and semantic checks.  TOP, refined geometry, and native I/O need one
shared conformance boundary before unchecked traversal.

## Alternatives

Trusting only shapes/ranges leaves child pointers, preorder intervals, leaf
maps, levels, and coordinates mutually inconsistent.  Reconstructing a second
forest or allocating visited sets is unnecessary because canonical preorder
already proves unique coverage.  Consumer-specific validators would drift and
mix representation semantics into topology/geometry.

Use one allocation-free recursive pass over the flat tables.  Traverse roots
in MOR rank order and require every child ID to equal the next preorder node.
Simultaneously prove levels, coordinates, parent reciprocity, leaf-map order,
sentinels, logical-grid representability, and complete node/leaf consumption.
Return the exact maximum level.

## Decomposition Record

Responsibility: validate that borrowed arrays are exactly one FST-001 flat
forest artifact.

Owned semantic decisions: roots aligned to supplied dense MOR rank rows,
preorder node identity, canonical child order, level/coordinate recurrence,
parent/child reciprocity, node/leaf inverse maps, sentinels, representable
logical extents, exact max level, and first-failure reporting.

Explicitly non-owned decisions: MOR mathematical key order, forest construction, topology contacts,
two-to-one admissibility, geometry, storage, I/O conversion, cache/materialized
relations, payload values, and scheduling.

Inputs and outputs: borrowed MOR maps and the seven FST arrays; one Python
integer maximum level is returned, with no output buffer.

Mutation and ownership: every array is borrowed read-only and preserved; no
scratch/output arrays or retained state.

Access pattern / halo reach: metadata preorder traversal only; no payload or
halo access.

Independent reference or invariant: Python recursive traversal, valid FST-001
outputs, one late corruption in each artifact, root/subtree partition, leaf
inverse/order, coordinate/depth overflow, and representative real tree.

Immediate producer and consumer: FST-001 and future adapters produce flat
artifacts; TOP-002, GEO-002, and native metadata composition consume one
successful conformance result before their own unchecked work.

Kernel and composed measurement boundary: nodes/s, fixed allocation, depth/
size scaling, and construction+conformance overhead on synthetic and real
trees.  Consumer operations must not repeat conformance per query/chunk.

A successful result applies to one immutable artifact lifecycle.  Read-only
arrays naturally preserve it; mutating any accepted writable input starts a new
lifecycle and requires revalidation before unchecked consumers run again.

Five-question result: yes/yes/yes/yes/yes.  This boundary owns representation
validity only and introduces no topology policy or execution strategy.

## Performance Gate

Measure full trees through level five and the real 25,844-node tree.  The pass
must be linear, allocation-free apart from fixed Python call objects, and small
relative to one-time FST construction.  A controlled median above FST-001
construction time is investigated; repeated per-query validation is forbidden
regardless of isolated speed.
