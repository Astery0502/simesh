# CWP-001 Contract: Cartesian COARSER Workspace Placement And Reach

## Responsibility

CWP-001 maps explicit active COARSER directions, primary phases, and fine target
boxes to a normalized zero-based coarse workspace for PRL-001.  It defines the
required workspace, shifted coarse origin, and the relation source interior's
source/destination copy boxes.  It defines no topology/support completion,
physical values, numerical transfer, payload allocation, scheduling, 2D, or
periodicity.

## Stable Operation

```text
fill_coarser_workspace_boxes(
    interior_lower,
    interior_upper,
    reduced_directions,
    phase_codes,
    target_lower,
    target_upper,
    coarse_source_lower,
    coarse_source_upper,
    workspace_source_lower,
    workspace_source_upper,
    workspace_required_lower,
    workspace_required_upper,
    workspace_coarse_origin,
) -> None
```

The interior is a positive-even ordered nonnegative `int64[3]` box.  Row inputs
are C-contiguous `int64[R,3]` reduced noncenter directions and target boxes plus
`uint8[R]` primary phases in `[0,7]`.  Outputs are seven pairwise-disjoint,
caller-owned writable C-contiguous `int64[R,3]` arrays disjoint from inputs.

For a nonempty row and axis, let `[l,u)` have `B=u-l`, direction `d`, phase bit
`p`, target `[a,b)`, and

```text
delta = floor((p+d)/2)
logical_origin = l + p*(B/2) - delta*B
center_lower = logical_origin + floor((a-l)/2)
center_upper = logical_origin + floor((b-1-l)/2) + 1
required = [center_lower-1, center_upper+1)
```

`d==0` requires target `[l,u)`.  `d==-1` requires a lower-side target of width
at most `B` and phase bit zero.  `d==+1` requires an upper-side target of width
at most `B` and phase bit one.  The derived center box must lie inside the
relation source interior `[l,u)`.

Normalize with `base=min(required_lower,logical_origin)`.  Output:

```text
workspace_required = required - base
workspace_coarse_origin = logical_origin - base
coarse_source = required intersect [l,u)
workspace_source = coarse_source - base
```

The required workspace and origin are nonnegative.  Source and workspace-source
extents are equal; the former is contained in the relation source interior and
the latter in the required workspace.  Cells inside `workspace_required` but
outside `workspace_source` are explicit uncovered reach for later support/PBC
application.

If any target axis is empty, the complete row is a no-op representation: all
seven output rows are exact zero.  Direction, phase, target-side, and interior
validation still applies.

## Validation, Evidence, And Cost

Validate representations/writability, positive-even interior, directions,
phases, target side/width, derived signed-int64 arithmetic and center
containment, and every output overlap before mutation.  Type/dtype errors raise
`TypeError`; shape/layout/value/overlap errors raise `ValueError`; derived
overflow raises `OverflowError`.  Errors preserve every output.  Empty `R` is
valid; inputs are unchanged and nothing is retained.

Evidence covers every compatible direction/phase, asymmetric targets, empty
rows, normalized/source containment, uncovered reach, copy placement, PRL
mapping, read-only inputs, current-supported coordinate cases, and atomic
errors.  Output is `168*R` bytes.  CWP-001 is cold/control: checked and
unchecked work is `O(R)`, the implementation uses no internal size-dependent
allocation, and PRL mapping composition establishes its consumer boundary
without artificial repeated box timing.  Later workspace application measures
the value-transfer path separately.

## Immediate Composition

TGT and compact active COARSER RPH rows produce inputs.  A later application
copies `coarse_source` into `workspace_source`, fills uncovered required cells
through explicit support/PBC semantics, and calls PRL with the emitted
`workspace_required` valid box and `workspace_coarse_origin`, fine
target `[target_lower,target_upper)`, and `fine_origin=interior_lower`.
