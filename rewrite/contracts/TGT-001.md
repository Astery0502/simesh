# TGT-001 Contract: Directed Halo Target Boxes

## Responsibility

TGT-001 maps explicit noncenter Cartesian directions to exact half-open target
boxes inside one caller-chosen requested halo envelope.  It defines no relation
kind/mask/source/phase, requested reach policy, source box, PBC rule, numerical
value, workspace, payload mutation, backend, scheduling, periodicity, or 2D
behavior.

## Stable Operation

```text
fill_directed_halo_target_boxes(
    interior_lower,
    interior_upper,
    requested_lower,
    requested_upper,
    directions,
    direction_lower,
    direction_upper,
) -> None
```

The four box inputs are borrowed read-only native-endian C-contiguous
`int64[3]`.  They satisfy

```text
0 <= requested_lower <= interior_lower <= interior_upper <= requested_upper
```

componentwise.  The caller owns the requested envelope/reach; asymmetric and
zero-width sides are valid.

`directions` is borrowed read-only native-endian C-contiguous `int64[D,3]`.
Every component is in `{-1,0,1}` and no row is center.  Rows may be empty,
subsetted, reordered, or repeated.

`direction_lower` and `direction_upper` are caller-owned writable native-endian
C-contiguous `int64[D,3]`.  Outputs may not overlap each other or any input;
inputs may overlap each other.  Nothing is retained.

## Exact Target Boxes

For row `d`, axis `a`, and component `v=directions[d,a]`, write

```text
v == -1: [direction_lower, direction_upper) =
         [requested_lower, interior_lower)
v ==  0: [direction_lower, direction_upper) =
         [interior_lower, interior_upper)
v == +1: [direction_lower, direction_upper) =
         [interior_upper, requested_upper)
```

on that axis.  A side interval may be empty.  With the 26 distinct canonical
directions, boxes are pairwise disjoint and their union is exactly the requested
envelope minus the interior.  Repeated directions intentionally repeat a box.

## Validation, Errors, And Atomicity

Validate box triplet representations in argument order, then directions, then
both output representations/shapes/writability.  Validate requested/interior
ordering, every direction component/noncenter row, and all output/input overlap
before either output is mutated.

Wrong object or dtype raises `TypeError`.  Invalid rank, shape, layout,
writability, box ordering, direction, or overlap raises `ValueError`.  Every
failure preserves both complete outputs.  Successful execution fully
overwrites both outputs, mutates no input, and allocates/retains no
size-dependent scratch.  Empty `D` is valid with exact outputs `[0,3]`.

## Independent Evidence

The independent reference uses Python per-axis interval selection without
production helpers.  Evidence covers all 26 directions, subsets/reorders/
repeats, asymmetric/zero-width requested sides, canonical disjoint union,
safe current table equality, valid singleton-axis rewrite boxes, every
representation/box/direction/overlap error, read-only inputs, and empty output.

Only the unsafe current singleton physical-status table access is excluded from
current parity.  Valid singleton-axis rewrite inputs and TGT boxes remain fully
supported.

## Performance And Memory

Output is exactly

```text
2*D*3*8 = 48*D bytes
```

or 1,248 bytes for `D=26`.  The Cython fill is `O(D)` with no payload or
size-dependent scratch.  Measure directions/s, fixed validation/allocation,
direction-count scaling, reference/current ratio, and native materialize-once
reuse versus repeated native derivation.  Exact arrays/bytes are hard gates;
standard >10% investigation and reproduced >20% blocking rules apply.

## Immediate Composition

FND interior/requested boxes and explicit directions produce TGT outputs.  A
later refined application combines them with REL actions, RPH phase codes, PBC
rules, source/workspace geometry, and numerical kernels.  TGT consumes no
refinement metadata or values.
