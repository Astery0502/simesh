# OPR-002 Contract: Axis Central Difference

## Responsibility

OPR-002 defines one representative fixed local stencil: the centered first
derivative of one field along one Cartesian axis. It maps an explicit source-
coordinate output box into a translated caller-owned destination. It defines no
field names, term batching, coefficient accumulation, allocation, chunk
planning, halo filling, refinement, 2D behavior, or fused storage policy.

## Stable Operation

```text
central_difference_into(
    source,
    source_valid_lower,
    source_valid_upper,
    output_lower,
    output_upper,
    source_field_position,
    axis,
    cell_spacing,
    destination,
    destination_field_position,
    destination_lower,
) -> None
```

- `source` is borrowed read-only C-contiguous
  `float64[nslot,nsource,sx,sy,sz]` with a borrowed contained `int64[3]` valid
  box.
- `[output_lower,output_upper)` is a borrowed ordered `int64[3]` box expressed
  in source storage coordinates.
- Source field position and `axis` are zero-based scalar integers; axis is in
  `[0,3)`.
- `cell_spacing` is borrowed read-only C-contiguous `float64[3]`, finite,
  positive, and normal.
- `destination` is caller-owned writable C-contiguous
  `float64[nslot,ndestination,dx,dy,dz]` with the same slot extent. Its field
  position and borrowed `int64[3] destination_lower` select the translated
  target.

Source and destination may not overlap. Destination may not overlap region or
spacing metadata. Read-only inputs may overlap one another. Nothing is retained.

## Reach And Arithmetic

Let `e_axis` be the integer unit triplet on the chosen axis. For a nonempty
requested output box, the exact FND-002 requirement is

```text
pattern     = LOCAL_STENCIL
lower_reach = e_axis
upper_reach = e_axis
required input = [output_lower-e_axis, output_upper+e_axis).
```

The available source valid box must contain that required box. Other axes have
zero reach. For each slot and output cell `p`, evaluate separate binary64
operations with no contraction:

```text
inverse_two_spacing = 0.5 / cell_spacing[axis]
difference = source[field,p+e_axis] - source[field,p-e_axis]
result = difference * inverse_two_spacing
```

Only the selected destination field and translated output extent may change.
Other destination cells/fields remain bitwise preserved; source and metadata
remain unchanged. The produced valid box for that destination field is exactly
the translated output box.

Both neighbors are always read. HAL-002-completed primary payloads provide the
required sibling/physical values when the requested output is the interior.

## Validation And Atomicity

Before mutation, validate exact ndarray types/dtypes/ranks/C-contiguity,
destination writability, equal slot extents, valid/output box ordering and
containment, axis and field positions, normal finite spacing, required-input
containment, destination translation/representability, and forbidden overlap.
Field/axis/spacing metadata are checked even for empty slot or output requests.

An empty slot axis or output box is a validated no-op and requires no neighbor
reads. Invalid calls leave destination unchanged. Type/dtype/scalar-kind
failures raise `TypeError`; invalid layout, region, axis, field, spacing,
support, output, writability, or overlap raises `ValueError`; unrepresentable
translation raises `OverflowError`.

## Numerical Evidence

Region, reach, field, and neighbor-index artifacts compare exactly. The fixed
subtract/multiply scalar reference and current comparison report maximum
absolute, cancellation-aware relative, and finite-nonzero ULP error. When
inverse spacing, neighbors, difference, and result are finite, the roundoff
bound is

```text
16 * eps * max(1, abs(left), abs(right)) / cell_spacing[axis].
```

Relative error is reported where the reference magnitude is at least
`sqrt(eps)` times that local scale. Signed zero and nonfinite/overflow cases
compare IEEE classification/sign and fixed operation order.

Affine fields reproduce their constant derivative within the roundoff bound.
Smooth fields demonstrate approximately second-order L-infinity convergence,
with retained observed order at least 1.8. Current one-term derivative output is
compared over the common valid region; current's conservative all-axis loop
contraction is not inherited as an axis reach requirement. Current's batching
layer also computes `+0.0 + 1.0*contribution`; its signed-zero difference from
the direct stencil is recorded explicitly and not treated as numerical error.

## Mutation And Bounded Composition

The normal level-1 path passes only a full-halo chunk's completed primary prefix
and computes its interior. Successive unique primary chunks write every block
exactly once; duplicate slots follow destination slot order naturally because
each slot has a separate destination row.

```text
full-halo plan -> gather -> HAL-001 -> HAL-002
-> central difference on primary interiors -> scatter primary results.
```

## Performance And Memory

The Cython kernel reads two values and writes one per output, with fixed scalar
state and no payload-, slot-, field-, or region-sized scratch. Measure values/s,
effective bandwidth, axis/region/field/chunk scaling, allocation, current and
NumPy runtime, convergence cost, and composed gather/halo/compute/scatter.
Explore multi-term, in-place, or halo-fused variants only after the separate
path is correct and measured.

## Immediate Composition

FND-002 supplies exact axis reach; GEO-001 supplies spacing; HCL-001/STO-001 and
HAL-001/HAL-002 supply bounded completed primaries; STO-001 scatters results.
INT-001 consumes the bounded stencil path.
