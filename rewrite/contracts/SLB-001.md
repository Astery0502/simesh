# SLB-001 Contract: Cartesian Same-Level Source Boxes

## Responsibility

SLB-001 translates explicit reduced-direction target boxes to exact equal-level
source boxes inside one block interior.  It defines no relation/action/mask/
slot, physical rule, requested reach, refinement phase, FINER/COARSER geometry,
payload value, backend, scheduling, periodicity, or 2D behavior.

## Stable Operation

```text
fill_same_level_source_boxes(
    interior_lower,
    interior_upper,
    reduced_directions,
    target_lower,
    target_upper,
    source_lower,
    source_upper,
) -> None
```

Interior bounds are borrowed read-only C-contiguous native-endian `int64[3]`,
ordered/nonnegative.  `reduced_directions` is borrowed read-only C-contiguous
`int64[R,3]` with components in `{-1,0,1}` and no center row.  Physical-mask
components have already been neutralized; pure physical rows are absent.

Target inputs and source outputs are respectively borrowed read-only and
caller-owned writable C-contiguous `int64[R,3]`.  Outputs do not overlap each
other or any input; inputs may overlap each other.  Target rows are ordered and
nonnegative FND storage regions, and rows may repeat/reorder.  On success both
outputs are fully overwritten, inputs are unchanged, and nothing is retained.

## Exact Translation

Let `B = interior_upper-interior_lower`.  For each row/axis:

```text
source_lower = target_lower - direction*B
source_upper = target_upper - direction*B
```

For interior axis `[l,u)` and `B=u-l`, the target must match the declared side:

- direction `-1`: `target_upper=l` and `l-B <= target_lower <= l`;
- direction `0`: `l <= target_lower <= target_upper <= u`;
- direction `+1`: `target_lower=u` and `u <= target_upper <= u+B`.

Translated source is contained in the interior and has the exact target extent.
Asymmetric/zero widths and zero interior extents are valid when these rules hold.

## Validation And Evidence

Validate representations/shapes/writability first, then interior ordering,
direction values/noncenter, nonnegative target ordering/side compatibility,
translated containment, and output overlap before mutation.  Valid side/width
constraints prove translated endpoints lie inside the representable interior,
so there is no separate translation-overflow case.  Wrong objects/dtypes raise
`TypeError`; other invalid calls raise `ValueError`.  Every failure preserves
both outputs; empty `R` is valid.

The independent Python reference uses mathematical integers.  Evidence covers
all directions, partial/asymmetric/zero widths, TGT rows, current same-level
behavior, one-slot FND copy, singleton/empty axes, and complete atomic errors.
Direct current parity is scoped to unmasked rows with supported positive even
interior extents and halo width no larger than the interior; singleton/empty
axes use rewrite/reference evidence.

Output is exactly `48*R` bytes.  Measure rows/s, fixed allocation, source-width
scaling, copied cells/s, reference/current comparison, and equivalent native
materialize-once reuse versus repeated derivation.  No size-dependent scratch,
hash, map, dynamic dispatch, or parallelism is used.
