# TRM-001 Contract: Nonperiodic Field-Line Termination Policy

## Responsibility

TRM-001 classifies finite seeds, RK stage states, FLN RHS statuses, final
candidates, and the accepted-step budget into stable nonperiodic field-line
outcomes. It owns the code/stage vocabulary, precedence, half-open domain,
bitwise no-progress rule, whole-step rejection, and accepted-prefix meaning. It
defines no field normalization, RK arithmetic, sampling/cache/I/O, or seed
scheduling.

## Stable Codes And Operations

```text
FieldLineTermination.ACTIVE                  = 0
FieldLineTermination.SEED_OUTSIDE            = 1
FieldLineTermination.MAX_STEPS               = 2
FieldLineTermination.DOMAIN_EXIT             = 3
FieldLineTermination.ZERO_FIELD              = 4
FieldLineTermination.NONFINITE_FIELD         = 5
FieldLineTermination.UNREPRESENTABLE_NORM    = 6
FieldLineTermination.UNREPRESENTABLE_SAMPLE  = 7
FieldLineTermination.NONFINITE_STATE         = 8
FieldLineTermination.NO_PROGRESS             = 9

FieldLineStage.CONTROL    = 0
FieldLineStage.K1         = 1
FieldLineStage.K2         = 2
FieldLineStage.K3         = 3
FieldLineStage.K4         = 4
FieldLineStage.CANDIDATE  = 5

classify_field_line_seed(seed, domain_lower, domain_upper) -> int
classify_field_line_stage_state(stage_state, domain_lower, domain_upper) -> int
field_line_termination_from_rhs_status(rhs_status) -> int
classify_field_line_candidate(
    current_state,
    candidate_state,
    domain_lower,
    domain_upper,
) -> int
```

Coordinate/state inputs are C-contiguous `float64[3]` or `float64[4]` as
appropriate; domains are finite ordered `float64[3]`. The pure operations return
the exact integer enum value and mutate/retain nothing.

## Truth Table And Precedence

Seeds are user request data. Any nonfinite seed coordinate is an ordinary
`ValueError`, not a trajectory result. A finite seed is `ACTIVE` exactly when
`domain_lower <= seed < domain_upper` on every axis; otherwise it is
`SEED_OUTSIDE`. SLE stores no point for an outside seed.

For an RK stage state:

1. any nonfinite `(x,y,z,I)` component -> `NONFINITE_STATE`;
2. any coordinate outside the same half-open domain -> `DOMAIN_EXIT`;
3. otherwise -> `ACTIVE` and sampling may proceed.

Map FLN-001 statuses exactly:

```text
RHS_OK                    -> ACTIVE
RHS_ZERO_FIELD            -> ZERO_FIELD
RHS_NONFINITE_FIELD       -> NONFINITE_FIELD
RHS_UNREPRESENTABLE_NORM  -> UNREPRESENTABLE_NORM
```

Unknown RHS status is an ordinary `ValueError` at the checked boundary. SLE
uses the unchecked mapping only for FLN-produced bytes.

A finite interior stage whose exact CHS/SAM-005 point preflight reports an
unrepresentable trilinear stencil is `UNREPRESENTABLE_SAMPLE`. SLE removes that
seed, retries the remaining compact stage batch, and records the current K1--K4
marker. The rejected CHS preflight performs no sampling, cache mutation, output
mutation, or nonempty I/O.

Candidate classification requires `current_state` to have finite interior
coordinates; violation is an ordinary `ValueError`. Candidate precedence is:

1. any of its four state components nonfinite -> `NONFINITE_STATE`;
2. all three candidate coordinate bit patterns equal the corresponding current
   coordinate bits -> `NO_PROGRESS`;
3. any candidate coordinate outside the half-open domain -> `DOMAIN_EXIT`;
4. otherwise -> `ACTIVE` and the complete `(x,y,z,I)` candidate may append.

Signed-zero changes therefore count as bitwise coordinate progress even though
the numerical coordinates compare equal. Integral-only change with identical
coordinate bits is `NO_PROGRESS`.

After exactly the caller's nonnegative `max_steps` candidates append, SLE sets
`MAX_STEPS` with stage `CONTROL`. `max_steps==0` stores an interior seed and
positive-zero integral, performs no sample, and returns `MAX_STEPS`.

A stage/RHS/candidate termination rejects the whole attempted step. The last
accepted point/integral stays final; the rejected state is not clipped, wrapped,
or appended. Stage marker 1--4 identifies the failed sample state/RHS;
`CANDIDATE` identifies final-state failure; seed/max-budget results use
`CONTROL`. One numerical result never terminates another seed.

## Validation And Errors

Checked functions validate exact ndarray/scalar kinds, float64/uint8 dtypes,
rank/shape/C-contiguity, finite ordered domain, and the current-state precondition
where stated. Type/dtype failures raise `TypeError`; invalid layout/domain,
nonfinite seed/current state, or unknown status raises `ValueError`. There is no
mutation or allocation proportional to input size.

## Reference, Tests, And Performance

An exhaustive scalar truth table covers exact lower/upper domain faces on every
axis, nonfinite seed/stage/candidate components (including finite stage
coordinates with nonfinite integral), all RHS codes and invalid bytes,
every precedence collision, all signed-zero progress combinations, integral-
only progress, max-step zero/positive, and stage-marker assignments in SLE.

TRM-001 is `cold/control`: every classification is fixed scalar work with no
retained or input-sized allocation. Its cost is reported only inside SLE.

SLE-001 is the sole initial result-policy consumer. Adaptive rejection, domain-
boundary intersection, periodic wrap, maximum arclength, event surfaces, or
user callbacks require separate termination capabilities and may not reinterpret
these codes.
