# BAL-001 Contract: Global Cartesian 3D All-Touch Two-To-One Balance

## Responsibility

BAL-001 validates the exact policy

```text
abs(level_a - level_b) <= 1
```

for every distinct Cartesian 3D leaf pair whose closed logical boxes touch at a
face, edge, or corner.  It defines no FST conformance, contact lookup, topology
cache/kind, relation/support plan, geometry, payload value, transfer rule,
storage, periodicity, or scheduling.

## Stable Operation

```text
validate_refined_all_touch_2to1(
    root_shape,
    coord_to_rank,
    root_node_ids,
    node_levels,
    node_coords,
    child_node_ids,
    node_leaf_ids,
    leaf_node_ids,
) -> None
```

Inputs have the exact borrowed read-only representations used by TOP-002.  They
belong to one unchanged artifact lifecycle that has passed FST-002.  MOR order
is the upstream MOR-001 precondition.  BAL-001 validates array shapes needed for
safe access but does not repeat FST conformance or retain input pointers.

## Exact Policy

Visit source leaves in ascending canonical leaf ID and direction columns in
the x-fast HPL/TOP cube order

```text
column = (dz+1)*9 + (dy+1)*3 + dx+1,
```

skipping center column 13.  Obtain the raw target through exact TOP-002 contact
semantics.

- Physical target `-1` has no touching leaf and is skipped.
- A target leaf at the source level is balanced.
- A target leaf below the source level is balanced exactly when
  `source_level-target_level <= 1`; a larger gap is a violation.
- A target internal node at the source level represents finer leaves.  For
  each axis, a negative direction touches target child bit one, a positive
  direction touches bit zero, and a zero direction permits both bits.  Every
  matching immediate child must be a leaf.  An internal matching child proves
  a touching descendant at least two levels finer and is a violation.

The selected child count is exactly four across a face, two across an edge, and
one across a corner.  Children away from the contact need not be leaves.  Since
every leaf is also visited as a source, these checks are equivalent to the
absolute-gap rule for all touching pairs.

The first violation under the declared leaf/direction order raises `ValueError`
identifying source leaf, direction column, raw target node, and offending node
when applicable.  BAL-001 returns `None` on success and produces no balance
table or token.

## Lifecycle, Validation, And Errors

FST-002/TOP-002 semantics are preconditions and the artifact must remain
unchanged for the BAL result to remain valid.  Any later artifact mutation
requires FST-002 and BAL-001 again before balanced consumers execute.

Before unchecked traversal, validate exact ndarray type/dtype/rank/shape/
C-contiguity and positive representable root volume.  Wrong types/dtypes raise
`TypeError`; invalid shapes/layouts raise `ValueError`; volume overflow raises
`OverflowError`.  Semantic artifact corruption after FST-002 is a caller
contract violation.  Inputs are never mutated, so ordinary failures are atomic.

## Independent Evidence

The reference lifts every leaf box to the common maximum-level integer lattice
and checks all `i<j` pairs whose closed boxes intersect at one or more boundary
dimensions.  It does not call TOP-002 or follow FST child pointers.

Evidence includes uniform and one-level mixed trees; face imbalance;
face-balanced but edge/corner imbalance; each direction/child phase; physical
boundaries and singleton axes; randomized complete octrees; maximum legal
depth; exact first-violation reporting; current-supported synthetic cases; and
the representative real refined tree.

## Performance And Memory

Production performs at most 26 TOP-002-depth lookups per leaf and inspects at
most four immediate target children per direction.  Worst-case complexity is
`O(26*L*max_level)` with no leaf/direction-sized heap scratch, query array,
cache, hash, bitmap, or retained output.  The checked Python boundary returns
one fixed-size violation tuple from Cython.  Measure leaf-directions/s, FST+BAL
lifecycle, fixed allocation, leaf/depth scaling, mixed relation distributions,
real-tree time, and the small-case pairwise reference.

## Immediate Composition

FST-002 establishes artifact conformance and TOP-002 establishes raw contacts.
REL-001, STO-004, restriction/prolongation, refined halos, and refined sampling
consume a successful BAL-001 lifecycle.  Optional TOP-003 may materialize face
relations only for an admitted artifact and only when cache evidence justifies
it.
