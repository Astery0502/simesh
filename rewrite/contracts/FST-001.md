# FST-001 Contract: Cartesian 3D Refined Forest Reconstruction

## Responsibility

FST-001 reconstructs a non-periodic Cartesian 3D octree forest from the
AMRVAC-style Boolean preorder stream into explicit flat integer relations.  It
defines node and leaf identity, levels, logical coordinates, and parent/child
relations.  It does not define geometry, balance, neighbors, halo support,
periodicity, field payload, or I/O.

## Forest Stream And Exact Order

The input stream contains one node flag per preorder node.  `True` denotes a
leaf and `False` denotes an internal node with exactly eight children.  There
is one complete tree for every level-1 root.  Roots occur in MOR-001 dense rank
order.  Children occur in increasing

```text
child = xbit + 2*ybit + 4*zbit
```

so x is fastest, then y, then z.  The zero-based stream position is the node
ID.  Leaves receive dense zero-based leaf IDs in stream order; this is the
canonical field-block order.

Root nodes have level one and the corresponding zero-based MOR-001 root
coordinate.  Child level and coordinate are exactly

```text
child_level = parent_level + 1
child_coord = 2*parent_coord + (xbit, ybit, zbit)
```

AMRVAC tree adapters convert `child_coord` to one-based coordinates by adding
one.  That conversion is not part of FST-001.

## Stable Operation

```text
fill_refined_forest(
    root_shape,
    coord_to_rank,
    rank_to_coord,
    is_leaf,
    node_levels,
    node_coords,
    parent_node_ids,
    child_node_ids,
    node_leaf_ids,
    leaf_node_ids,
    root_node_ids,
) -> max_level
```

Let `R = product(root_shape)`, `K = len(is_leaf)`, and
`L = count_nonzero(is_leaf)`.

- `root_shape`, `coord_to_rank`, and `rank_to_coord` satisfy MOR-001 and are
  borrowed read-only.  Their inverse consistency is validated before output
  mutation.
- `is_leaf` is borrowed read-only, native NumPy `bool`, one-dimensional, and
  C-contiguous with shape `(K,)`.
- Every output is caller-owned, writable, native-endian C-contiguous `int64`.
- `node_levels` has shape `(K,)` and `node_coords` has shape `(K, 3)`.
- `parent_node_ids` has shape `(K,)` and `child_node_ids` has shape `(K, 8)`.
- `node_leaf_ids` has shape `(K,)`, `leaf_node_ids` has shape `(L,)`, and
  `root_node_ids` has shape `(R,)`.
- Inputs and outputs may not overlap; distinct outputs may not overlap.
- Successful execution overwrites every output element and returns the exact
  maximum level.  Inputs are unchanged and no array or pointer is retained.

`refined_forest(...)` is an allocating orchestration helper that returns the
same arrays and scalar in an immutable `RefinedForest` tuple.

## Sentinels And Relations

Exact signed value `-1` is the sole missing-relation sentinel.

- `parent_node_ids[node] == -1` exactly for root nodes.
- A leaf has eight `-1` child entries; an internal node has eight valid child
  node IDs in canonical child-column order.
- `node_leaf_ids[node] == -1` exactly for internal nodes.
- For every leaf `leaf`, `node_leaf_ids[leaf_node_ids[leaf]] == leaf`.
- Every parent/child relation is reciprocal and every non-root node has exactly
  one parent.

## Validation And Errors

The stream must encode exactly `R` complete octrees.  A stream that ends while
a root or child is pending, or that contains nodes after the last root, raises
`ValueError`.  Any node coordinate or complete level logical-grid extent that
cannot be represented in signed `int64` raises `OverflowError`.  FST-001
accepts complete unbalanced octrees; two-to-one balance belongs to refined
topology.

Type or dtype errors raise `TypeError`.  Invalid shapes, contiguity,
writability, overlap, inconsistent MOR maps, or malformed forest structure
raise `ValueError`.  Root-grid volume and refined-coordinate overflow raise
`OverflowError`.  All validation completes before output mutation.

## Exactness, Memory, And Evidence

All FST-001 artifacts are discrete and exact.  Correctness is established by:

- an independent recursive Python reference;
- hard-coded shallow and mixed-depth forests;
- exact parent/child, node/leaf, preorder, and coordinate invariants;
- comparison with current forest roundtrip/count/level behavior;
- exact comparison of reconstructed leaf levels and one-based coordinates
  with representative refined AMRVAC tree metadata;
- malformed-stream and overflow rejection before output mutation.

Required retained output storage is

```text
112*K + 8*L + 8*R bytes.
```

The compiled operation performs one validation traversal and one fill
traversal, uses `O(max_level)` C stack, and performs no heap or per-node
allocation.  Forest reconstruction is one-time metadata work; runtime,
nodes/s, output bytes, fixed Python allocation, and depth/size scaling are
recorded.  Parallel scaling is not relevant.

## Immediate Composition

MOR-001 produces root order and coordinates.  Refined geometry consumes leaf
levels and coordinates.  Refined topology consumes parents, children,
node/leaf maps, and root IDs to classify physical, same-level, coarse, and fine
relations without pointer-owned tree state.
