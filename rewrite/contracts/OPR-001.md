# OPR-001 Contract: Scaled Pointwise Difference

## Responsibility

OPR-001 defines the minimal pointwise operator execution contract and one
representative transform, `left - scale*right`. It maps aligned valid source
cells into a translated caller-owned destination region. It defines no field
names, expression language, callbacks, allocation, chunk planning, storage
selection, halo provision, stencil, reduction, or fused I/O policy.

## Stable Operation

```text
scaled_difference_into(
    source,
    source_valid_lower,
    source_valid_upper,
    left_field_position,
    right_field_position,
    scale,
    destination,
    destination_field_position,
    destination_lower,
) -> None
```

- `source` is borrowed read-only C-contiguous
  `float64[nslot,nsource,sx,sy,sz]`.
- Its borrowed C-contiguous `int64[3]` region is ordered and contained.
- Source field positions are zero-based scalar integers in `[0,nsource)` and
  may be equal.
- `scale` is a finite Python `float` or NumPy `float64` scalar. Integers,
  booleans, narrower NumPy floats, and rank-zero arrays are rejected.
- `destination` is caller-owned writable C-contiguous
  `float64[nslot,ndestination,dx,dy,dz]` with the same slot extent.
- Its field position is in `[0,ndestination)`, and borrowed C-contiguous
  `int64[3] destination_lower` translates the source extent into bounds.

Source and destination may not overlap. Destination may not overlap region
metadata; read-only inputs may overlap one another. Nothing is retained.

## Arithmetic And Mutation

For source spatial offset `q` in the valid extent and each slot `s`, evaluate
two separate binary64 operations with no fused multiply-add:

```text
product = scale * source[s,right_field_position,source_valid_lower + q]
result  = source[s,left_field_position,source_valid_lower + q] - product
destination[s,destination_field_position,destination_lower + q] = result.
```

Only that one destination field and translated box may change. Other fields,
slots, and spatial cells remain bitwise preserved. Inputs remain unchanged.
The produced destination-valid box for that field is exactly
`[destination_lower,destination_lower + extent)`; validity for other destination
fields remains caller state.

The operation is FND-002 `POINTWISE` with exact lower and upper reach
`(0,0,0)`. It reads no halo relative to its requested output cells.

## Validation And Atomicity

Before mutation, validate exact ndarray types/dtypes/ranks/C-contiguity,
destination writability, equal slot extents, source box ordering/containment,
field positions, finite scale, destination lower/translated containment,
signed-`int64` translation, and forbidden overlap. Field positions are checked
even for empty slot or spatial selections.

An empty slot axis or spatial region is a validated no-op. Invalid calls leave
destination unchanged. Type/dtype/scalar-kind failures raise `TypeError`;
invalid layout, region, field, scale finiteness, output, writability, or overlap
raises `ValueError`; unrepresentable translation raises `OverflowError`.

## Numerical Evidence

Region/field mapping and preservation are exact. When the intermediate product
and reference result are finite, scalar and current comparisons report maximum
absolute, relative, and ULP error and use

```text
8 * eps * max(1, abs(left), abs(scale*right), abs(reference)).
```

Relative error is included only where
`abs(reference) >= sqrt(eps) * local_scale`, so cancellation is represented by
the absolute bound rather than a meaningless ratio. ULP distance is reported
only for finite nonzero results. Signed zeros compare by exact bit; NaN,
infinity, and finite-input product overflow compare IEEE classification/sign and
the fixed multiply-then-subtract behavior. The current arithmetic-derived
recipe `e - 0.5*rho` is the behavioral comparison; field-name registration and
result appending remain adapter responsibilities.

## Performance And Memory

The Cython kernel visits each selected source value pair once and writes one
result, with no payload-, field-, slot-, or region-sized scratch. Measure values
per second, effective read/read/write bandwidth, region/field/slot scaling,
fixed allocation, NumPy/current runtime, and bounded
plan/gather/compute/scatter composition. Explore in-place or fused storage only
after the separate contract is correct and measured.

## Immediate Composition

FND-002 supplies zero-reach semantics. STO-002 plans primary chunks; STO-001
gathers selected input fields and scatters the derived output. OPR-002 later
extends the execution model to one-cell local stencils, and INT-001 consumes the
bounded pointwise path.
