# LFE-001 Contract: Bounded Selected Refined Curl And Regional Sum

## Responsibility

LFE-001 schedules one bounded refined Cartesian curl over explicit leaf-local
ROI windows, writes compact selected results, and adds one curl component to a
persistent serial regional sum. It owns one shared magnetic read/halo traversal,
equal-window run grouping, compact placement, reduction order, workspace, and
statistics. It defines no ROI/curl/halo/reduction meaning, reader backend,
cache, volume weighting, derived-field registry, dataset lifecycle, or
streamline behavior.

## Stable Operation

```text
execute_selected_refined_curl_from_blocks(
    reader,
    primary_leaf_ids,
    cell_lower,
    cell_upper,
    magnetic_field_ids,
    domain_lower,
    domain_upper,
    domain_cell_counts,
    block_cell_counts,
    max_level,
    root_shape,
    coord_to_rank,
    root_node_ids,
    node_levels,
    node_coords,
    child_node_ids,
    node_leaf_ids,
    leaf_node_ids,
    boundary_modes,
    normal_field_slots,
    slot_capacity,
    curl_values,
    reduction_component,
    accumulator,
) -> SelectedCurlExecutionStats
```

`reader` is a STO-003 block reader of shape `(L,Fsource,Bx,By,Bz)`.
`primary_leaf_ids int64[P]` is C-contiguous, strictly increasing, and valid.
`cell_lower/cell_upper int64[P,3]` are paired nonempty local boxes satisfying
`0 <= lower < upper <= block_cell_counts`; normal composition passes one
unchanged ROI-001 result. `magnetic_field_ids int64[3]` names `(Bx,By,Bz)` in
the reader; order and repeats are allowed.

Domain/count/MOR/FST metadata and `max_level` belong to one unchanged
FST-002/GEO-002 lifecycle. `boundary_modes uint8[3,6]` and
`normal_field_slots int64[3]` refer to the three local selected magnetic
positions and have RHE-001 semantics. The block shape is even and at least four
on every axis; LFE requests exactly one lower/upper halo layer and uses RHE's
all-26 support scope. `slot_capacity` satisfies RHE progress.

`curl_values` is caller-owned writable C-contiguous
`float64[P,3,Bx,By,Bz]`, aligned with the primary/ROI rows. Only
`curl_values[p,:,cell_lower[p]:cell_upper[p]]` is overwritten; all other cells
are bitwise preserved. `accumulator` is caller-owned writable C-contiguous
`float64[1]` with RED-001 state semantics. `reduction_component` is an exact
integer in `[0,3)` and selects Jx/Jy/Jz. The operation adds to the caller's
initial state; it does not reset or finalize it.

Mutable outputs are pairwise nonoverlapping and may not overlap reader memory,
metadata, or internal workspace. Inputs remain unchanged and no caller view is
retained.

## Geometry, Curl, And Run Composition

Before I/O, run GEO-002 over all primary IDs into call-scoped
`leaf_bounds float64[P,2,3]` and `slot_cell_spacing float64[P,3]`. Bounds close
the selected numerical-geometry preflight; spacing feeds OPR-003. No full-leaf
geometry table is materialized.

RHC-001 reads selected magnetic fields and completes one-cell halos. For each
completed primary prefix, verify IDs equal the exact input slice and partition
its rows into maximal consecutive runs with identical `(cell_lower,cell_upper)`.
For one run and local box `[q0,q1)`:

```text
source output box = [interior_lower + q0, interior_lower + q1)
destination box   = [q0,q1)
```

Call the unchecked OPR-003 kernel once over the completed payload run and its
per-slot spacing, writing the corresponding compact `curl_values` rows. No
halo copy, six derivative arrays, curl staging payload, or uniform grid is
created.

Immediately after that run's curl succeeds, call RED-001 over the same compact
rows/box and selected component. RHC primary rows are ascending, runs preserve
them, and RED visits slot/x/y/z ascending. Thus the global addition order is
exactly primary leaf ID, x, y, z and is independent of `slot_capacity`.
The result is an unweighted sum of cell-centered values, not a physical volume
integral; mixed refinement cells contribute one value each.

## Validation, Atomicity, And External Failure

Before the RHC empty reader call or any output mutation, validate exact
descriptor/ndarray types, dtypes, ranks, shapes, C-contiguity, output
writability/nonoverlap, strict primary order, paired boxes, field IDs,
boundary configuration, capacity/byte arithmetic, reduction component/state,
all selected GEO spacing/bounds, every translated curl stencil/output box, and
all RHC/RHE support/action geometry. Ordinary failures leave `curl_values` and
`accumulator` unchanged and make no nonempty read.

Type/dtype/scalar-kind failures raise `TypeError`; invalid selection, layout,
box, field, geometry, PBC, halo support, accumulator, or overlap raises
`ValueError`; integer/byte overflow raises `OverflowError`.

After preflight, a reader failure leaves the failed chunk untouched but retains
earlier completed compact rows and accumulator updates. An unexpected consumer/
resource failure may partially mutate its current run; earlier work is not
rolled back. External file errors inherit DAT-003/RHC semantics. Empty primary
selection is a validated no-op that preserves both outputs and accumulator.

## Statistics And Memory

Success returns exact Python integers:

```text
primary_count
output_cell_count
output_value_count              3 * output_cell_count
chunk_count
reader_call_count
consumer_call_count
operator_call_count
reduction_call_count
selected_load_count
support_load_count              selected_load_count - primary_count
maximum_selected_slots
logical_reader_bytes            selected_load_count * 3 * product(B) * 8
managed_array_bytes
```

Managed bytes include RHC workspace, selected leaf bounds/spacing, reduction
execution state owned by LFE, and fixed/box-run scratch arrays. Caller ROI
arrays, `curl_values`, `accumulator`, immutable DAT/FST metadata, native reader
offsets/transfer buffers, page cache, Python objects, and process RSS are
reported separately. `output_cell_count` is the exact sum of ROI window
volumes. Operator/reduction calls equal the maximal identical-window runs
within RHC chunks, not necessarily chunks or leaves.

## Correctness And Numerical Evidence

ROI IDs/boxes, chunk offsets/IDs, calls, cells, bytes, and stats compare exactly.
Compact curl uses OPR-003 numerical metrics. The accumulator must be bitwise
equal across capacities and to a manual primary/x/y/z serial sum over the final
selected curl component. Unselected output bits and all source bytes are
preserved.

Evidence includes empty/single/thin/non-block-aligned/full windows; mixed levels
and unequal consecutive boxes; all refined SAME/FINER/COARSER/pure/mixed
physical halos and PBC modes; reordered/repeated magnetic fields; native and
array readers; minimum/intermediate/full capacities; first/later reader failure;
and synthetic affine/smooth plus real tdm/WENO-bridge fields. Safe common cells
compare with current derived-current behavior under recorded operation-tree and
geometry differences.

## Performance And Immediate Consumer

LFE-001 is `milestone-workflow`. For small, medium, and full physical regions,
record metadata/ROI/first-result and cold/warm runtime; primary/support counts,
block-cover amplification, logical/native header/payload/useful/output bytes;
chunk/reader/consumer/operator/reduction calls; halo/curl/reduction stages;
managed/output memory, faults, and RSS; capacity scaling; and native/array/
current numerical results.

The next streamline slice remains separate. Hierarchy-pruned ROI lookup,
direction-projected support, cached headers/payload, generic scientific recipes,
volume-weighted integrals, external result writers, and parallelism reopen only
from this or later measured consumers.
