# HPR-001: Owned Halo Preflight

Frozen: 2026-09-07, independent review approved with the conditions below.
Composition-only implementation of the unchanged RHE/RHC/CHS numerical and
failure contracts; dependencies and promotion gate are in
[round evidence](../evidence/M1-OPTIMIZATION-ROUND.md).

The private executor may reuse CSP representation proofs from its allocator
(native dtype, contiguous writable disjoint outputs), accepted SPR prefix
(primary slot), unchanged canonical REL/RSL/RPH producer lifecycle (phase and
action identity), outer RHE admission (even B>=4, reach<=B/2), and checked CWP
(target-side rules, phase range, arithmetic and exact generated CWP boxes).

Validate the entire CSP relation row lazily on the first nonempty unmasked
COARSER action of each primary. This proof expires at the end of that primary
inside the same preflight invocation. Retain the guard before unchecked RPH.
For every CSP action, retain the original `_validate_plan_geometry`, then the
unchanged compiled generator, output count/slot/flag checks, PWA physical-suffix
validation and checked zero-field PRL. Primary PWA and SAME/FINER checks remain.
No new proof crosses a callback; existing all-chunk preflight retains its
unchanged lifecycle requirements.

No public unchecked operation or new shared artifact is introduced. Standalone
CSP remains completely checked and atomic. Full checked RHE preflight and
pre-optimization M1 preflight remain private substitution references.
Generated CSP arrays/counts, output bits, calls, selected loads, valid coverage,
failure order and managed-array formulas must match those references. No
persistent plan or additional ndarray is retained. Transient tuples are bounded
by one action, independently of leaf count. The first-use validation flag is a
local scalar, reset for each primary and invocation.

Tests cover intermediate plans, mixed physical/coarse support, asymmetric/zero
reach, output/stat/I/O equality, and malformed relation/geometry rejection
before nonempty I/O. Existing scientific acceptance is preserved by the complete
LFE/CHS/SLE regression suites; this is not a new derivative interpretation.
