# SAM-002 Evidence

## Correctness, Ownership, And Integration

Eleven focused tests and all 105 accumulated rewrite tests pass. Retained
coverage includes independent canonical-face owner maps, exact native cell and
block-face ties, native/coarse/fine/subdomain resolutions, safe large origins,
padded/reordered/repeated/partial/empty selections, exact input and unselected-
output bit preservation, and atomic bounds/spacing/map/region/field/readonly/
overlap failures.

Exact one-dimensional probes on four native cells produce owner sequences:

```text
native 4 points:             0 1 2 3
full-domain 3 points:        0 2 3
full-domain 7 points:        0 0 1 2 2 3 3
[0.75,3.25], 5 points:       1 1 2 2 3
```

Centers exactly on a native cell or block face select the upper owner. For
unique selected IDs, block/chunk order is therefore irrelevant; repeated IDs
retain slot-order last-write semantics. A no-closure STO-002 traversal gathers
only primary interiors through STO-001 and reconstructs the arbitrary sample
grid bitwise equal to a one-shot call.

Independent audit ran 1,000 randomized bitwise owner/value cases before the
final optimization and found exact agreement. Final re-audit confirmed that the
arithmetic candidate is used only when canonical faces bracket it exactly and
otherwise falls back to highest-face binary search. The audit found no remaining
correctness, atomicity, or performance defect.

## Current Evidence And Deliberate Differences

Current sampling agrees bitwise for all retained safe native, coarse, subdomain,
and large-origin cases. At an exact shared block face, its lower block also
visits the output and forms a one-past-end local index while the upper block
writes the intended value; serial order happens to leave the same upper result,
but OpenMP traversal has an overlapping-write race. SAM-002 has one owner and no
out-of-bounds read.

On the benchmark's `96x72x48` fine grid over `64x48x32` native cells, many
centers lie exactly on source faces. Current differs in 69,120 of 331,776 values
(20.8%); four fields produce exactly four times as many differences. These are
discrete owner/read differences and are not hidden by tolerance.

The rewrite rejects current's exterior-bounds behavior, which silently leaves
outside output cells untouched, and rejects an outer-center-collapsed
`1e16..1e16+8` grid for which current produced an out-of-bounds garbage bit. It
accepts GEO-valid coincident internal faces and applies highest-face ownership.
A retained two-cell example samples `[20,20]` while SAM-001 exact placement is
`[10,20]`; this is why native dispatch is conditional rather than assumed.
Independent contract review initially rejected the unconditional native claim,
then accepted the corrected coincident-face policy.

## Runtime, Scaling, And Memory

The retained standalone benchmark uses an `8x6x4` root, `8^3` blocks, and 21
repeats:

| Fields | Scenario | Output | Runtime | Mvalue/s | Current | Current mismatches |
| ---: | --- | ---: | ---: | ---: | ---: | ---: |
| 1 | coarse | `32x24x16` | 0.300 ms | 40.9 | 0.018 ms | 0 |
| 1 | native | `64x48x32` | 1.118 ms | 87.9 | 0.105 ms | 0 |
| 1 | fine | `96x72x48` | 3.020 ms | 109.9 | 0.342 ms | 69,120 |
| 1 | subdomain | `40x30x20` | 0.410 ms | 58.6 | 0.030 ms | 0 |
| 4 | coarse | `32x24x16` | 0.311 ms | 157.9 | 0.039 ms | 0 |
| 4 | native | `64x48x32` | 1.259 ms | 312.4 | 0.278 ms | 0 |
| 4 | fine | `96x72x48` | 3.711 ms | 357.6 | 0.951 ms | 276,480 |
| 4 | subdomain | `40x30x20` | 0.460 ms | 208.8 | 0.076 ms | 0 |

The large shuffled four-field fine case takes 3.710 ms versus 3.711 ms ordered,
showing no material order penalty under disjoint ownership. Direct calls retain
64 traced bytes with a fixed 3,080-byte peak. The general sampler is slower than
the current unsafe arithmetic/OpenMP path but provides the defined face and
collapsed-grid behavior above.

For four-field fine subdomain composition, capacity 32 uses six chunks, 524,544
managed workspace bytes, and 4.169 ms (318.3 Mvalue/s); capacity 128 uses two
chunks, 2,098,176 bytes, and 3.926 ms (338.1 Mvalue/s). Both equal one-shot
sampling bitwise, with traced peaks of 4,152 and 3,672 bytes. A small independent
reference takes 3.615 ms versus 51.0 us compiled, a 70.9x speedup.

The arithmetic-candidate/verified-fallback owner improved representative
general and bounded paths by 2.3--2.4x. A typical inline guarded native dispatch
was another 6.7x faster, but its proof repeated per chunk and took 11.9 ms for
an empty two-million-cell axis; it was removed after independent audit. The
retained implementation uses no resolution-sized owner arrays. Further native
dispatch belongs in an executor that proves ownership once, and parallel work
waits for an explicit unique-chunk execution policy.
