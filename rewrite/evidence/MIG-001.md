# MIG-001 Evidence

## Source-Wide Audit

The audit covered the canonical `simesh.amrvac`, `simesh.utils`, and
`simesh.tools` source trees plus the preserved legacy tree and current tests.
It identified feature families for layout, forest/topology, geometry/mesh,
halos, sampling, scientific/derived operations, AMRVAC reads/writes,
construction/export, dataset/public APIs, independent tools, runtime/build,
and legacy disposition.

M0 closes only the Cartesian 3D level-1 subset of the numerical families.
M1--M3 are correctly ordered for refined 3D, dimensional generalization, and
periodicity, but do not close the remaining source surface. The accepted
roadmap therefore adds M4 operators/derived fields, M5 I/O/construction/export,
M6 dataset/public API, and M7 packaging/parallelism/cutover, with real-data
vertical slices during M1--M3.

Independent review agreed that feature behavior and public workflows are the
correct migration unit, legacy code should remain evidence rather than an
automatic port target, and final completion needs an explicit disposition for
every canonical feature family. The resulting inventory and cutover gate are
recorded in `SOURCE_MIGRATION.md` and linked from the charter, workflow,
roadmap, capability ledger, and current checkpoint.
