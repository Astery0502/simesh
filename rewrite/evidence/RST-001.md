## Kernel Optimization, Scaling, And Allocation

Correctness was frozen with an explicit-statement kernel.  The first credible
variant replaced volatile local temporaries with ordinary binary64 locals;
normal project compiler flags preserve statement order, and every exact output
gate remains bitwise identical.  On the standard workload this changes checked
runtime from about 0.995 ms to 0.199 ms, roughly 5x faster.  The final kernel is
also 4.7x faster than a caller-buffered vectorized NumPy comparator using the
same seven-step tree.

Final Apple arm64 standard workload `float64[64,4,16,16,16]`:

| Path | Runtime ms | M coarse field-cells/s | M fine values/s | Effective GB/s |
| --- | ---: | ---: | ---: | ---: |
| Checked RST | 0.199 | 659.5 | 5,275.9 | 47.48 |
| Unchecked kernel | 0.191 | 685.9 | 5,487.5 | 49.39 |
| Exact-order NumPy | 0.943 | 139.1 | 1,112.5 | 10.01 |

Interleaved timing removes cache-order bias.  Standard checked-boundary cost is
4.0%; fixed validation is visible only on very small calls, where checked RST
still matches or beats the NumPy comparator.  A checked call retains zero
traced bytes and peaks at 1,056 bytes; its caller output is 1,048,576 bytes.

and exact STO progress capacity 37.  A full 480,480-byte REL table is used only

The resident compact RST call is 0.148 ms and emits 586,752 bytes.  At capacity
256, relation generation/compaction, STO planning, FINER extraction, gather,
RST, and result placement take 0.167/0.120/0.326/4.204/0.236/0.189/0.027 ms.
The later source-extraction/slot-planning decision dominates; full capacity is
slower because one Python list uniqueness scan takes 5.88 ms.  Optimizing that
policy inside RST would violate the approved boundary.

The nonvolatile loop materially improves the only numerical variant, the
checked boundary is amortized at useful batches, and RST is already a small
part of the exact composed path.  Further fusion, hidden scratch, selectors, or
parallel machinery has no credible RST-level runtime-memory-complexity benefit,
so optimization stops.
