# RHE-001 Design: Bounded Selected Refined Halo Execution

## Choice

Build a new selected pull-based executor over the functional reader/writer
boundary.  It fixes canonical x-fast all-26 directions because the concrete
consumer produces a complete rectangular halo.  SPR plans each bounded chunk;
REL/RSL/RPH and every CWP/CSP application plan are complete before that chunk's
payload read.  One reader call gathers all selected interiors, base actions run
before physical widening, and one writer call emits only the primary prefix.

Extending INT-001 or HAL-002 was rejected because their dense level-1 traversal
and fused sibling semantics would absorb refinement, support, and execution
policy.  Returning a resident `P`-sized output was rejected as the only API;
the existing BlockWriter supports both a caller-owned array and bounded native
consumers.  A second full-query REL dry pass was rejected for time to first
result: under FST/BAL lifecycle, canonical all-26, CSP's scope gate, and
`capacity>=min(57,leaf_count)`, progress and support are already proven.

The first complete standard run then showed that the deliberately simple
standalone-wrapper preflight consumed 92.2% of medium wall time.  The retained
checked reference validates CWA, zero-field copy/RST, and every lower wrapper
separately.  Production now uses an equivalent narrower proof: checked SLB or
FRP; checked CWP plus checked CSP; CSP-physical PWA validation; zero-field PRL;
primary PWA validation; and explicit kind/count/slot guards before unchecked
RPH or payload I/O.  It does not repeat CWA plan scans or zero-field value
wrappers after their producer already proved the same boxes, ratios, coverage,
modes, and internal nonaliasing buffers.

Two independent reviews approved that proof boundary.  Focused equivalence
checks preserve every output bit, stat, byte, and callback.  Retained standard
before/after raw records improve small, medium, and full wall time by 1.82x,
1.90x, and 2.29x.  The complete checked preflight remains available as a
private reference and reopens if workspace/plan inputs become external or
direction, balance, reach, or lifecycle assumptions change.

## Decomposition Record

Responsibility: schedule one bounded selected complete-refined-halo traversal
through explicit reader/writer and caller-selected fields.

Owned decisions: conservative capacity gate; per-chunk REL/SPR/RSL/RPH plan
lifetime; one-read/one-write scheduling; reusable workspaces; base-action,
CWA/PRL, then PWA order; accounting and external failure boundary.

Explicitly non-owned decisions: forest/balance/REL semantics, primary selection,
support union, boxes/phases, physical/RST/PRL values, adapter behavior, cache,
local operator/sampler, parallelism, periodicity, or 2D.

Inputs/outputs: validated FST/BAL arrays, sorted primary IDs, functional block
reader/writer, field selection and boundary rules, side reach, and slot
capacity; output is writer state plus immutable execution counts.

Mutation/ownership: internal buffers live only for the call; reader/metadata are
borrowed; only writer-owned selected-primary destinations change.  External I/O
failures may leave a completed prefix under STO-003.

Access/halo reach: complete requested rectangle with `B>=4` and each side
`<=B/2`; support interiors only; support halos are never read or written.

Reference/invariant: resident independent per-primary composition; bounded/full
capacity exact equivalence; current safe dyadic refined halo comparison.

Immediate producer/consumer: explicit leaf/field selection produces inputs;
refined sampling and selected local-field execution consume the writer or the
same completed primary workspace after this group.

Performance class: composition-only at complete selected halo execution.  The
later native/local M1 slices promote the surrounding workflows, not RHE's
numerical semantics.

Five-question result: yes/yes/yes/yes/yes.  RHE is a justified executor whose
only large responsibility is explicit scheduling/resource policy over frozen
semantic functions.
