# PRL-001 Design: Cartesian 3D Ratio-Two Limited Prolongation

## Problem And Current Behavior

Current refined halo interpolation maps each fine target coordinate to a coarse
center, evaluates three LIM-001 axial slopes, and reconstructs in x/y/z order.
Its physical-coordinate map identifies the correct coarse cell but introduces
small eta rounding noise.  Relation selection, source-slot mapping, coarse
workspace assembly, physical rules, and transfer scheduling surround this
transformation and vary independently.

## Alternatives

Preserving physical-coordinate eta would couple prolongation to rounded
`rnode` geometry.  A separate index/weight plan would materialize output-sized
arrays for a ratio-two rule with no other consumer.  Fusing relation lookup,
workspace assembly, and halo targeting would recreate the current dispatcher.

Use one canonical ratio-two transformation with explicit fine/coarse alignment
origins.  Mathematical floor mapping gives the coarse center and phase inline;
phase fixes eta to exact binary64 `-0.25` or `+0.25`.  LIM remains the shared
independent slope rule.  The caller separately provides a valid coarse
workspace and explicit fine target box.

An audit over all 22,614 WENO leaves found zero coarse-index differences between
current and integer mapping, but 27 current eta bit patterns with maximum
absolute deviation `2.842170943040401e-14`.  Exact phase eta is an intentional
rounding cleanup; non-dyadic current comparisons use recorded numeric error
rather than bitwise identity.

## Decomposition Record

Responsibility: reconstruct an explicit fine target box from an aligned
ratio-two coarse workspace using exact phase weights and LIM-001 axial slopes.

Owned decisions: mathematical floor coarse mapping; phase; exact `+/-0.25`
eta; the seven-cell axial cross; three LIM calls; separate slope products;
x/y/z addition order; required coarse valid reach; explicit fine-box mutation;
empty behavior, validation, and atomicity.

Explicitly non-owned decisions: REL kind/sources; selected support or slot map;
which leaf/direction/halo box needs prolongation; coarse workspace assembly,
layout choice, or lifetime; RST placement; physical transforms; field
selection; backend; chunking/scheduling; periodicity; or 2D.

Inputs and outputs: borrowed canonical coarse payload plus valid box and
alignment origin; caller-owned canonical fine payload plus target box and
alignment origin.  Leading slot/field extents match.

Mutation and ownership: only the fine target box is overwritten.  Coarse input
and all metadata remain unchanged; output/input overlap is forbidden; nothing
is retained.  The kernel allocates no payload- or size-dependent scratch;
fixed checked-boundary objects are measured.

Access pattern and reach: each output reads the mapped center and its six axial
neighbors.  The mapped center range expanded one lower and upper cell on every
axis must lie in the declared coarse valid box; diagonals are not read.

Independent reference and invariants: scalar floor/phase mapping; exact eta
bits; manual LIM reference and separate products/additions; all eight phases;
constant/affine/step/quadratic fields; axial poison versus diagonal poison;
signed-zero/nonfinite order; partial translated boxes; RST/workspace
composition; current dyadic bitwise comparisons; and non-dyadic current maximum
absolute/relative/ULP differences checked against the slope-weighted eta delta
plus the fixed six-operation binary64 roundoff bound in the contract.

Immediate producer and consumer: RST plus a later workspace assembler supplies
coarse self/neighbor/physical values and validity.  A later refined transfer
application chooses explicit targets and invokes PRL.  PRL consumes no IDs,
relations, masks, boundary modes, or execution plan.

Kernel and composed measurement boundary: fine field-cells/s, effective
64-byte traffic, validation, phase distribution, target/field/slot scaling,
output bytes, fixed allocation, scalar reference, current descriptive
comparison, and separate workspace/PRL times.  Transfer planning and assembly
remain separately reported.

Five-question result: yes/yes/yes/yes/yes.  Integer phase mapping and limited
reconstruction jointly define one ratio-two transformation, require no plan
artifact, and are independently testable/substitutable/measurable without
storage or scheduling policy.

## Performance Gate

The standard direct workload uses coarse `float64[64,4,10,10,10]`, full valid
box, coarse origin `[1,1,1]`, and fine `float64[64,4,16,16,16]` with origin
`[0,0,0]`.  Scale even/odd/translated target boxes, fine extents 4/8/16/32,
fields 1/4/8, and slots 1/8/64/256.

Freeze exact output first, then compare two allocation-free loop organizations:

1. fine-output-centric mapping and repeated slopes, closest to current;
2. coarse-center-centric slopes reused for up to eight clipped children.

Exact bits, target preservation, zero retained scratch, and equal reach are hard
gates.  Report validated/unchecked/reference/current and composed workspace/PRL
stages.  Investigate >10% and block reproduced >20% regressions absent a
documented memory/complexity benefit.  Defer slope arrays and parallelism unless
composed profiling demonstrates material benefit.
