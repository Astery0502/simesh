# PWA-001 Design: Cartesian Physical Widening

## Choice

Apply PBC-001 to explicit completed base rectangles in one target payload slot.
Each row carries the true nonnegative logical block interior and an exact
storage-to-logical coordinate offset separately from its clipped base.  The
target is wholly owned: complete preflight proves every field-specific mapped
source lies in the base, target rows do not overlap, and no target intersects
any batch base.  The kernel can then map, load once, transform x/y/z, and write
without ownership branches or reading prior writes.

A per-phase candidate operation was rejected.  Its target rows overlap and
would require field/mode-dependent mapped-preimage ownership tests in the hot
loop.  Both concrete consumers can first complete the reduced-direction base:
FRP phases partition one primary base, and CSP transfer records complete every
coarse-workspace base before its physical suffix.  Passing a signed shifted
interior without an offset is smaller but obscures that PBC-001's stable public
interior remains nonnegative.

## Decomposition Record

Responsibility: widen explicit valid Cartesian base rectangles into disjoint
physical or mixed-physical target rectangles using PBC-001 rules.

Owned decisions: storage/logical translation, row target traversal, one mapped
load, ascending x/y/z transforms, exact write/preservation set, and batch RAW/
WAW safety.

Explicitly non-owned decisions: physical-face discovery, topology/relation,
base construction, support, copy/restriction/prolongation, workspace lifetime,
backend, scheduling, periodicity, or 2D.

Inputs/outputs: one writable canonical payload, one target slot, per-row
logical interiors/offsets/directions/masks/base/target boxes, and PBC mode data.

Mutation/ownership: only the disjoint target union in the selected slot changes;
all bases, other slots, and exterior cells are preserved; preflight is atomic.

Access/halo reach: reads only the declared bases.  Reflected depth is limited by
the true logical interior, not by base extent.

Independent reference/invariant: Python integer coordinate mapping and
bit-exact PBC value transforms; every target image is contained in its base.

Immediate producers/consumers: completed SAME/RST/PRL or CSP/CWA bases produce
inputs; CWA and RHE consume the widened values.

Performance class: hot-kernel.  Record candidate/written field-cells, effective
bytes, checked/unchecked runtime, fixed allocation, and CWA/RHE composition.
The standard cases mix all modes/faces and compare pure physical widening with
HAL and mixed widening with HAX; the expected result is no more than 20%
per-written-cell regression against the corresponding compiled comparator,
without size-dependent allocation.

Five-question result: yes/yes/yes/yes/yes.  Independent review found the
clipped-base/interior and overlapping-phase counterexamples; completing bases
before PWA permits the narrower branch-free contract selected here.
