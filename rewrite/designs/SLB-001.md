# SLB-001 Design: Cartesian Same-Level Source Boxes

## Decision

Extract one topology-free ratio-one translation from target boxes to selected
same-level source boxes.  It consumes reduced nonphysical directions; relation
filtering, physical masks, slots, and payload copying stay outside.

For interior `M=[m,m+B)`, target row `U`, and reduced direction `r`, the exact
source is `S = U - r*B` componentwise.  Side widths may be asymmetric or zero,
but source boxes remain inside `M`.

## Decomposition Record

Responsibility: translate explicit directed target boxes to equal-extent
same-level source boxes.

Owned decisions: ratio-one layer-preserving translation, side/neutral target
compatibility, containment, direction order/empty rows, validation/atomicity.

Nonowned: relation/action/mask/slot; physical mapping; reach choice; refinement
phase; FINER/COARSER geometry; values/payload; backend/scheduling/2D policy.

Reference/evidence: Python affine translation; all directions and side widths;
TGT composition; current level-one unique-constant halos; one-slot FND copy;
atomic malformed boxes.  Measure rows/s, copied cells/s, exact 48*R bytes, fixed
allocation, and native materialize/reuse versus inline translation.

Five-question result: yes/yes/yes/yes/yes.  SLB is one independently
substitutable affine box rule with an immediate copy consumer and no policy.
