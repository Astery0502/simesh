# RPH-001 Design: Refined Relation Child Phases

## Problem And Alternatives

Ratio-two restriction/prolongation needs the child phase associated with each
accepted COARSER or FINER relation.  REL/RSL preserve source order/identity but
do not emit phase.  Recomputing FST parity inside value loops repeats semantic
validation; combining phase with TGT boxes failed the decomposition gate.

Use one compact caller-buffered phase tensor matching accepted REL shape.
COARSER records use primary parity, FINER records use source parity, and exact
`255` marks SAME/PHYSICAL/inactive columns.  It emits no action or box.

## Decomposition Record

Responsibility: derive and validate ratio-two child-column phase codes for
accepted REL/RSL records.

Owned decisions: primary/source node parity; COARSER/FINER relative level;
COARSER reduced-coordinate identity; FINER direction-touch compatibility;
physical-mask neutrality; FINER canonical phase order/count; inactive/non-ratio
sentinel; validation and atomicity.

Explicitly non-owned decisions: relation classification or slot identity;
target/source boxes; PBC narrowing; requested reach; RST/PRL values; workspace
assembly/lifetime; payload mutation; cache/backend/scheduling/parallelism;
periodicity; or 2D.

Inputs and output: unique selected leaf IDs; FST levels/coordinates/leaf map;
directions; accepted kind/mask/count and RSL slot tensors; caller-owned
`uint8[P,D,4]` phase codes.

Mutation and ownership: complete representation/level/phase preflight precedes
output; output is fully overwritten; nothing is retained; no size-dependent
scratch is allocated.

Independent reference and invariants: Python parity/common-level checks; all
eight phases, directions/kinds/masks/counts/order; mixed physical neutrality;
random balanced forests/WENO; current safe connectivity phase facts;
RST/PRL phase-coded consumer probes; complete malformed/atomic cases.

Immediate producer and consumer: unchanged FST plus accepted REL/RSL produce
RPH.  A later PBC-aware workspace/value application combines RPH with TGT and
numerical kernels.  RPH touches no boxes or values.

Kernel and composed measurement boundary: records/s, active phases/s,
selected/support/primary/direction/depth/mask/count scaling, fixed allocation,
exact `4*P*D` bytes, reference/current evidence, and native materialize/reuse
versus inline derivation.

Five-question result: yes/yes/yes/yes/yes.  RPH owns one refinement-parity fact
set, is independently substitutable/measurable, and contains no region,
numerical, storage, or scheduling policy.

## Performance Gate

Use all kinds/phases/masks in synthetic balanced forests and bounded WENO rows;
vary selected/support size independently from accepted primary rows.
Exact codes/order/sentinels and bytes are hard gates.  Compare checked,
unchecked, reference, and equivalent native materialize-once versus repeated
derivation including artifact creation.

Investigate >10% and block reproduced >20% composed regressions absent a
documented memory/complexity benefit.  Do not add boxes, action enums, payload
scratch, dense maps, hashes, dynamic dispatch, or parallelism.
