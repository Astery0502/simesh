# TOP-002 Design: Exact Refined Contact Lookup

## Responsibility

TOP-002 answers explicit leaf/direction contact queries by returning the raw
FST node that covers the adjacent logical block at the source leaf's level, or
the physical sentinel.  It owns no balance/admissibility rule and retains no
global face/edge/corner cache.

## Boundary Decision

The preserved pre-audit drafts combined four independently variable decisions.
They are now assigned as follows:

- FST-002 validates caller-supplied flat forest artifacts once;
- TOP-002 locates exact contacts on balanced or unbalanced forests;
- BAL-001 applies the global face/edge/corner two-to-one policy using TOP-002;
- optional TOP-003 may retain six balanced face relations only if a consumer
  and cached-versus-on-demand benchmark justify the memory.

REL-001 later owns edge/corner/mixed-physical operation records.  STO-004 owns
support union, ordering, capacity, and traversal.  Neither decision enters
TOP-002.

## Selected Semantic Shape

A batched caller-buffered operation receives source leaf IDs and aligned
directions in `{-1,0,1}^3` excluding center.  It descends from the exact MOR
root to at most the source level.  It returns:

- `-1` when the target logical block is outside the non-periodic domain;
- the first covering coarser leaf node when descent stops early;
- the same-level leaf node when descent reaches a leaf at the source level;
- the internal node at the source level when the target region is subdivided.

Node level and `node_leaf_ids` classify the raw result; TOP-002 does not collapse
it into SAME/COARSER/FINER policy codes.  Repeated and reordered queries are
independent and deterministic.  Unbalanced targets are valid outputs.

Production descends child pointers in `O(source_level)`.  The independent
reference builds a Python `(level,coordinate)->node` dictionary and searches
ancestors without following children, so agreement is not tautological.  A
global retained contact table is deliberately absent; callers batch only the
directions they require.

## Decomposition Record

Responsibility: locate one exact adjacent logical region in the validated flat
forest.

Owned decisions: source-level logical target, non-periodic physical detection,
MOR root selection, canonical child descent, raw target-node sentinel, query
ordering, and atomic output behavior.

Explicitly non-owned decisions: FST artifact conformance, allowed level gaps,
face-cache retention/kind codes, fine-child expansion, geometry, support
planning, halo values, storage, periodicity, and scheduling.

Independent reference: a common-finest-lattice/brute-force leaf-box locator
for small forests plus exact current relation comparisons where current is
defined.

Producer/consumer: FST-002 supplies validated arrays; BAL-001 and REL-001
consume raw contacts.  TOP-003 is an optional cache consumer.

Measurement: contacts/s by depth/kind/query order and FST+lookup composition;
no retained topology bytes beyond caller query outputs.

Five-question result: yes/yes/yes/yes/yes.  Contact meaning is independent of
admissibility and cache policy.

## Performance Gate

Measure all 26 directions on synthetic levels one through five and six faces on
the real tree.  Report contacts/s, fixed allocation, output bytes, kind/depth
mix, and one preceding FST-002 validation.  The on-demand lookup need not beat a
prebuilt current table, but it must remain linear in query count times depth and
avoid leaf-sized retained state.  A later TOP-003 decision compares repeated
on-demand use with exact `54*L` cache cost before retaining faces.
