# FST-001 Design: Cartesian 3D Refined Forest Reconstruction

## Problem

M1 needs to recover a complete octree forest from the AMRVAC Boolean preorder
stream.  The current implementation allocates pointer-owned nodes, assigns
neighbors while the tree is still being built, and exposes leaf order through
object state.  Refined geometry, topology, storage, and native block reads
instead need stable integer artifacts that can be borrowed independently.

The forest stream contains enough information to reconstruct hierarchy and
leaf order, but it does not itself prove that all level-1 roots are complete.
Malformed truncation or trailing nodes must be rejected before caller-owned
outputs are changed.

## Alternatives

A pointer tree closely mirrors the current implementation and makes recursive
neighbor searches direct, but retains hidden ownership, per-node allocation,
and construction-order coupling.  Storing only leaf levels and coordinates is
compact, but loses the explicit parent/child structure required by later
relation planning and forest roundtrip evidence.  A flat node table preserves
the preorder node identity while making every relation an ordinary integer
array.

The flat table could infer child IDs by reparsing the stream.  That saves one
`(node, 8)` array but makes every topology consumer repeat a variable-depth
walk.  M1 will repeatedly traverse parents and children, so direct child IDs
are the simpler composed trade-off.  Both node-to-leaf and leaf-to-node maps
are retained because field payloads use leaf order while topology operates on
nodes.

## Selected Direction

Use the forest-stream position as the zero-based node ID.  Produce caller-owned
`int64` arrays for levels, logical coordinates, parents, children,
node/leaf maps, and root node IDs.  Roots follow MOR-001 rank order.  A parent
expands children in `x + 2*y + 4*z` order, matching the current x-fast preorder;
child coordinates are `2*parent + (x,y,z)`.

Run an allocation-free recursive validation pass before filling outputs.  The
pass proves one complete octree per level-1 root, rejects trailing nodes, and
checks signed-`int64` logical-grid extent growth.  Recursion is bounded by the
maximum representable refinement depth rather than the number of nodes.  The fill pass
then overwrites every output without per-node allocation.

FST-001 reconstructs arbitrary complete 3D octrees.  It does not require
two-to-one balance or classify neighbors; those are properties of the next
refined-topology capability.  AMRVAC one-based block coordinates remain a
file-adapter conversion.
