# BAL-001 Design: Global All-Touch Two-To-One Balance

## Problem

Refined transfer and halo relation planning assume touching leaves differ by at
most one level.  Face balance alone is insufficient: a deeply refined leaf can
touch a coarse leaf only at an edge or corner while every face remains balanced.
Current connectivity can misclassify such diagonals rather than reject them.

## Alternatives

A finest-grid occupancy table makes pair relations simple but can scale as the
uniformized domain rather than leaf count.  Pairwise leaf-box comparison is an
independent reference but `O(L^2)`.  Retaining all 26 contacts just to validate
once couples policy to a global cache.

Reuse TOP-002's raw single-contact semantic as an inline C primitive.  For each
leaf and x-fast noncenter direction, a coarser leaf must be at most one level
lower.  A subdivided target node at the source level is admissible only when
every immediate child touching that direction is a leaf.  Four children touch a
face, two an edge, and one a corner.  This proves every touching level gap
without retaining contacts.

## Decomposition Record

Responsibility: enforce one explicit global Cartesian 3D all-touch two-to-one
admissibility rule on an unchanged refined forest artifact.

Owned semantic decisions: closed-box face/edge/corner touching, allowed
absolute level gap `<=1`, x-fast first-violation order, physical-direction skip,
and violation reporting.

Explicitly non-owned decisions: FST conformance, contact discovery, relation
kind/cache, operation/source expansion, support planning, value transfer,
geometry, storage, periodicity, and scheduling.

Inputs and outputs: the TOP-002/FST subset is borrowed; success returns `None`,
failure identifies the first source leaf/direction/target without mutation.

Mutation and ownership: all inputs read-only borrowed; no output or retained
state; no leaf/direction scratch.

Access pattern / halo reach: metadata contacts over the complete 26-neighbor
shell; no payload access or operator reach.

Independent reference or invariant: pairwise closed boxes lifted to the common
maximum-level lattice; balanced uniform/mixed trees; face gap; face-balanced
edge/corner gap; randomized forests; real metadata.

Immediate producer and consumer: FST-002/TOP-002 establish artifact/contact
semantics; REL-001/STO-004 and refined transfers consume the balance precondition.
TOP-003 may cache faces only after BAL-001 succeeds.

Kernel and composed measurement boundary: leaf-directions/s, depth/kind mix,
fixed allocation, FST+BAL lifecycle, real tree, and pairwise-reference scaling.

Five-question result: yes/yes/yes/yes/yes.  BAL owns admissibility only and
retains no topology or execution policy.

## Performance Gate

Measure uniform levels one through five, mixed synthetic trees, and the real
22,614-leaf tree.  Runtime must scale with `26*L*depth`, retain zero leaf-sized
memory, and remain small relative to current forest construction.  The
quadratic reference is limited to small cases.  No cache is introduced merely
to accelerate this once-per-artifact validation.
