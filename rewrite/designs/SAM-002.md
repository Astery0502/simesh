# SAM-002 Design: Zero-Order Level-1 Sampling

## Problem

SAM-002 samples arbitrary Cartesian output cell centers from level-1
piecewise-constant source cells while allowing selected primary chunks to write
their disjoint contributions into one output. The difficult part is not the
copy: it is defining one deterministic source cell and block at binary64 faces
without a dense output-owner map or mutation-order dependence.

## Alternatives

The current block-driven formulas estimate each block's output index range with
`ceil`/`floor`. They are fast, but an output center exactly on a block face is
visited by both blocks; the lower block can form a one-past-end local index, and
the final owner depends on block/pass ordering. A direct output-driven reference
avoids ambiguity by locating every output center globally, but repeating the
whole output scan for every bounded chunk is not useful. Precomputing dense
owner or slot arrays would add output- or topology-sized scratch and complicate
the explicit memory budget.

The selected design defines one global owner function. It computes each output
center with an explicit binary64 formula, converts it to one canonical global
source-cell index, then obtains block coordinate and local cell by integer
division/remainder. The simple reference scans output cells once. The bounded
Cython path remains block-driven: for each selected block and axis, binary
search finds the contiguous output-index interval whose owner block coordinate
matches that block. Cells in the Cartesian product use the same global owner
function, so chunks are disjoint by construction and exact-face centers belong
to the upper source cell/block.

This requires only scalar state, reuses MOR maps, and never reads halos. Native
full-domain/native-resolution requests may dispatch to SAM-001 only after an
explicit per-axis check proves that every nominal native center retains its own
half-open face owner. Parallel block traversal is safe only for unique selected
IDs; it is deferred until serial runtime and duplicate semantics are measured.

Independent review produced a GEO-valid counterexample where separately rounded
native `center(0)` equals `face(1)`. Highest-face SAM-002 ownership correctly
selects cell one, while exact SAM-001 placement puts source cell zero at output
index zero. The selected design therefore accepts internal coincident faces,
keeps highest-face ownership, and does not claim unconditional native equality.
Rejecting every such source grid would require a potentially enormous per-call
scan and would narrow GEO-001 retroactively.

## Optimization Result

The first correct Cython path used canonical-face binary search for every owner.
An arithmetic quotient candidate, accepted only after exact lower/upper face
bracketing and otherwise falling back to that binary search, improved general
and bounded runtime by about 2.3--2.4x without changing any owner in focused or
randomized tests.

A guarded native prototype proved every axis owner before dispatching to
SAM-001. It improved an ordinary four-field native call by about 6.7x, but the
`O(sum(domain_cell_counts))` proof repeated for every bounded chunk and took
about 11.9 ms even for an empty two-million-cell call. Independent audit caught
that scaling defect. The inline dispatch was removed; orchestration may perform
and amortize such a proof once in a later executor. Resolution-sized owner
arrays and parallel duplicate-free variants are not retained.
